장면 1

새 파일 생성과 끝에 추가

쓰기 모드 x는 파일이 없을 때만 새로 만들고 이미 있으면 FileExistsError를 냅니다. a는 파일 끝에 내용을 추가하며 파일이 없으면 만듭니다.

모든 예제는 TemporaryDirectory로 새로 만든 임시 폴더 안에서만 작업하고 종료할 때 정리합니다. 실제 기록 경로를 코드에 넣지 않아도 생성과 추가의 차이를 확인할 수 있습니다.

Path(folder) / "observations.txt"는 그 폴더 안의 observations.txt 경로를 만듭니다. Path에 쓰는 /는 나눗셈이 아니라 경로 부분을 이어 붙이는 연산입니다. 경로를 만든 것만으로 파일이 생기지는 않으며 뒤의 open() 호출에서 실제 파일을 만듭니다.

Python 코드

from pathlib import Path
from tempfile import TemporaryDirectory

with TemporaryDirectory() as folder:
    path = Path(folder) / "observations.txt"
    with path.open("x", encoding="utf-8") as target:
        target.write("숲:4\n")
    with path.open("a", encoding="utf-8") as target:
        target.write("강:2\n")
    print(path.read_text(encoding="utf-8"), end="")

장면 2

덮어쓰기의 영향을 확인하기

w는 파일을 열 때 기존 내용을 비우고 새로 씁니다. Path.write_text()도 텍스트를 덮어쓰는 편의 메서드입니다. 기존 기록을 보존해야 하면 새 경로를 고르거나 추가 모드를 선택해야 합니다.

아래는 우리가 방금 만든 임시 파일만 덮어씁니다. 새 글이 더 짧아도 이전 글의 뒷부분은 남지 않습니다. 실제 작업에서는 대상 경로와 기존 자료 보존 방법을 정한 후 쓰기를 수행하세요.

Python 코드

from pathlib import Path
from tempfile import TemporaryDirectory

with TemporaryDirectory() as folder:
    path = Path(folder) / "summary.txt"
    path.write_text("이전 긴 기록", encoding="utf-8")
    print(path.read_text(encoding="utf-8"))
    path.write_text("새 기록", encoding="utf-8")
    print(path.read_text(encoding="utf-8"))

장면 3

방금 만든 파일과 빈 폴더 삭제하기

mkdir()는 폴더를 만듭니다. unlink()는 파일 경로를 제거하고, rmdir()는 비어 있는 폴더를 제거합니다. 보통 휴지통으로 이동하는 기능이 아니므로 대상 확인 없이 실제 자료에 적용하면 안 됩니다.

아래는 새 임시 폴더 안에 만든 draft.txt 한 파일만 삭제한 뒤, 비어진 drafts 폴더를 지웁니다. exists() 결과를 통해 이 예제 경로들이 사라졌는지 확인합니다. 비어 있지 않은 폴더의 재귀 삭제는 다루지 않습니다.

Python 코드

from pathlib import Path
from tempfile import TemporaryDirectory

with TemporaryDirectory() as folder:
    drafts = Path(folder) / "drafts"
    drafts.mkdir()
    path = drafts / "draft.txt"
    path.write_text("연습", encoding="utf-8")
    path.unlink()
    print(path.exists())
    drafts.rmdir()
    print(drafts.exists())
