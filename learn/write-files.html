파일을 만들고 안전하게 정리하기

기존 파일에 숲:4가 있습니다. 강:2를 더 적을 때 앞의 기록을 지우지 않으려면 어떤 쓰기 방법을 골라야 할까요?

기존 내용: 숲:4→추가 후: 숲:4 · 강:2

저장된 파일을 읽을 수 있습니다. 이제 새로 만들기·끝에 추가하기·덮어쓰기가 파일 내용을 어떻게 바꾸는지 구별합니다.

두 줄을 순서대로 저장한 결과를 대조하고, 예제가 직접 만든 파일과 빈 폴더만 정리하는 범위를 확인합니다.

읽고 나면생성·덮어쓰기·추가 모드와 파일·빈 폴더 삭제의 차이를 설명합니다.

먼저 익힐 개념 · 저장된 파일에서 기록 읽기

01

새 파일 생성과 끝에 추가

새 관찰 파일에 첫 줄을 쓰고, 그 뒤에 두 번째 줄을 덧붙이려 합니다. "x" 모드는 파일이 없을 때만 새로 만들며 이미 있으면 FileExistsError를 냅니다. "a" 모드는 기존 내용 뒤에 쓰고, 파일이 없으면 만듭니다.

아래 코드는 TemporaryDirectory로 만든 예제용 폴더 안에서만 작업합니다. Path(folder) / "observations.txt"는 파일 위치를 정할 뿐 파일을 만들지 않습니다. 6행에서 x 모드로 열 때 실제 파일이 생깁니다.

target.write("숲:4\n")은 글을 파일에 쓰는 지시입니다. 화면에 출력하는 print와 다릅니다. 첫 with가 끝나 파일을 닫은 뒤 a 모드로 다시 열어 "강:2\n"을 뒤에 추가합니다.

마지막에 파일을 다시 읽어 print할 때 비로소 두 줄이 화면에 나옵니다. 바깥 with를 나가면 예제의 임시 폴더와 파일은 정리됩니다. 실제 기록을 보존하려면 따로 정한 프로젝트 경로에 저장해야 합니다.

첫 줄을 쓴 뒤 a 모드로 다시 열면 숲:4는 남아 있을까요?

상태의 변화01 / 06
Pythonwrite-files.py
01from pathlib import Path02from tempfile import TemporaryDirectory03 04with TemporaryDirectory() as folder:05    path = Path(folder) / "observations.txt"06    with path.open("x", encoding="utf-8") as target:07        target.write("숲:4\n")08    with path.open("a", encoding="utf-8") as target:09        target.write("강:2\n")10    print(path.read_text(encoding="utf-8"), end="")

이 예제의 두 줄은 마지막 print에서 화면에 보입니다. 그 뒤 임시 파일을 정리해도 이미 출력한 글은 없어지지 않습니다.

02

덮어쓰기의 영향을 확인하기

w는 파일을 열 때 기존 내용을 비우고 새로 씁니다. Path.write_text()도 텍스트를 덮어쓰는 편의 메서드입니다. 기존 기록을 보존해야 하면 새 경로를 고르거나 추가 모드를 선택해야 합니다.

아래는 우리가 방금 만든 임시 파일만 덮어씁니다. 새 글이 더 짧아도 이전 글의 뒷부분은 남지 않습니다. 실제 작업에서는 대상 경로와 기존 자료 보존 방법을 정한 후 쓰기를 수행하세요.

첫 write_text 뒤의 파일 내용은 "이전 긴 기록"입니다. 두 번째 write_text는 파일 내용을 "새 기록"만으로 바꿉니다. 줄을 추가하는 a와 달리 기존 글의 나머지도 없어져, 마지막 출력에 "긴 기록"이 따라오지 않습니다.

Pythonwrite-files.py
01from pathlib import Path02from tempfile import TemporaryDirectory03 04with TemporaryDirectory() as folder:05    path = Path(folder) / "summary.txt"06    path.write_text("이전 긴 기록", encoding="utf-8")07    print(path.read_text(encoding="utf-8"))08    path.write_text("새 기록", encoding="utf-8")09    print(path.read_text(encoding="utf-8"))

03

방금 만든 파일과 빈 폴더 삭제하기

mkdir()는 폴더를 만듭니다. unlink()는 파일 경로를 제거하고, rmdir()는 비어 있는 폴더를 제거합니다. 보통 휴지통으로 이동하는 기능이 아니므로 대상 확인 없이 실제 자료에 적용하면 안 됩니다.

아래는 새 임시 폴더 안에 만든 draft.txt 한 파일만 삭제한 뒤, 비어진 drafts 폴더를 지웁니다. exists() 결과를 통해 이 예제 경로들이 사라졌는지 확인합니다. 비어 있지 않은 폴더의 재귀 삭제는 다루지 않습니다.

파일이 들어 있는 drafts 폴더를 먼저 rmdir로 지울 수는 없습니다. 이 예제는 path.unlink()로 draft.txt를 지우고, 이제 비어 있는 drafts를 rmdir()로 지웁니다. 두 False는 각각 파일과 폴더 경로가 더 이상 없다는 확인입니다.

Pythonwrite-files.py
01from pathlib import Path02from tempfile import TemporaryDirectory03 04with TemporaryDirectory() as folder:05    drafts = Path(folder) / "drafts"06    drafts.mkdir()07    path = drafts / "draft.txt"08    path.write_text("연습", encoding="utf-8")09    path.unlink()10    print(path.exists())11    drafts.rmdir()12    print(drafts.exists())

정답x

오답: ww는 기존 내용을 비우므로 새 파일만 허용하는 목적에 맞지 않습니다.

정답: xx는 배타적 생성 모드로, 같은 경로가 이미 있으면 예외를 냅니다.
