장면 1

같은 값을 하나로 세기

집합 set은 중복 항목을 갖지 않는 묶음입니다. 리스트를 set()에 전달하면 같은 값은 한 항목으로 모입니다. 집합에는 인덱스로 접근하는 순서가 없습니다.

집합 출력 순서에 기대지 않도록 예제에서는 sorted()로 정렬해 보여줍니다. 빈 집합은 set()으로 만들고, {}는 빈 딕셔너리이므로 구별해야 합니다.

Python 코드

visited = set(["숲", "강", "숲"])
print(len(visited))
print(sorted(visited))
print("숲" in visited)

실행 결과

2
['강', '숲']
True

값의 구성

원래 기록: 숲, 강, 숲 · 서로 다른 장소: 강, 숲

    visited
    강 · 숲 (순서 없음)

    이 단계의 출력: (표준 출력 없음)

  2. 개수 확인

    서로 다른 장소가 두 곳입니다.

장면 2

두 묶음의 관계 계산하기

합집합 |는 양쪽의 모든 항목, 교집합 &는 공통 항목, 차집합 -는 왼쪽에만 있는 항목을 구합니다. 대칭 차집합 ^는 한쪽에만 있는 항목을 구합니다.

두 기록을 비교할 때 같은 기호라도 숫자의 비트 연산과 자료형이 다릅니다. 여기서는 집합 전체에 포함된 장소를 기준으로 결과를 만듭니다.

Python 코드

morning = {"숲", "강"}
afternoon = {"강", "못"}
print(sorted(morning | afternoon))
print(sorted(morning & afternoon))
print(sorted(morning - afternoon))
print(sorted(morning ^ afternoon))

실행 결과

['강', '못', '숲']
['강']
['숲']
['못', '숲']

값의 구성

아침만: 숲 · 공통: 강 · 오후만: 못

  1. 공통 항목 검사

    양쪽에 강이 있습니다.

    공통 항목
    강

    이 단계의 출력: ['강', '못', '숲'] ['강']

  2. 한쪽 항목 검사

    아침만 숲, 오후만 못이 있습니다.

    아침에만
    숲
    오후에만
    못

    이 단계의 출력: ['강', '못', '숲'] ['강'] ['숲'] ['못', '숲']

장면 3

수정할 집합과 고정할 집합

add()는 집합에 항목 하나를 추가하고 discard()는 있으면 제거합니다. remove()도 제거하지만 없는 항목이면 오류가 납니다. update()는 여러 항목을 추가합니다.

frozenset은 항목을 추가하거나 제거할 수 없는 집합입니다. 고정된 허용 장소처럼 변경하지 않을 집합을 표현할 수 있습니다. 아래에서는 수정한 set에서 별도 frozenset을 만듭니다.

Python 코드

allowed = {"숲"}
allowed.add("강")
allowed.discard("못")
fixed = frozenset(allowed)
allowed.add("공원")
print(sorted(allowed))
print(sorted(fixed))

실행 결과

['강', '공원', '숲']
['강', '숲']

값의 구성

변경 가능한 allowed: 강, 공원, 숲 · 고정한 fixed: 강, 숲

  1. 고정 시점

    강과 숲을 frozenset으로 만듭니다.

    allowed
    강 · 숲
    fixed
    강 · 숲 (변경 불가)

    이 단계의 출력: (표준 출력 없음)

  2. 이후 추가

    allowed에만 공원이 추가됩니다.

    allowed
    강 · 공원 · 숲
    fixed
    강 · 숲 (유지)

    이 단계의 출력: (표준 출력 없음)

결과와 관계 확인

allowed
강 · 공원 · 숲 (순서 없음)
fixed
강 · 숲 (변경 불가)
