중복과 공통 항목 찾기

두 번 방문한 장소는 하나로 세고 두 기록의 공통 장소를 찾고 싶습니다.

읽고 나면

집합의 중복 제거와 합집합·교집합·차집합을 사용합니다.

먼저 읽으면 좋은 레슨 리스트의 순서와 항목 바꾸기

아래로 이어 읽으세요. 결과와 상태는 항상 보이며, 확인 문항은 원할 때 답하면 됩니다.

01

같은 값을 하나로 세기

집합 set은 중복 항목을 갖지 않는 묶음입니다. 리스트를 set()에 전달하면 같은 값은 한 항목으로 모입니다. 집합에는 인덱스로 접근하는 순서가 없습니다.

집합 출력 순서에 기대지 않도록 예제에서는 sorted()로 정렬해 보여줍니다. 빈 집합은 set()으로 만들고, {}는 빈 딕셔너리이므로 구별해야 합니다.

Python 코드

Python 3.10+
visited = set(["숲", "강", "숲"])
print(len(visited))
print(sorted(visited))
print("숲" in visited)

예제 실행 결과

2
['강', '숲']
True

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    중복 제거

    반복한 숲을 한 항목으로 봅니다.

  2. 2

    개수 확인

    서로 다른 장소가 두 곳입니다.

02

두 묶음의 관계 계산하기

합집합 |는 양쪽의 모든 항목, 교집합 &는 공통 항목, 차집합 -는 왼쪽에만 있는 항목을 구합니다. 대칭 차집합 ^는 한쪽에만 있는 항목을 구합니다.

두 기록을 비교할 때 같은 기호라도 숫자의 비트 연산과 자료형이 다릅니다. 여기서는 집합 전체에 포함된 장소를 기준으로 결과를 만듭니다.

Python 코드

Python 3.10+
morning = {"숲", "강"}
afternoon = {"강", "못"}
print(sorted(morning | afternoon))
print(sorted(morning & afternoon))
print(sorted(morning - afternoon))
print(sorted(morning ^ afternoon))

예제 실행 결과

['강', '못', '숲']
['강']
['숲']
['못', '숲']

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    공통 항목 검사

    양쪽에 강이 있습니다.

  2. 2

    한쪽 항목 검사

    아침만 숲, 오후만 못이 있습니다.

03

수정할 집합과 고정할 집합

add()는 집합에 항목 하나를 추가하고 discard()는 있으면 제거합니다. remove()도 제거하지만 없는 항목이면 오류가 납니다. update()는 여러 항목을 추가합니다.

frozenset은 항목을 추가하거나 제거할 수 없는 집합입니다. 고정된 허용 장소처럼 변경하지 않을 집합을 표현할 수 있습니다. 아래에서는 수정한 set에서 별도 frozenset을 만듭니다.

Python 코드

Python 3.10+
allowed = {"숲"}
allowed.add("강")
allowed.discard("못")
fixed = frozenset(allowed)
allowed.add("공원")
print(sorted(allowed))
print(sorted(fixed))

예제 실행 결과

['강', '공원', '숲']
['강', '숲']

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    고정 시점

    강과 숲을 frozenset으로 만듭니다.

  2. 2

    이후 추가

    allowed에만 공원이 추가됩니다.

두 집합에 공통으로 들어 있는 항목을 구하는 연산은 무엇인가요?

정답과 모든 선택지의 해설 읽기
  1. 오답: a | b

    합집합은 어느 한쪽에라도 있는 모든 항목을 구합니다.

  2. 오답: a - b

    차집합은 a에만 있는 항목을 구합니다.

  3. 정답: a & b

    교집합은 양쪽에 함께 있는 항목을 구합니다.
