공백과 대소문자 맞추기

메서드는 객체에 붙어 있는 함수입니다. 문자열 뒤에 .strip()을 붙이면 앞뒤 공백을 없앤 새 문자열을 얻고 .lower()는 영문자를 소문자로 바꿉니다.

두 호출을 이어 쓰면 앞 호출의 결과에 다음 호출을 적용합니다. 원래 raw는 바뀌지 않으므로 정리한 결과를 place에 대입합니다.

Python 코드

raw = "  PARK  "
place = raw.strip().lower()
print(place)
print(len(raw))

실행 결과

park
8

원본: 공백 2개 + PARK + 공백 2개 · 정리한 값: park

    앞뒤 공백이 빠진 PARK를 얻습니다.

    raw
    " PARK "
    strip() 결과
    "PARK"

    이 단계의 출력: (표준 출력 없음)

  2. lower 이후

    소문자 park를 place에 연결합니다.

    raw
    " PARK "
    place
    "park"

    이 단계의 출력: (표준 출력 없음)

찾고 바꾸기

in은 문자열 안에 특정 글이 있는지 확인하는 연산자입니다. startswith()는 시작 부분을 확인하고 replace()는 일치하는 부분을 다른 글로 바꾼 새 문자열을 만듭니다.

find()는 처음 찾은 위치를 돌려주고, 없으면 -1을 돌려줍니다. 찾기와 바꾸기의 결과를 먼저 확인하면 전체 기록을 의도하지 않게 수정하는 실수를 줄일 수 있습니다.

Python 코드

label = "zone-west"
print("west" in label)
print(label.startswith("zone"))
print(label.find("east"))
print(label.replace("west", "east"))

실행 결과

True
True
-1
zone-east

실행 순서

찾을 글: west는 있음, east는 없음 · 바꾼 결과: zone-east

  1. 검색

    west 포함 여부는 True, east의 위치는 -1입니다.

    label
    "zone-west" 유지
    새 문자열
    "zone-east"

    이 단계의 출력: True True -1 zone-east

나누고 다시 잇기

split()은 구분자를 기준으로 글을 나누어 리스트로 돌려줍니다. 리스트는 순서가 있는 여러 값의 묶음이며, 자세한 수정 방법은 「리스트의 순서와 항목 바꾸기」 레슨에서 배웁니다.

join()은 문자열 묶음 사이에 구분자를 넣어 하나의 문자열을 만듭니다. 아래에서는 쉼표로 나뉜 장소를 읽고, 출력에는 슬래시를 사용합니다.

Python 코드

places = "숲,강,공원".split(",")
print(places)
print(" / ".join(places))

실행 결과

['숲', '강', '공원']
숲 / 강 / 공원

입력에서 결과로

입력 글: 숲,강,공원 · 중간 묶음: 숲 · 강 · 공원 · 출력 글: 숲 / 강 / 공원

  1. 나누기

    쉼표마다 글을 나누어 순서대로 담습니다.

    places
    ['숲', '강', '공원']

    이 단계의 출력: (표준 출력 없음)

  2. 잇기

    각 문자열 사이에 /를 넣어 연결합니다.

    구분자
    " / "
    새 문자열
    숲 / 강 / 공원

    이 단계의 출력: ['숲', '강', '공원'] 숲 / 강 / 공원

결과와 관계 확인

places
['숲', '강', '공원']
연결한 결과

정답원래 문자열에 계속 연결됩니다.

오답: 앞뒤 공백이 제거됩니다.문자열은 불변 객체입니다. 호출은 새 문자열을 돌려줍니다.

정답: 원래 문자열에 계속 연결됩니다.raw의 연결을 바꾸려면 raw = raw.strip()처럼 대입해야 합니다.

오답: 빈 문자열이 됩니다.strip()은 모든 글을 지우는 메서드가 아닙니다.

기억할 한 가지

문자열 메서드는 원본 문자열을 바꾸지 않습니다. 반환값은 메서드에 따라 문자열·정수·불리언·리스트 등이므로 필요한 결과를 이름에 연결합니다.
