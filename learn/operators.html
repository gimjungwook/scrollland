01

값·객체·포함을 구별하기

같은 내용을 적은 기록 두 개와 기록 하나를 두 이름으로 부르는 경우는 다릅니다. first와 second를 각각 [2, 4]로 만들면 항목 값은 같아도 리스트 객체는 둘입니다. 객체는 이름이 가리키는 실제 값을 뜻합니다.

alias = first는 새 리스트를 만들지 않습니다. first가 이미 가리키는 리스트에 alias라는 이름을 하나 더 연결합니다. 그림에서 first와 alias의 선이 같은 리스트에 닿는지 보세요.

==는 항목 값이 같은지 묻고, is는 같은 객체를 가리키는지 묻습니다. in은 값이 묶음의 항목에 들어 있는지 묻습니다. 작은 정수나 문자열을 is로 비교하면 Python의 객체 재사용 때문에 혼동할 수 있으므로 일반적인 값 비교에는 ==를 사용합니다. 값 없음 확인에는 is None을 씁니다.

first와 second의 내용이 같은데 is는 왜 False이고, first와 alias의 is는 왜 True일까요?

02

조건의 계산 순서 이용하기

count가 0이면 12 / count를 계산할 수 없습니다. 하지만 and는 앞 조건이 거짓이면 뒤 조건을 계산하지 않습니다. 두 조건이 모두 참일 가능성이 이미 사라졌기 때문입니다.

아래에서는 count != 0이 False여서 12 / count > 2를 건너뜁니다. 따라서 0으로 나누는 오류 없이 False를 출력합니다. 이런 계산 방식을 단락 평가라고 합니다. 순서를 거꾸로 쓰면 먼저 0으로 나누게 되므로 같은 보호가 되지 않습니다.

다음 count += 2는 현재 숫자 0에 2를 더해 count에 다시 대입합니다. 이 숫자 예제에서는 count = count + 2와 같은 결과이며 둘째 출력은 2입니다. 여러 연산을 묶을 때는 괄호로 어느 부분을 먼저 계산할지 드러낼 수 있습니다.

비트별 상태를 비교하기

비트는 0 또는 1 한 자리입니다. 이진수는 비트로 수를 적는 방법이며 0b 접두사로 적습니다. 0b101은 십진수 5입니다. &는 두 비트가 모두 1일 때, |는 하나라도 1일 때, ^는 서로 다를 때 1을 만듭니다.

<<는 비트를 왼쪽으로, >>는 오른쪽으로 옮기는 연산입니다. ~는 비트를 뒤집으며 정수 x에서 ~x는 -x-1입니다. 논리 조건의 and·or와 정수의 &·|는 용도가 다릅니다.

Pythonoperators.py
01flags = 0b10102mask = 0b00103print(flags & mask)04print(flags | 0b010)05print(flags ^ mask)06print(mask << 2)07print(flags >> 1)08print(~mask)
