값·객체·포함을 구별하기

==는 값이 같은지 묻고 is는 같은 객체인지 묻습니다. 같은 내용의 리스트 두 개도 별도로 만들면 서로 다른 객체입니다. in은 묶음에 값이 포함되는지 묻습니다.

[2, 4]는 2와 4를 항목으로 갖는 새 리스트를 만드는 표기입니다. 두 줄에서 각각 만들면 내용이 같아도 별도 객체입니다. 반면 alias = first는 이미 만든 객체에 다른 이름을 연결합니다.

작은 정수나 문자열을 is로 비교하면 Python의 객체 재사용 때문에 혼란스러울 수 있습니다. 값 비교에는 ==를, 값 없음 확인에는 is None을 사용하세요.

Pythonoperators.py
01first = [2, 4]02second = [2, 4]03alias = first04print(first == second)05print(first is second)06print(first is alias)07print(4 in first)

단락 평가는 결과가 결정되면 뒤 식을 계산하지 않는 방식입니다. and에서 앞 조건이 거짓이면 뒤 조건은 계산하지 않습니다. 아래에서는 0으로 나누는 식에 도달하지 않습니다.

+=는 현재 값에 오른쪽 값을 더해 다시 대입하는 증강 대입입니다. 숫자에 사용하는 count += 2는 이 예제에서 count = count + 2와 같은 결과를 냅니다. 괄호는 복잡한 식에서 의도한 묶음을 드러냅니다.

비트별 상태를 비교하기

비트는 0 또는 1 한 자리입니다. 이진수는 비트로 수를 적는 방법이며 0b 접두사로 적습니다. 0b101은 십진수 5입니다. &는 두 비트가 모두 1일 때, |는 하나라도 1일 때, ^는 서로 다를 때 1을 만듭니다.

<<는 비트를 왼쪽으로, >>는 오른쪽으로 옮기는 연산입니다. ~는 비트를 뒤집으며 정수 x에서 ~x는 -x-1입니다. 논리 조건의 and·or와 정수의 &·|는 용도가 다릅니다.

Pythonoperators.py
01flags = 0b10102mask = 0b00103print(flags & mask)04print(flags | 0b010)05print(flags ^ mask)06print(mask << 2)07print(flags >> 1)08print(~mask)
