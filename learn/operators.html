01

값·객체·포함을 구별하기

==는 값이 같은지 묻고 is는 같은 객체인지 묻습니다. 같은 내용의 리스트 두 개도 별도로 만들면 서로 다른 객체입니다. in은 묶음에 값이 포함되는지 묻습니다.

[2, 4]는 2와 4를 항목으로 갖는 새 리스트를 만드는 표기입니다. 두 줄에서 각각 만들면 내용이 같아도 별도 객체입니다. 반면 alias = first는 이미 만든 객체에 다른 이름을 연결합니다.

작은 정수나 문자열을 is로 비교하면 Python의 객체 재사용 때문에 혼란스러울 수 있습니다. 값 비교에는 ==를, 값 없음 확인에는 is None을 사용하세요.

Python 코드

Python 3.10+
first = [2, 4]
second = [2, 4]
alias = first
print(first == second)
print(first is second)
print(first is alias)
print(4 in first)

예제 실행 결과

False
True

검증한 예제의 상태를 순서대로 읽습니다.

    별도 생성

    리스트 객체 두 개를 만듭니다.

  2. 2

    alias는 first와 같은 리스트를 가리킵니다.

  3. 3

    질문별 결과

    ==는 값, is는 객체, in은 포함을 확인합니다.

02

조건의 계산 순서 이용하기

단락 평가는 결과가 결정되면 뒤 식을 계산하지 않는 방식입니다. and에서 앞 조건이 거짓이면 뒤 조건은 계산하지 않습니다. 아래에서는 0으로 나누는 식에 도달하지 않습니다.

+=는 현재 값에 오른쪽 값을 더해 다시 대입하는 증강 대입입니다. 숫자에 사용하는 count += 2는 이 예제에서 count = count + 2와 같은 결과를 냅니다. 괄호는 복잡한 식에서 의도한 묶음을 드러냅니다.

Python 코드

Python 3.10+
count = 0
print(count != 0 and 12 / count > 2)
count += 2
print(count)

예제 실행 결과

False
2

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    and 검사

    앞이 거짓이라 전체 결과가 정해집니다.

  2. 2

    다음 지시

    증강 대입으로 count의 값을 2로 바꿉니다.

03

비트별 상태를 비교하기

비트는 0 또는 1 한 자리입니다. 이진수는 비트로 수를 적는 방법이며 0b 접두사로 적습니다. 0b101은 십진수 5입니다. &는 두 비트가 모두 1일 때, |는 하나라도 1일 때, ^는 서로 다를 때 1을 만듭니다.

<<는 비트를 왼쪽으로, >>는 오른쪽으로 옮기는 연산입니다. ~는 비트를 뒤집으며 정수 x에서 ~x는 -x-1입니다. 논리 조건의 and·or와 정수의 &·|는 용도가 다릅니다.

Python 코드

Python 3.10+
flags = 0b101
mask = 0b001
print(flags & mask)
print(flags | 0b010)
print(flags ^ mask)
print(mask << 2)
print(flags >> 1)
print(~mask)

7
4

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    비트 비교

    같은 자리끼리 규칙을 적용합니다.

  2. 2

    표현 확인

    출력은 기본적으로 이진 표기가 아닌 십진수입니다.

원할 때 확인하세요

코드를 읽고, 한 번 예측하기

같은 내용을 가진 별도 리스트 a와 b의 값을 비교하려면 무엇을 쓰나요?

정답과 모든 선택지의 해설 읽기
  1. 오답: a is b

    is는 내용 대신 같은 객체인지 묻습니다.

  2. 정답: a == b

    ==는 리스트의 항목 값을 비교합니다.

  3. 오답: a in b

    in은 a가 b의 항목으로 포함되는지를 묻습니다.

기억할 내용

값이 같은지, 같은 객체인지, 안에 포함되는지는 서로 다른 질문입니다.
