기록 하나와 기록 묶음 구별하기

중첩은 묶음 안에 다른 묶음이 들어 있는 구조입니다. 리스트는 기록의 순서를, 딕셔너리는 한 기록의 항목 이름을 표현할 수 있습니다.

records[1]["count"]는 먼저 두 번째 기록을 고른 뒤 그 기록의 count 값을 읽습니다. [] 한 쌍씩 읽으면 어떤 자료형을 다루는지 놓치지 않습니다.

Python 코드

records = [{"place": "숲", "count": 4}, {"place": "강", "count": 2}]
print(records[1]["place"])
print(records[1]["count"])

안쪽의 특정 값만 수정하기

관찰 한 건에 여러 수량이 있으면 딕셔너리 안에 리스트를 둘 수 있습니다. record["counts"][0]은 counts 리스트의 첫 숫자를 뜻합니다.

안쪽 항목만 고치면 다른 키는 그대로입니다. 큰 자료를 한 번에 이해하려고 하기보다 이름을 붙여 중간 묶음을 따로 읽는 방법도 사용할 수 있습니다.

Python 코드

record = {"place": "숲", "counts": [4, 2]}
record["counts"][0] = 5
print(record["place"])
print(record["counts"])

얕은 복사의 안쪽 공유 확인하기

딕셔너리 copy()도 바깥 객체만 복사합니다. 그 안의 리스트는 같은 객체일 수 있습니다. 그래서 copied["counts"].append(3)은 원본으로 읽는 리스트에도 보입니다.

한 단계 안쪽 리스트까지 독립시켜야 하면 그 리스트도 copy()할 수 있습니다. 복잡한 구조 전체를 재귀적으로 복사하는 deepcopy()는 copy 모듈의 기능입니다. 모듈은 「모듈을 불러와 연결하기」 레슨에서 배웁니다.

Python 코드

original = {"counts": [4, 2]}
copied = original.copy()
copied["counts"].append(3)
print(original["counts"])
independent = {"counts": original["counts"].copy()}
independent["counts"][0] = 9
print(original["counts"])
print(independent["counts"])

실행 결과

[4, 2, 3]
[4, 2, 3]
[9, 2, 3]

이름과 객체

original와 copied: 같은 안쪽 리스트 [4, 2, 3] · independent: 별도 안쪽 리스트 [9, 2, 3]

  1. 바깥 복사

    안쪽 리스트는 여전히 공유합니다.

    original["counts"]
    [4, 2]
    copied["counts"]
    [4, 2]

    이 단계의 출력: (표준 출력 없음)

  2. 안쪽 복사

    independent에 별도 리스트를 연결합니다.

    original["counts"]
    [4, 2, 3]
    copied["counts"]
    [4, 2, 3]
    independent["counts"]
    [4, 2, 3]

    이 단계의 출력: [4, 2, 3]

  3. 개별 수정

    독립한 리스트의 첫 값만 9가 됩니다.

    original["counts"]
    [4, 2, 3]
    copied["counts"]
    [4, 2, 3]
    independent["counts"]
    [9, 2, 3]

    이 단계의 출력: [4, 2, 3]
