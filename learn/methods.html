객체의 행동에 이름 붙이기

관찰 수량 4에 2를 더하려 합니다. record에 더하라고 요청하면 그 기록의 수량도 함께 바뀌게 할 수 있을까요?

record.add(2)→반환값 6 · count 6

객체에는 개별 상태가 있습니다. 메서드는 그 상태를 받거나 클래스 자체를 받아 필요한 작업을 수행하는 함수입니다.

record.add(2)가 어느 객체를 바꾸는지 확인한 뒤, 인스턴스·클래스·정적 메서드가 받는 첫 인자를 비교합니다.

읽고 나면인스턴스·클래스·정적 메서드의 첫 인자와 목적을 구별합니다.

먼저 익힐 개념 · 데이터와 행동을 객체로 묶기 · 함수 앞뒤에 공통 작업 붙이기

01

인스턴스 상태를 사용하는 메서드

관찰 수를 늘릴 때마다 바깥에서 count를 직접 고치는 대신 record.add(2)라는 행동으로 이름 붙일 수 있습니다. 클래스 안에 정의해 객체와 함께 사용하는 함수를 메서드라고 합니다.

record.add(2)를 호출하면 Python이 record를 self에 전달하고, 우리가 적은 2는 amount로 전달합니다. self.count += amount는 호출한 바로 그 객체의 수량을 4에서 6으로 바꿉니다.

이 메서드는 수량을 바꾸는 일과 새 수량을 반환하는 일을 둘 다 합니다. return self.count가 돌려준 6을 바깥 print가 출력한 뒤, 다음 줄에서 record.count를 읽어도 바뀐 6이 남아 있습니다.

첫 print가 끝난 뒤에도 record.count가 6인 이유는 무엇일까요?

02

클래스로 만드는 다른 경로 제공하기

@classmethod는 인스턴스 대신 클래스를 첫 인자로 받습니다. 첫 매개변수 이름으로 cls를 관례적으로 사용합니다. 문자열 등 다른 입력 형식에서 인스턴스를 만드는 대체 생성 경로에 쓸 수 있습니다.

cls(...)로 새 객체를 만들면 상속받은 클래스에서 메서드를 호출했을 때 그 클래스의 객체를 만들 수 있습니다. 아래에서는 숫자 문자열을 정수로 읽어 초기화합니다.

Observation.from_text("7")에서는 cls가 Observation을 가리킵니다. int("7")로 7을 만든 뒤 cls(7), 즉 Observation(7)을 호출합니다. 반환받은 record에는 count가 7로 준비되어 있습니다. 문자열을 받을 다른 출입구를 클래스에 둔 셈입니다.

Pythonmethods.py
01class Observation:02    def __init__(self, count):03        self.count = count04    @classmethod05    def from_text(cls, text):06        return cls(int(text))07 08record = Observation.from_text("7")09print(record.count)10print(isinstance(record, Observation))

객체 상태가 필요 없는 보조 함수

@staticmethod는 self나 cls를 자동으로 받지 않습니다. 클래스와 개념적으로 관련 있지만 객체의 상태를 읽지 않는 계산을 함께 둘 때 사용합니다.

단순한 독립 함수로 두는 것도 가능합니다. 클래스 안에 있다는 이유만으로 상태를 바꾸는 메서드라고 생각하지 말고, 입력과 사용하는 속성을 확인하세요.

이 검사는 어느 관찰 객체의 count도 읽지 않고 전달받은 value만 봅니다. bool은 int의 하위 자료형이므로 True를 수량으로 받지 않으려면 not isinstance(value, bool) 조건도 필요합니다. 그래서 4·-1·True의 판정은 차례로 True·False·False입니다.

Pythonmethods.py
01class Observation:02    @staticmethod03    def is_valid_count(value):04        return isinstance(value, int) and not isinstance(value, bool) and value >= 005 06print(Observation.is_valid_count(4))07print(Observation.is_valid_count(-1))08print(Observation.is_valid_count(True))
