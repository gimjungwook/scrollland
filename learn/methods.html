01

인스턴스 상태를 사용하는 메서드

인스턴스 메서드는 현재 객체를 self로 받아 그 속성을 읽거나 바꿉니다. record.add(2)는 Python이 record를 self로 전달한 호출입니다.

메서드는 함수와 마찬가지로 결과를 반환할 수 있습니다. 아래 add는 수량을 바꾼 후 새 수량을 반환합니다. 상태 변경과 반환의 두 역할을 설명에 함께 남겨야 호출자가 예상할 수 있습니다.

Python 코드

Python 3.10+
class Observation:
    def __init__(self, count):
        self.count = count
    def add(self, amount):
        self.count += amount
        return self.count

record = Observation(4)
print(record.add(2))
print(record.count)

예제 실행 결과

6
6

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    인자 연결

    self는 record, amount는 2입니다.

  2. 2

    상태 갱신

    count를 6으로 바꾸고 6을 반환합니다.

02

클래스로 만드는 다른 경로 제공하기

@classmethod는 인스턴스 대신 클래스를 첫 인자로 받습니다. 첫 매개변수 이름으로 cls를 관례적으로 사용합니다. 문자열 등 다른 입력 형식에서 인스턴스를 만드는 대체 생성 경로에 쓸 수 있습니다.

cls(...)로 새 객체를 만들면 상속받은 클래스에서 메서드를 호출했을 때 그 클래스의 객체를 만들 수 있습니다. 아래에서는 숫자 문자열을 정수로 읽어 초기화합니다.

Python 코드

Python 3.10+
class Observation:
    def __init__(self, count):
        self.count = count
    @classmethod
    def from_text(cls, text):
        return cls(int(text))

record = Observation.from_text("7")
print(record.count)
print(isinstance(record, Observation))

예제 실행 결과

7
True

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    문자열 변환

    7이라는 글을 정수로 읽습니다.

  2. 2

    생성

    cls(7)로 새 인스턴스를 만듭니다.

03

객체 상태가 필요 없는 보조 함수

@staticmethod는 self나 cls를 자동으로 받지 않습니다. 클래스와 개념적으로 관련 있지만 객체의 상태를 읽지 않는 계산을 함께 둘 때 사용합니다.

단순한 독립 함수로 두는 것도 가능합니다. 클래스 안에 있다는 이유만으로 상태를 바꾸는 메서드라고 생각하지 말고, 입력과 사용하는 속성을 확인하세요.

Python 코드

Python 3.10+
class Observation:
    @staticmethod
    def is_valid_count(value):
        return isinstance(value, int) and not isinstance(value, bool) and value >= 0

print(Observation.is_valid_count(4))
print(Observation.is_valid_count(-1))
print(Observation.is_valid_count(True))

예제 실행 결과

True
False
False

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    자료형 확인

    정수인지 확인하고 정수의 하위형인 bool은 제외합니다.

  2. 2

    범위 확인

    0 이상인 수량만 허용합니다.

원할 때 확인하세요

코드를 읽고, 한 번 예측하기

@classmethod의 첫 매개변수 cls는 무엇을 받나요?

정답과 모든 선택지의 해설 읽기
  1. 오답: 현재 개별 인스턴스

    인스턴스를 자동으로 받는 것은 일반 인스턴스 메서드의 self입니다.

  2. 정답: 호출에 사용한 클래스

    클래스 메서드는 클래스를 받아 대체 생성 경로 등에 사용할 수 있습니다.

  3. 오답: 아무 값도 받지 않습니다.

    자동 첫 인자가 없는 것은 staticmethod입니다.

기억할 내용

메서드는 필요한 상태가 인스턴스인지 클래스인지에 따라 형태를 고릅니다.
