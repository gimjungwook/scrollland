01

한 줄을 입력받기

표준 입력은 프로그램이 입력을 받는 통로이고, 표준 출력은 결과를 내보내는 통로입니다. 터미널에서는 보통 키보드와 화면에 연결됩니다. input()은 줄 하나를 읽고 끝의 줄바꿈을 제외한 문자열을 돌려줍니다.

예제에 제공한 입력은 숲입니다. 여기 표시한 출력은 프로그램이 내보낸 글만 포함하므로 사람이 입력한 글의 화면 표시는 따로 포함하지 않습니다. 이 사이트에서 입력창을 기다리는 코드는 실행되지 않습니다.

Python 코드

Python 3.10+
place = input()
print("장소:", place)

예제 실행 결과

장소: 숲
예제에 제공한 입력 자료

표준 입력

숲

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    입력 대기

    input()이 한 줄을 기다립니다.

  2. 2

    입력 후

    place에 문자열을 연결하고 장소를 출력합니다.

02

입력 문자를 수량으로 바꾸기

input()이 "6"을 읽어도 자료형은 str입니다. int()로 정수 6을 얻어야 정수 2와 더할 수 있습니다. 아래 입력은 6입니다.

int()가 읽을 수 없는 글을 주면 ValueError라는 예외가 납니다. 예외는 실행 중 생기는 오류 신호입니다. 여기서는 숫자 입력을 전제로 계산하고, 잘못된 글에 응답하는 방법은 「예외를 구별해 처리하기」 레슨에서 다룹니다.

Python 코드

Python 3.10+
text = input()
count = int(text)
print(count + 2)

예제 실행 결과

8
예제에 제공한 입력 자료

표준 입력

6

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    읽기

    text에 문자열 6을 연결합니다.

  2. 2

    변환하기

    count에 정수 6을 연결합니다.

  3. 3

    출력하기

    정수 덧셈 결과 8을 출력합니다.

03

안내와 결과를 나누기

input("장소: ")처럼 괄호 안에 안내문을 넣으면 입력받기 전에 안내문을 출력합니다. print()의 sep은 값 사이 구분자이고 end는 출력 마지막에 붙일 글입니다. 기본 end는 줄바꿈입니다.

이 예제의 제공 입력은 강입니다. input()의 안내에는 줄바꿈이 없으므로 검증한 표준 출력에서 장소: 뒤로 다음 print()의 결과가 이어집니다. 실제 터미널은 사람이 입력한 강도 화면에 표시할 수 있습니다.

Python 코드

Python 3.10+
place = input("장소: ")
print(place, 3, sep=" | ", end="\n")

예제 실행 결과

장소: 강 | 3
예제에 제공한 입력 자료

표준 입력

강

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    안내 출력

    장소: 뒤에 줄바꿈 없이 입력을 기다립니다.

  2. 2

    입력 완료

    강을 읽고 구분자 |로 결과를 출력합니다.

원할 때 확인하세요

코드를 읽고, 한 번 예측하기

input()으로 4를 입력받은 값의 자료형은 무엇인가요?

정답과 모든 선택지의 해설 읽기
  1. 오답: int

    숫자처럼 보여도 input()의 반환값은 문자열입니다.

  2. 정답: str

    정수로 계산하려면 int() 같은 변환을 추가해야 합니다.

  3. 오답: float

    소수 계산용 변환 역시 자동으로 일어나지 않습니다.

기억할 내용

input()은 문자열을 돌려줍니다. 숫자 계산 전에 변환할 형식을 정합니다.
