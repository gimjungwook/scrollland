입력을 받아 답 만들기

예제에 적힌 장소를 숲에서 강으로 바꾸려면 매번 코드를 고쳐야 할까요?

입력: 숲→출력: 장소: 숲

숫자와 문자열의 차이를 배웠습니다. input()으로 받은 글을 그대로 표시할 때와 수량으로 바꿔 계산할 때를 구별합니다.

미리 제공한 입력을 프로그램이 받아 안내문을 만드는 과정을 읽습니다. 이 페이지에서 직접 입력할 필요는 없습니다.

읽고 나면input()의 문자열 결과를 변환하고 print()로 답을 구성합니다.

먼저 익힐 개념 · 같아 보이는 값 구별하기

01

한 줄을 입력받기

표준 입력은 프로그램이 입력을 받는 통로이고, 표준 출력은 결과를 내보내는 통로입니다. 터미널에서는 보통 키보드와 화면에 연결됩니다. input()은 줄 하나를 읽고 끝의 줄바꿈을 제외한 문자열을 돌려줍니다.

예제에 제공한 입력은 숲입니다. 여기 표시한 출력은 프로그램이 내보낸 글만 포함하므로 사람이 입력한 글의 화면 표시는 따로 포함하지 않습니다. 이 사이트에서 입력창을 기다리는 코드는 실행되지 않습니다.

02

입력 문자를 수량으로 바꾸기

사람이 입력한 6은 처음에는 숫자 값이 아니라 글자 "6"으로 들어옵니다. input()은 입력한 줄을 문자열(str)로 돌려주므로 text의 값은 "6"입니다. 숫자처럼 보이는지와 자료형이 숫자인지는 별개의 문제입니다.

int(text)는 글자 "6"을 정수(int) 6으로 읽어 count에 연결합니다. 이제 count + 2는 정수끼리의 덧셈이므로 8입니다. text + 2처럼 문자열과 정수를 바로 더할 수는 없습니다.

이 예제에 제공된 입력은 6이며 직접 입력할 필요는 없습니다. "여섯"처럼 int()가 정수로 읽을 수 없는 글이면 ValueError라는 오류 신호가 납니다. 그런 입력에 응답하는 방법은 「예외를 구별해 처리하기」 레슨에서 다룹니다.

입력에 6이라고 썼는데 왜 int()를 거쳐야 2를 더할 수 있을까요?

입력 문자열 "6"을 정수 6으로 변환한 뒤 2를 더해 8을 출력합니다. text와 count의 값은 그대로 남습니다.

따옴표를 붙인 "6"과 따옴표 없는 6은 화면에 비슷하게 보여도 자료형이 다릅니다. 문자열은 글을 다루고 정수는 수량을 계산하는 데 사용합니다.

8은 print()에 전달한 계산 결과입니다. count = count + 2라고 대입하지 않았으므로 count가 자동으로 8이 되지는 않습니다.

03

안내와 결과를 나누기

input("장소: ")처럼 괄호 안에 안내문을 넣으면 입력받기 전에 안내문을 출력합니다. print()의 sep은 값 사이 구분자이고 end는 출력 마지막에 붙일 글입니다. 기본 end는 줄바꿈입니다.

이 예제의 제공 입력은 강입니다. input()의 안내에는 줄바꿈이 없으므로 검증한 표준 출력에서 장소: 뒤로 다음 print()의 결과가 이어집니다. 실제 터미널은 사람이 입력한 강도 화면에 표시할 수 있습니다.

01place = input("장소: ")02print(place, 3, sep=" | ", end="\n")

답을 떠올린 뒤, 아래의 설명과 비교해 보세요.

정답str

오답: int숫자처럼 보여도 input()의 반환값은 문자열입니다.

정답: strinput()은 입력한 한 줄을 문자열로 돌려줍니다. "4"를 정수 4로 계산에 쓰려면 int()로 변환합니다.

오답: float소수 계산용 변환 역시 자동으로 일어나지 않습니다.

기억할 한 가지

input()은 문자열을 돌려줍니다. 숫자 계산 전에 변환할 형식을 정합니다.
