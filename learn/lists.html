리스트의 순서와 항목 바꾸기

숲·강·공원을 차례로 방문했습니다. 두 번째 장소를 읽고 잘못 적은 장소 하나만 고치려면 어떻게 묶을까요?

places = ["숲", "강", "공원"]→places[1]: "강"

문자열은 글자를 순서대로 담았습니다. 리스트에는 여러 장소 같은 값들을 순서대로 담고 항목 자체를 바꿀 수 있습니다.

위치로 장소를 찾은 뒤 새 장소를 넣거나 지웁니다. 항목을 지운 자리에서 무엇이 다음 항목이 되는지도 확인합니다.

읽고 나면리스트의 항목을 읽고 추가·수정·삭제한 결과를 설명합니다.

먼저 익힐 개념 · 값에 이름을 연결하기 · 글의 위치와 표현 다루기

01

순서가 있는 묶음 만들기

리스트는 여러 값을 순서대로 담는 변경 가능한 객체입니다. 대괄호로 만들고, 문자열과 마찬가지로 인덱스 0부터 항목을 읽습니다. len()은 항목 수를 구합니다.

다른 언어에서 배열이라고 부르는 순서 있는 묶음과 비교할 수 있지만 Python 리스트는 서로 다른 자료형도 담을 수 있습니다. 같은 자료형의 수치를 저장하는 표준 array 도구와의 차이는 「모듈을 불러와 연결하기」 레슨에서 확인합니다.

Pythonlists.py
01places = ["숲", "강", "공원"]02print(places[1])03print(places[-1])04print(len(places))

실행 결과

강
공원
3
02

추가하고 한 항목 수정하기

append()는 마지막에 항목 하나를 추가하고 insert()는 지정 위치에 항목을 끼워 넣습니다. places[0] = "정원"은 리스트 자체의 첫 항목을 바꿉니다.

재대입과 달리 이 작업은 기존 리스트 객체의 내용 변경입니다. append()의 반환값은 None이므로 places = places.append(...)로 결과를 다시 대입하면 이름이 리스트가 아닌 None을 가리키게 됩니다.

Pythonlists.py
01places = ["숲", "강"]02places.append("공원")03places[0] = "정원"04places.insert(1, "못")05print(places)

실행 결과

['정원', '못', '강', '공원']
03

위치와 값으로 삭제하기

pop()은 위치의 항목을 제거하고 그 값을 반환합니다. 위치를 생략하면 마지막 항목입니다. remove()는 같은 값이 처음 나타난 항목 하나를 제거합니다.

del places[0]은 그 위치의 항목을 삭제하는 지시입니다. 없는 위치나 값을 제거하려 하면 오류가 나므로 어떤 항목을 지우는지 먼저 확인하세요. clear()는 해당 리스트의 모든 항목을 비웁니다.

Pythonlists.py
01places = ["숲", "강", "못", "강"]02removed = places.pop(2)03places.remove("강")04print(removed)05print(places)06del places[0]07print(places)

실행 결과

못
['숲', '강']
['강']

잠깐, 머릿속으로 실행해 보세요.

items = [1, 2]에 items.append(3)을 실행하면 무엇이 바뀌나요?

  1. 새 리스트만 생기고 items는 그대로입니다.
  2. items가 가리키는 리스트 끝에 3이 추가됩니다.
  3. items가 자동으로 None을 가리킵니다.

답을 떠올린 뒤, 아래의 설명과 비교해 보세요.

정답items가 가리키는 리스트 끝에 3이 추가됩니다.

오답: 새 리스트만 생기고 items는 그대로입니다.append()는 기존 리스트 객체의 내용을 바꿉니다.

정답: items가 가리키는 리스트 끝에 3이 추가됩니다.리스트는 변경 가능한 객체이며 결과는 [1, 2, 3]입니다.

오답: items가 자동으로 None을 가리킵니다.append()의 반환값은 None이지만 대입하지 않았다면 items의 연결은 유지됩니다.
