01

순서가 있는 묶음 만들기

리스트는 여러 값을 순서대로 담는 변경 가능한 객체입니다. 대괄호로 만들고, 문자열과 마찬가지로 인덱스 0부터 항목을 읽습니다. len()은 항목 수를 구합니다.

다른 언어에서 배열이라고 부르는 순서 있는 묶음과 비교할 수 있지만 Python 리스트는 서로 다른 자료형도 담을 수 있습니다. 같은 자료형의 수치를 저장하는 표준 array 도구와의 차이는 「모듈을 불러와 연결하기」 레슨에서 확인합니다.

Python 코드

Python 3.10+
places = ["숲", "강", "공원"]
print(places[1])
print(places[-1])
print(len(places))

예제 실행 결과

강
공원
3

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    생성

    세 항목이 순서대로 들어 있는 리스트를 만듭니다.

  2. 2

    읽기

    1은 두 번째, -1은 마지막 항목입니다.

02

추가하고 한 항목 수정하기

append()는 마지막에 항목 하나를 추가하고 insert()는 지정 위치에 항목을 끼워 넣습니다. places[0] = "정원"은 리스트 자체의 첫 항목을 바꿉니다.

재대입과 달리 이 작업은 기존 리스트 객체의 내용 변경입니다. append()의 반환값은 None이므로 places = places.append(...)로 결과를 다시 대입하면 이름이 리스트가 아닌 None을 가리키게 됩니다.

Python 코드

Python 3.10+
places = ["숲", "강"]
places.append("공원")
places[0] = "정원"
places.insert(1, "못")
print(places)

예제 실행 결과

['정원', '못', '강', '공원']

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    끝에 추가

    숲, 강, 공원

  2. 2

    첫 항목 수정

    정원, 강, 공원

  3. 3

    위치 1에 삽입

    정원, 못, 강, 공원

03

위치와 값으로 삭제하기

pop()은 위치의 항목을 제거하고 그 값을 반환합니다. 위치를 생략하면 마지막 항목입니다. remove()는 같은 값이 처음 나타난 항목 하나를 제거합니다.

del places[0]은 그 위치의 항목을 삭제하는 지시입니다. 없는 위치나 값을 제거하려 하면 오류가 나므로 어떤 항목을 지우는지 먼저 확인하세요. clear()는 해당 리스트의 모든 항목을 비웁니다.

Python 코드

Python 3.10+
places = ["숲", "강", "못", "강"]
removed = places.pop(2)
places.remove("강")
print(removed)
print(places)
del places[0]
print(places)

예제 실행 결과

못
['숲', '강']
['강']

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    최초 목록

    숲, 강, 못, 강

  2. 2

    pop과 remove 이후

    숲, 강

  3. 3

    del 이후

    강

원할 때 확인하세요

코드를 읽고, 한 번 예측하기

items = [1, 2]에 items.append(3)을 실행하면 무엇이 바뀌나요?

정답과 모든 선택지의 해설 읽기
  1. 오답: 새 리스트만 생기고 items는 그대로입니다.

    append()는 기존 리스트 객체의 내용을 바꿉니다.

  2. 정답: items가 가리키는 리스트 끝에 3이 추가됩니다.

    리스트는 변경 가능한 객체이며 결과는 [1, 2, 3]입니다.

  3. 오답: items가 자동으로 None을 가리킵니다.

    append()의 반환값은 None이지만 대입하지 않았다면 items의 연결은 유지됩니다.
