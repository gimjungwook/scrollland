관련된 작은 자료형을 안에 두기

보고서에서만 쓰는 상태를 Report.Status라고 찾을 수 있게 했습니다. 그러면 상태 객체가 바깥 보고서도 자동으로 알까요?

Report.Status("작성 중")→status.label: "작성 중"

클래스로 자료와 메서드를 묶었습니다. 클래스 안에 다른 클래스를 정의하면 이름의 경로는 묶이지만 두 인스턴스의 연결까지 생기지는 않습니다.

중첩 클래스의 객체를 만든 뒤 바깥 정보가 필요할 때 직접 전달합니다. 이름을 묶는 일과 객체를 연결하는 일을 나눠 봅니다.

읽고 나면중첩 클래스의 이름 경로와 바깥 인스턴스 연결의 한계를 설명합니다.

먼저 익힐 개념 · 데이터와 행동을 객체로 묶기 · 객체의 행동에 이름 붙이기

01

클래스 안에서 다른 클래스 정의하기

중첩 클래스는 클래스 본문 안에 정의한 별도 클래스입니다. Report.Status처럼 바깥 클래스의 속성 경로로 찾습니다. 이름 공간은 이름들이 어떤 객체와 연결되는지 관리하는 영역입니다.

안에 정의했다는 이유만으로 바깥 인스턴스의 속성을 자동으로 읽지는 않습니다. 아래 Status는 독립 인스턴스를 만들고 자신에게 전달한 label을 저장합니다.

Pythonnested-classes.py
01class Report:02    class Status:03        def __init__(self, label):04            self.label = label05 06status = Report.Status("작성 중")07print(status.label)08print(isinstance(status, Report.Status))

True
02

바깥 정보를 쓰려면 직접 전달하기

중첩 객체가 바깥 객체를 사용하려면 인자로 전달하는 등 연결을 직접 만들어야 합니다. 아래 Status는 report를 받아 자기 report 속성에 연결합니다.

서로 가리키는 객체가 많아지면 관계를 이해하기 어려워집니다. 단지 제목 문자열만 필요하다면 객체 전체 대신 제목 값만 전달하는 편이 더 단순할 수 있습니다.

Pythonnested-classes.py
01class Report:02    def __init__(self, title):03        self.title = title04    class Status:05        def __init__(self, report):06            self.report = report07        def summary(self):08            return self.report.title + ": 작성 중"09 10report = Report("숲 관찰")11status = Report.Status(report)12print(status.summary())

실행 결과

숲 관찰: 작성 중
03

중첩과 구성을 구별하기

구성은 한 객체가 다른 객체를 속성으로 갖고 함께 사용하는 구조입니다. 클래스 정의가 중첩되었는지와 별개입니다. 중첩은 이름을 어디에 둘지, 구성은 객체를 어떻게 연결할지에 관한 선택입니다.

여러 종류의 보고서에서 같은 상태를 사용할 예정이면 Status를 바깥에 독립 정의하는 편이 찾기 쉬울 수 있습니다. 아래는 중첩 없이도 Report가 Status를 가지는 구성 예제입니다.

Pythonnested-classes.py
01class Status:02    def __init__(self, label):03        self.label = label04 05class Report:06    def __init__(self, title, status):07        self.title = title08        self.status = status09 10report = Report("강 관찰", Status("검토 전"))11print(report.title, report.status.label)

실행 결과

강 관찰 검토 전

잠깐, 머릿속으로 실행해 보세요.

중첩 클래스의 인스턴스가 바깥 인스턴스를 자동으로 받나요?

  1. 항상 자동으로 받습니다.
  2. 중첩되어 있으면 self가 바깥 인스턴스입니다.
  3. 필요한 바깥 객체를 직접 전달해야 합니다.

답을 떠올린 뒤, 아래의 설명과 비교해 보세요.

정답필요한 바깥 객체를 직접 전달해야 합니다.

오답: 항상 자동으로 받습니다.Python의 중첩 클래스는 바깥 인스턴스를 자동 연결하지 않습니다.

오답: 중첩되어 있으면 self가 바깥 인스턴스입니다.self는 호출 대상인 현재 인스턴스입니다.

정답: 필요한 바깥 객체를 직접 전달해야 합니다.중첩은 이름 배치이며 객체 간 연결은 명시해야 합니다.

기억할 한 가지

클래스를 안에 정의해도 바깥 인스턴스가 자동으로 전달되지는 않습니다.
