01

클래스 안에서 다른 클래스 정의하기

중첩 클래스는 클래스 본문 안에 정의한 별도 클래스입니다. Report.Status처럼 바깥 클래스의 속성 경로로 찾습니다. 이름 공간은 이름들이 어떤 객체와 연결되는지 관리하는 영역입니다.

안에 정의했다는 이유만으로 바깥 인스턴스의 속성을 자동으로 읽지는 않습니다. 아래 Status는 독립 인스턴스를 만들고 자신에게 전달한 label을 저장합니다.

Python 코드

Python 3.10+
class Report:
    class Status:
        def __init__(self, label):
            self.label = label

status = Report.Status("작성 중")
print(status.label)
print(isinstance(status, Report.Status))

예제 실행 결과

작성 중
True

검증한 예제의 상태를 순서대로 읽습니다.

    정의

    Report 안에 Status 클래스를 둡니다.

  2. 2

    생성

    Status를 호출해 독립 객체를 만듭니다.

02

바깥 정보를 쓰려면 직접 전달하기

중첩 객체가 바깥 객체를 사용하려면 인자로 전달하는 등 연결을 직접 만들어야 합니다. 아래 Status는 report를 받아 자기 report 속성에 연결합니다.

서로 가리키는 객체가 많아지면 관계를 이해하기 어려워집니다. 단지 제목 문자열만 필요하다면 객체 전체 대신 제목 값만 전달하는 편이 더 단순할 수 있습니다.

Python 코드

Python 3.10+
class Report:
    def __init__(self, title):
        self.title = title
    class Status:
        def __init__(self, report):
            self.report = report
        def summary(self):
            return self.report.title + ": 작성 중"

report = Report("숲 관찰")
status = Report.Status(report)
print(status.summary())

예제 실행 결과

숲 관찰: 작성 중

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    명시적 전달

    report를 Status 생성 인자로 넘깁니다.

  2. 2

    속성 읽기

    status가 저장한 report를 통해 제목을 읽습니다.

03

중첩과 구성을 구별하기

구성은 한 객체가 다른 객체를 속성으로 갖고 함께 사용하는 구조입니다. 클래스 정의가 중첩되었는지와 별개입니다. 중첩은 이름을 어디에 둘지, 구성은 객체를 어떻게 연결할지에 관한 선택입니다.

여러 종류의 보고서에서 같은 상태를 사용할 예정이면 Status를 바깥에 독립 정의하는 편이 찾기 쉬울 수 있습니다. 아래는 중첩 없이도 Report가 Status를 가지는 구성 예제입니다.

Python 코드

Python 3.10+
class Status:
    def __init__(self, label):
        self.label = label

class Report:
    def __init__(self, title, status):
        self.title = title
        self.status = status

report = Report("강 관찰", Status("검토 전"))
print(report.title, report.status.label)

예제 실행 결과

강 관찰 검토 전

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    상태 생성

    검토 전 상태 객체를 만듭니다.

  2. 2

    연결

    그 객체를 report.status에 연결합니다.

원할 때 확인하세요

코드를 읽고, 한 번 예측하기

중첩 클래스의 인스턴스가 바깥 인스턴스를 자동으로 받나요?

정답과 모든 선택지의 해설 읽기
  1. 오답: 항상 자동으로 받습니다.

    Python의 중첩 클래스는 바깥 인스턴스를 자동 연결하지 않습니다.

  2. 오답: 중첩되어 있으면 self가 바깥 인스턴스입니다.

    self는 호출 대상인 현재 인스턴스입니다.

  3. 정답: 필요한 바깥 객체를 직접 전달해야 합니다.

    중첩은 이름 배치이며 객체 간 연결은 명시해야 합니다.

기억할 내용

클래스를 안에 정의해도 바깥 인스턴스가 자동으로 전달되지는 않습니다.
