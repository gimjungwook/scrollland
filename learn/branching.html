상황에 맞는 실행 경로 고르기

관찰 수량이 0인데도 기록이 있다는 안내가 나오면 곤란합니다. 상황에 맞는 문장만 출력하려면 어떻게 할까요?

count = 0→첫 기록을 남겨 주세요

비교식의 답이 참인지 거짓인지 읽을 수 있습니다. 그 답에 따라 실행할 지시를 나누는 방법을 익힙니다.

실행한 줄과 건너뛴 줄을 함께 보며, 분기가 끝난 뒤에는 어느 지시로 돌아오는지 확인합니다.

읽고 나면if·elif·else와 match에서 실행되는 분기를 설명합니다.

먼저 익힐 개념 · 조건을 참과 거짓으로 읽기

01

if와 들여쓰기로 실행 묶기

관찰 수가 있으면 “기록 있음”, 없으면 “첫 기록을 남겨 주세요”를 보여주려 합니다. 두 안내를 모두 출력하는 대신 조건을 검사해 한쪽을 고르는 일이 분기입니다.

if count > 0:은 count가 0보다 클 때만 그 아래 들여쓴 지시를 실행하라는 뜻입니다. 이 예제의 0 > 0은 거짓이므로 “기록 있음”은 출력하지 않고 else 아래의 안내를 출력합니다.

들여쓰기는 같은 실행 묶음에 들어가는 줄을 정합니다. 보통 공백 네 칸을 씁니다. 마지막 print("검사 끝")는 들여쓰지 않았으므로 if·else 묶음 밖에 있으며, 어느 쪽을 골랐든 그 뒤에 실행합니다.

count가 0일 때 실행하지 않는 print()는 어느 것이고, 마지막 print()는 왜 실행될까요?

02

여러 기준 중 하나 선택하기

count가 6일 때 먼저 count == 0을 검사하면 False입니다. 그래서 elif의 count < 5를 검사하지만 이것도 False여서 else의 "충분"을 label에 연결합니다. 이처럼 elif는 앞 조건이 맞지 않을 때 다음 기준을 검사합니다.

연결된 if·elif·else에서는 처음 참인 조건 하나를 선택하고 나머지를 건너뜁니다. 조건이 겹치면 위에 적은 조건이 먼저 기회를 얻으므로 순서가 결과에 영향을 줍니다.

마지막 줄은 값을 두 후보 중에서 고르는 조건식입니다. "계속" if count < 10 else "마침"은 조건이 참이면 "계속", 거짓이면 "마침"이라는 값을 만듭니다. 6은 10보다 작으므로 여기서는 "계속"을 출력합니다. 조건 안에 또 if를 두는 중첩 분기도 가능하지만 필요한 기준을 먼저 문장으로 나누어 보세요.

Pythonbranching.py
01count = 602if count == 0:03    label = "없음"04elif count < 5:05    label = "조금"06else:07    label = "충분"08print(label)09print("계속" if count < 10 else "마침")

03

정해진 값에 따라 나누기

match는 값을 여러 case의 패턴과 비교합니다. 패턴은 일치하는 값의 형태를 적은 것이며, 여기서는 문자열 하나와 비교합니다. case _는 앞의 어떤 경우에도 맞지 않을 때 사용합니다. Python 3.10 이상에서 쓸 수 있습니다.

pass는 아무 동작도 하지 않는 지시입니다. 비어 있는 분기에 형식상 지시가 필요할 때 쓸 수 있으며, 반복을 건너뛰는 continue와는 다릅니다. 아래 skip 분기는 문법 예시이며 현재 값 west에는 실행되지 않습니다.

Pythonbranching.py
01direction = "west"02match direction:03    case "west":04        print("서쪽 길")05    case "skip":06        pass07    case _:08        print("다른 길")
