장면 1

if와 들여쓰기로 실행 묶기

분기는 조건에 따라 실행 경로를 고르는 일입니다. if 뒤 조건이 참이면 콜론 다음의 들여쓴 지시들을 실행합니다. 들여쓰기는 같은 실행 묶음에 속함을 나타내며 보통 공백 네 칸을 씁니다.

else는 if 조건이 거짓일 때 실행합니다. 들여쓰기가 끝난 print("검사 끝")는 어느 경로를 택하든 실행됩니다.

Python 코드

count = 0
if count > 0:
    print("기록 있음")
else:
    print("첫 기록을 남겨 주세요")
print("검사 끝")

장면 2

여러 기준 중 하나 선택하기

elif는 앞 조건이 거짓일 때 다음 조건을 검사합니다. if·elif·else 묶음에서는 처음 참인 경로 하나를 실행하고 나머지를 건너뜁니다. 조건 순서가 결과에 영향을 줍니다.

한 값을 두 후보 중에서 고를 때는 “참일 때 값 if 조건 else 거짓일 때 값”이라는 조건식을 사용할 수 있습니다. 조건 안에 또 if를 두는 중첩 분기도 가능하지만, 우선 서로 겹치지 않는 기준을 드러내세요.

Python 코드

count = 6
if count == 0:
    label = "없음"
elif count < 5:
    label = "조금"
else:
    label = "충분"
print(label)
print("계속" if count < 10 else "마침")

장면 3

정해진 값에 따라 나누기

match는 값을 여러 case의 패턴과 비교합니다. 패턴은 일치하는 값의 형태를 적은 것이며, 여기서는 문자열 하나와 비교합니다. case _는 앞의 어떤 경우에도 맞지 않을 때 사용합니다. Python 3.10 이상에서 쓸 수 있습니다.

pass는 아무 동작도 하지 않는 지시입니다. 비어 있는 분기에 형식상 지시가 필요할 때 쓸 수 있으며, 반복을 건너뛰는 continue와는 다릅니다. 아래 skip 분기는 문법 예시이며 현재 값 west에는 실행되지 않습니다.

Python 코드

direction = "west"
match direction:
    case "west":
        print("서쪽 길")
    case "skip":
        pass
    case _:
        print("다른 길")

서쪽 길

비교할 값: direction → west · 일치한 경우: case "west" · 출력: 서쪽 길
