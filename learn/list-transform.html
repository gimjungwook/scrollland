리스트를 복사하고 정렬하기

backup이라는 이름으로 기록을 보관했는데, backup을 고치자 original도 바뀌었습니다. 복사본을 만든 게 아니었을까요?

backup[0] = 9→original: [9, 2]

리스트의 항목을 바꿀 수 있게 됐습니다. 이제 두 이름이 같은 리스트를 가리키는 경우와 별도 리스트를 만든 경우를 구별합니다.

이름만 추가했을 때와 copy()로 복사했을 때를 비교하고, 원본을 정렬할지 새 결과를 받을지도 선택합니다.

읽고 나면같은 객체 연결·얕은 복사·정렬 결과를 구별합니다.

먼저 익힐 개념 · 리스트의 순서와 항목 바꾸기

01

같은 리스트를 가리키는 이름

별칭은 같은 객체에 연결된 다른 이름입니다. backup = original은 리스트를 복사하지 않습니다. 둘 중 어느 이름으로 항목을 바꿔도 같은 리스트를 읽습니다.

숫자 재대입을 배운 「값에 이름을 연결하기」 레슨과 비교하세요. 여기서는 backup이라는 이름을 재대입한 것이 아니라 backup이 가리키는 리스트의 항목을 변경합니다.

backup으로 첫 항목을 바꿨는데 original에서도 9가 보이는 이유는 무엇일까요?

이름과 객체01 / 03
Pythonlist-transform.py
01original = [4, 2]02backup = original03backup[0] = 904print(original)05print(original is backup)

    original · backup
    [4, 2]

    이 단계의 출력: (표준 출력 없음)

  2. 항목 변경 후

    그 객체의 첫 항목이 9로 바뀝니다.

    original · backup
    [9, 2]

    이 단계의 출력: (표준 출력 없음)

실행 후 관계와 값

[9, 2]

original: 같은 리스트 → [9, 2] · backup: 같은 리스트 → [9, 2]

original과 backup은 같은 리스트를 가리킵니다. backup[0] = 9는 이름을 새 리스트로 옮기지 않고 그 리스트의 첫 항목을 바꿉니다.

original is backup의 True는 두 이름으로 같은 객체를 읽는다는 뜻입니다. 다음 예제에서는 copy()로 별도 리스트를 만든 뒤 결과를 비교합니다.

02

별도 리스트로 복사하기

copy()는 바깥 리스트를 새로 만드는 얕은 복사입니다. 정수 항목을 바꾸는 아래 경우에는 원본이 유지됩니다. 중첩된 리스트는 내부 객체를 공유할 수 있으므로 「중첩된 기록 읽기」 레슨에서 다시 확인합니다.

슬라이스도 새 리스트를 만듭니다. +는 리스트 두 개를 잇는 새 리스트를 만들고, extend()는 여러 항목을 기존 리스트 끝에 추가합니다. append()는 전달한 값 전체를 항목 하나로 추가한다는 차이가 있습니다.

Pythonlist-transform.py
01original = [4, 2]02backup = original.copy()03backup[0] = 904backup.extend([6, 8])05print(original)06print(backup)07print(backup[1:3])

실행 결과

[4, 2]
[9, 2, 6, 8]
[2, 6]
03

원본 정렬과 새 정렬 결과

sorted()는 정렬한 새 리스트를 반환합니다. sort()는 기존 리스트 자체를 정렬하고 None을 반환합니다. reverse=True는 내림차순을 뜻합니다.

숫자 목록을 비교할 때는 원본의 순서가 기록 순서를 뜻하는지 먼저 생각하세요. 원본을 보존해야 하면 sorted()의 결과를 다른 이름에 연결합니다.

Pythonlist-transform.py
01counts = [4, 2, 7]02ordered = sorted(counts)03print(counts)04print(ordered)05counts.sort(reverse=True)06print(counts)

실행 결과

[4, 2, 7]
[2, 4, 7]
[7, 4, 2]

잠깐, 머릿속으로 실행해 보세요.

원본 numbers를 유지하며 정렬 결과를 얻는 식은 무엇인가요?

  1. ordered = numbers.sort()
  2. ordered = numbers
  3. ordered = sorted(numbers)

답을 떠올린 뒤, 아래의 설명과 비교해 보세요.

정답ordered = sorted(numbers)

오답: ordered = numbers.sort()원본을 정렬하며 ordered에는 반환값 None이 연결됩니다.

오답: ordered = numbers정렬도 복사도 하지 않고 같은 객체에 이름을 하나 더 연결합니다.

정답: ordered = sorted(numbers)정렬한 새 리스트를 얻고 원본의 순서를 유지합니다.

기억할 한 가지

대입은 복사가 아니며, 원본 보존이 필요한 변환은 새 리스트로 받습니다.
