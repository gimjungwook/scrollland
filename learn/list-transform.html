같은 리스트를 가리키는 이름

별칭은 같은 객체에 연결된 다른 이름입니다. backup = original은 리스트를 복사하지 않습니다. 둘 중 어느 이름으로 항목을 바꿔도 같은 리스트를 읽습니다.

숫자 재대입을 배운 「값에 이름을 연결하기」 레슨과 비교하세요. 여기서는 backup이라는 이름을 재대입한 것이 아니라 backup이 가리키는 리스트의 항목을 변경합니다.

Python 코드

original = [4, 2]
backup = original
backup[0] = 9
print(original)
print(original is backup)

실행 결과

[9, 2]
True

이름과 객체

original: 같은 리스트 → [9, 2] · backup: 같은 리스트 → [9, 2]

  1. 대입 후

    두 이름이 [4, 2] 객체 하나를 가리킵니다.

    original · backup
    [4, 2]

    이 단계의 출력: (표준 출력 없음)

  2. 항목 변경 후

    그 객체의 첫 항목이 9로 바뀝니다.

    original · backup
    [9, 2]

    이 단계의 출력: (표준 출력 없음)

결과와 관계 확인

original · backup
[9, 2]

별도 리스트로 복사하기

copy()는 바깥 리스트를 새로 만드는 얕은 복사입니다. 정수 항목을 바꾸는 아래 경우에는 원본이 유지됩니다. 중첩된 리스트는 내부 객체를 공유할 수 있으므로 「중첩된 기록 읽기」 레슨에서 다시 확인합니다.

슬라이스도 새 리스트를 만듭니다. +는 리스트 두 개를 잇는 새 리스트를 만들고, extend()는 여러 항목을 기존 리스트 끝에 추가합니다. append()는 전달한 값 전체를 항목 하나로 추가한다는 차이가 있습니다.

Python 코드

original = [4, 2]
backup = original.copy()
backup[0] = 9
backup.extend([6, 8])
print(original)
print(backup)
print(backup[1:3])

실행 결과

[4, 2]
[9, 2, 6, 8]
[2, 6]

값의 구성

원본: [4, 2] 유지 · 복사본: [9, 2, 6, 8]

  1. copy 이후

    바깥 리스트 객체가 두 개입니다.

    original
    [4, 2] · 객체 A
    backup
    [4, 2] · 객체 B

    이 단계의 출력: (표준 출력 없음)

  2. 수정과 확장

    복사본만 바뀝니다.

    original
    [4, 2]
    backup
    [9, 2, 6, 8]

    이 단계의 출력: (표준 출력 없음)

  3. 부분 선택

    위치 1과 2를 새 리스트로 읽습니다.

    backup
    [9, 2, 6, 8]
    backup[1:3]
    [2, 6]

    이 단계의 출력: [4, 2] [9, 2, 6, 8] [2, 6]

결과와 관계 확인

원본 정렬과 새 정렬 결과

sorted()는 정렬한 새 리스트를 반환합니다. sort()는 기존 리스트 자체를 정렬하고 None을 반환합니다. reverse=True는 내림차순을 뜻합니다.

숫자 목록을 비교할 때는 원본의 순서가 기록 순서를 뜻하는지 먼저 생각하세요. 원본을 보존해야 하면 sorted()의 결과를 다른 이름에 연결합니다.

Python 코드

counts = [4, 2, 7]
ordered = sorted(counts)
print(counts)
print(ordered)
counts.sort(reverse=True)
print(counts)

실행 결과

[4, 2, 7]
[2, 4, 7]
[7, 4, 2]

값의 구성

원래 순서: 4, 2, 7 · 새 오름차순: 2, 4, 7 · 원본 내림차순 변경: 7, 4, 2

  1. sorted 이후

    ordered만 정렬되어 있습니다.

    counts
    [4, 2, 7]
    ordered
    [2, 4, 7]

    이 단계의 출력: (표준 출력 없음)

  2. sort 이후

    counts 자체의 순서가 달라집니다.

    counts
    [7, 4, 2]
    ordered
    [2, 4, 7]

    이 단계의 출력: [4, 2, 7] [2, 4, 7]

결과와 관계 확인

counts
[7, 4, 2]
ordered
[2, 4, 7]

원본 numbers를 유지하며 정렬 결과를 얻는 식은 무엇인가요?

답을 떠올린 뒤, 조금 더 내려 보세요.

정답ordered = sorted(numbers)

오답: ordered = numbers.sort()원본을 정렬하며 ordered에는 반환값 None이 연결됩니다.

오답: ordered = numbers정렬도 복사도 하지 않고 같은 객체에 이름을 하나 더 연결합니다.

정답: ordered = sorted(numbers)정렬한 새 리스트를 얻고 원본의 순서를 유지합니다.

기억할 한 가지

대입은 복사가 아니며, 원본 보존이 필요한 변환은 새 리스트로 받습니다.
