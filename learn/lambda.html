짧은 계산을 함수에 전달하기

숫자 4와 함께 두 배로 만들기라는 작업도 함수에 전달하면, 받는 쪽에서는 그 작업을 실행할 수 있을까요?

apply(4, double)→8

함수로 계산을 묶고 기록을 정렬했습니다. 이번에는 함수 자체를 값으로 전달해 호출할 작업이나 정렬 기준을 정합니다.

짧은 계산을 lambda로 표현해 다른 함수에 전달하고, 기록 전체에서 비교할 값만 꺼내는 기준 함수를 읽습니다.

읽고 나면lambda의 입력·표현식과 정렬 기준 함수의 역할을 설명합니다.

먼저 익힐 개념 · 리스트를 복사하고 정렬하기 · 중첩된 기록 읽기 · 필요한 값만 새 묶음으로 만들기 · 계산에 이름을 붙여 재사용하기

01

함수도 값으로 전달하기

함수도 다른 값처럼 이름에 연결하거나 다른 함수에 전달할 수 있습니다. double은 함수 객체를 가리키는 이름이고 double(3)은 그 함수를 실제로 호출하는 표현입니다. 함수를 값처럼 다루는 성질을 일급 함수라고 부릅니다.

lambda n: n * 2는 n을 받아 n * 2의 결과를 반환하는 짧은 함수입니다. def로 쓴 함수의 return n * 2와 같은 계산이지만 lambda에서는 return을 따로 적지 않습니다. 첫 줄은 이 함수를 double에 연결하며 아직 곱셈을 실행하지 않습니다.

apply(4, double)은 숫자 4와 함수 자체를 전달합니다. apply 안에서 value는 4, operation은 double이 가리키는 함수입니다. operation(value)에 도달해야 그 함수가 4를 받아 8을 계산합니다.

이름을 붙여 여러 번 쓰고 설명이나 지시를 더할 함수라면 def가 읽기 쉽습니다. lambda는 아래 정렬 기준처럼 짧은 함수를 다른 지시에 전달할 때 자주 씁니다.

apply(4, double)의 double은 계산 결과 8일까요, 아직 호출할 함수일까요?

apply에 전달한 operation은 double 함수입니다. operation(4)가 반환한 8을 apply도 반환하고, 마지막 print()가 출력합니다.

double처럼 괄호 없이 전달한 것은 함수 자체입니다. 받은 쪽에서 operation(value)로 괄호를 붙여야 계산을 실행합니다.

lambda가 8을 반환해도 화면에 바로 쓰지는 않습니다. apply가 그 8을 다시 반환하고, 가장 바깥 print()가 받은 뒤에야 두 번째 줄이 출력됩니다.

02

정렬 기준만 알려주기

sorted()의 key는 각 항목에서 비교할 값을 구하는 함수입니다. 딕셔너리 목록을 수량순으로 정렬하려면 기록 하나를 받아 count만 돌려주게 합니다.

key 함수는 정렬 결과 항목을 바꾸는 함수가 아닙니다. 비교 기준만 꺼내며, 결과에는 원래 기록 객체들이 정렬된 순서로 들어 있습니다.

숲 기록의 기준 값은 4이고 강 기록의 기준 값은 2입니다. 2가 먼저이므로 ordered에는 강 기록, 숲 기록 순서로 들어갑니다. 마지막 리스트 컴프리헨션이 각 기록의 place만 꺼내므로 출력은 ["강", "숲"]입니다. sorted()의 결과 자체가 [2, 4]로 바뀐 것은 아닙니다.

Pythonlambda.py
01records = [{"place": "숲", "count": 4}, {"place": "강", "count": 2}]02ordered = sorted(records, key=lambda record: record["count"])03print([record["place"] for record in ordered])

실행 결과

['강', '숲']
03

변환과 선택 구별하기

map()은 각 항목에 함수를 적용한 결과를 순서대로 제공하는 반복자를 만듭니다. filter()는 함수의 결과가 참으로 판정되는 항목만 제공하는 반복자를 만듭니다.

두 도구 모두 list()로 소비해 출력할 수 있습니다. 같은 작업을 리스트 컴프리헨션으로 썼을 때 더 읽기 쉽다면 그 표기를 선택하세요. 핵심은 변환인지 선택인지 분명히 하는 것입니다.

map의 n * 2는 1·4·2를 각각 2·8·4로 바꿉니다. filter의 n >= 2는 False·True·True를 판단에만 쓰고 통과한 원래 값 4·2를 내보냅니다. 따라서 filter의 결과가 [True, True]인 것은 아닙니다.

Pythonlambda.py
01counts = [1, 4, 2]02print(list(map(lambda n: n * 2, counts)))03print(list(filter(lambda n: n >= 2, counts)))

실행 결과

[2, 8, 4]
[4, 2]
