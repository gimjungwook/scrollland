01

함수도 값으로 전달하기

함수는 이름에 연결하거나 다른 함수에 전달할 수 있는 객체입니다. 이런 성질을 일급 함수라고 부릅니다. lambda는 표현식 하나의 결과를 반환하는 짧은 함수 표기입니다.

lambda n: n * 2에서 n은 매개변수이고 콜론 뒤가 결과 식입니다. 이름을 붙여 여러 번 쓸 함수라면 def로 쓰면 설명과 여러 지시를 추가하기 쉽습니다.

Python 코드

Python 3.10+
double = lambda n: n * 2
print(double(3))

def apply(value, operation):
    return operation(value)

print(apply(4, double))

예제 실행 결과

6
8

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    첫 호출

    double(3)이 6을 반환합니다.

  2. 2

    함수 전달

    apply가 전달받은 함수를 값 4로 호출합니다.

02

정렬 기준만 알려주기

sorted()의 key는 각 항목에서 비교할 값을 구하는 함수입니다. 딕셔너리 목록을 수량순으로 정렬하려면 기록 하나를 받아 count만 돌려주게 합니다.

key 함수는 정렬 결과 항목을 바꾸는 함수가 아닙니다. 비교 기준만 꺼내며, 결과에는 원래 기록 객체들이 정렬된 순서로 들어 있습니다.

Python 코드

Python 3.10+
records = [{"place": "숲", "count": 4}, {"place": "강", "count": 2}]
ordered = sorted(records, key=lambda record: record["count"])
print([record["place"] for record in ordered])

예제 실행 결과

['강', '숲']

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    기준 계산

    기록별 count 값을 꺼냅니다.

  2. 2

    정렬

    수량 오름차순으로 기록을 배치합니다.

03

변환과 선택 구별하기

map()은 각 항목에 함수를 적용한 결과를 순서대로 제공하는 반복자를 만듭니다. filter()는 함수의 결과가 참으로 판정되는 항목만 제공하는 반복자를 만듭니다.

두 도구 모두 list()로 소비해 출력할 수 있습니다. 같은 작업을 리스트 컴프리헨션으로 썼을 때 더 읽기 쉽다면 그 표기를 선택하세요. 핵심은 변환인지 선택인지 분명히 하는 것입니다.

Python 코드

Python 3.10+
counts = [1, 4, 2]
print(list(map(lambda n: n * 2, counts)))
print(list(filter(lambda n: n >= 2, counts)))

예제 실행 결과

[2, 8, 4]
[4, 2]

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    변환

    map은 모든 항목을 계산 결과로 바꿉니다.

  2. 2

    선택

    filter는 조건에 맞는 원래 항목을 남깁니다.

원할 때 확인하세요

코드를 읽고, 한 번 예측하기

sorted(records, key=lambda r: r["count"])의 key는 무엇을 정하나요?

정답과 모든 선택지의 해설 읽기
  1. 오답: 최종 결과를 숫자 목록으로 바꿉니다.

    결과에는 기록들이 남고 숫자는 비교 기준으로만 사용됩니다.

  2. 정답: 각 기록을 비교할 수량을 구합니다.

    key 함수가 각 항목에서 정렬 기준 값을 꺼냅니다.

  3. 오답: count가 없는 기록을 자동으로 삭제합니다.

    키가 없으면 오류가 나며 자동 필터 기능은 아닙니다.

기억할 내용

lambda는 짧은 표현식 하나를 함수로 만들며, 이름이 있는 def가 더 명확하면 def를 씁니다.
