필요한 값만 새 묶음으로 만들기

수량 [2, 4, 3]을 모두 두 배로 바꾼 새 목록이 필요합니다. 항목마다 반복할 규칙을 한곳에 적을 수 있을까요?

[2, 4, 3]→두 배: [4, 8, 6]

반복으로 값을 꺼내고 조건으로 항목을 고를 수 있습니다. 컴프리헨션은 그 선택과 변환을 새 묶음을 만드는 표현으로 적습니다.

일반 for와 컴프리헨션이 같은 [4, 8, 6]을 만드는지 대조한 뒤, 조건을 붙여 필요한 항목만 남깁니다.

읽고 나면컴프리헨션을 반복·필터·변환의 순서로 해석합니다.

먼저 익힐 개념 · 상황에 맞는 실행 경로 고르기 · 중복과 공통 항목 찾기 · 이름표로 값 찾기 · 모든 항목에 같은 작업 하기

01

변환 결과를 한곳에 모으기

컴프리헨션은 반복한 계산 결과로 새 묶음을 만드는 표기입니다. [count * 2 for count in counts]에서는 먼저 for count in counts로 항목을 하나 받고, 앞의 count * 2를 계산해 새 리스트에 추가합니다. 화면에 적힌 왼쪽부터 계산하는 것은 아닙니다.

count가 2이면 4를, 4이면 8을, 3이면 6을 넣습니다. 이 계산은 counts의 항목을 두 배로 고쳐 쓰지 않습니다. 원본 [2, 4, 3]과 새 결과 [4, 8, 6]이 따로 남습니다.

아래의 일반 for와 append()가 loop_result를 먼저 완성합니다. 이어 같은 규칙의 컴프리헨션이 별도 리스트를 만들고, 항목을 모두 처리한 뒤 doubled에 연결합니다. 리스트를 만드는 도중에는 아직 doubled의 대입이 끝나지 않았습니다.

두 리스트를 계산하는 동안에는 print()가 실행되지 않습니다. 마지막 세 print()가 원본, 일반 반복 결과, 컴프리헨션 결과를 차례로 화면에 남깁니다.

컴프리헨션이 4·8·6을 모으는 동안 원본 counts도 바뀔까요?

counts에서 꺼낸 숫자는 바꾸지 않고, 그 숫자로 계산한 결과를 새 리스트에 넣었습니다. 그래서 원본과 결과를 각각 출력해 비교할 수 있습니다.

컴프리헨션이 짧아져도 항목별 계산 순서는 일반 for와 같습니다. for로 받을 항목 → 결과 식으로 계산할 값 → 새 리스트에 넣을 값 순서로 읽어 보세요.

02

조건에 맞는 항목만 남기기

필터는 조건에 맞는 항목만 통과시키는 과정입니다. 컴프리헨션 끝의 if는 원본의 각 항목이 결과에 들어갈지 결정합니다.

실행할 때는 for로 항목을 받고 if로 거른 뒤 앞의 결과 식을 계산합니다. 아래 -1은 조건을 만족하지 않아 결과에 들어가지 않습니다.

첫 식의 count >= 0에는 0도 통과하므로 valid는 [3, 5, 0]입니다. 다음 식의 count > 0에는 3과 5만 통과하고, 그 뒤 두 배로 계산하므로 [6, 10]입니다. 조건에서 탈락한 -1은 결과 식을 계산하지 않습니다.

Pythoncomprehensions.py
01counts = [3, -1, 5, 0]02valid = [count for count in counts if count >= 0]03print(valid)04print([count * 2 for count in counts if count > 0])

실행 결과

[3, 5, 0]
[6, 10]
03

키가 있는 묶음과 중복 없는 묶음

딕셔너리 컴프리헨션은 {키 식: 값 식 for ...}, 집합 컴프리헨션은 {값 식 for ...} 형태입니다. 중괄호 안에 콜론이 있는지로 구별합니다.

복잡한 중첩 조건이나 여러 부수 작업을 넣기보다는 일반 for로 나누는 편이 읽기 좋을 수 있습니다. 여기서는 짧은 변환 하나만 수행하고 결과를 바로 확인합니다.

딕셔너리에서는 숲·강이라는 키는 그대로 두고 수량만 4→8, 2→4로 계산합니다. 집합에서는 숲과 강의 글자 수가 모두 1이어서 1을 한 번만 남기고, 공원의 글자 수 2를 함께 담습니다. sorted()는 이 집합을 [1, 2] 순서의 리스트로 보여주기 위한 것입니다.

Pythoncomprehensions.py
01counts = {"숲": 4, "강": 2}02doubled = {place: count * 2 for place, count in counts.items()}03lengths = {len(place) for place in ["숲", "강", "공원"]}04print(doubled)05print(sorted(lengths))

실행 결과

{'숲': 8, '강': 4}
[1, 2]

[n * 2 for n in [1, -1, 3] if n > 0]의 결과는 무엇인가요?

  1. [2, -2, 6]
  2. [1, 3]
  3. [2, 6]

답을 떠올린 뒤, 아래의 설명과 비교해 보세요.

정답[2, 6]

오답: [2, -2, 6]-1은 필터 조건 n > 0을 만족하지 못합니다.

오답: [1, 3]남긴 값에는 결과 식 n * 2도 적용됩니다.

정답: [2, 6]1과 3을 남긴 다음 두 배 값을 새 리스트에 모읍니다.

기억할 한 가지

컴프리헨션에서는 반복할 항목, 남길 조건, 결과 값을 순서대로 읽습니다.
