변환 결과를 한곳에 모으기

컴프리헨션은 반복한 결과로 새 묶음을 만드는 표기입니다. [count * 2 for count in counts]는 각 count를 받아 두 배로 계산한 값을 새 리스트에 넣습니다.

아래에서는 먼저 일반 for와 append()로 loop_result를 만들고, 이어서 컴프리헨션으로 doubled를 만듭니다. 출력은 원본 counts, 일반 반복의 결과, 컴프리헨션의 결과 순서입니다. 두 방식의 리스트 결과가 같고 원본은 그대로인지 비교하세요.

Python 코드

counts = [2, 4, 3]
loop_result = []
for count in counts:
    loop_result.append(count * 2)
doubled = [count * 2 for count in counts]
print(counts)
print(loop_result)
print(doubled)

실행 결과

[2, 4, 3]
[4, 8, 6]
[4, 8, 6]

입력에서 결과로

원본은 유지됩니다. 일반 반복과 컴프리헨션은 같은 항목과 순서의 새 리스트를 각각 만듭니다.

  1. 일반 반복

    빈 loop_result에 4, 8, 6을 차례로 추가합니다.

    counts
    [2, 4, 3]
    loop_result
    [4, 8, 6]

    이 단계의 출력: (표준 출력 없음)

  2. 컴프리헨션

    같은 변환 결과를 새 리스트 doubled에 모읍니다.

    counts
    [2, 4, 3]
    doubled
    [4, 8, 6]

    이 단계의 출력: (표준 출력 없음)

  3. 비교

    counts는 [2, 4, 3]이고 두 결과 리스트는 모두 [4, 8, 6]입니다.

    counts
    [2, 4, 3]
    loop_result
    [4, 8, 6]
    doubled
    [4, 8, 6]

    이 단계의 출력: [2, 4, 3] [4, 8, 6] [4, 8, 6]

결과와 관계 확인

[2, 4, 3]
loop_result
[4, 8, 6]
doubled
[4, 8, 6]

조건에 맞는 항목만 남기기

필터는 조건에 맞는 항목만 통과시키는 과정입니다. 컴프리헨션 끝의 if는 원본의 각 항목이 결과에 들어갈지 결정합니다.

실행할 때는 for로 항목을 받고 if로 거른 뒤 앞의 결과 식을 계산합니다. 아래 -1은 조건을 만족하지 않아 결과에 들어가지 않습니다.

Python 코드

counts = [3, -1, 5, 0]
valid = [count for count in counts if count >= 0]
print(valid)
print([count * 2 for count in counts if count > 0])

실행 결과

[3, 5, 0]
[6, 10]

입력에서 결과로

원본: 3, -1, 5, 0 · 0 이상 필터: 3, 5, 0 · 양수만 두 배: 6, 10

  1. 항목 검사

    조건을 만족하는지 먼저 봅니다.

    count >= 0
    3: 참 · -1: 거짓 · 5: 참 · 0: 참
    valid
    [3, 5, 0]

    이 단계의 출력: (표준 출력 없음)

  2. 결과 계산

    남은 항목에만 결과 식을 적용합니다.

    count > 0
    3 · 5 선택
    count * 2
    [6, 10]

    이 단계의 출력: [3, 5, 0] [6, 10]

결과와 관계 확인

counts
[3, -1, 5, 0]
valid
[3, 5, 0]
양수만 두 배로 만든 결과
[6, 10]

키가 있는 묶음과 중복 없는 묶음

딕셔너리 컴프리헨션은 {키 식: 값 식 for ...}, 집합 컴프리헨션은 {값 식 for ...} 형태입니다. 중괄호 안에 콜론이 있는지로 구별합니다.

복잡한 중첩 조건이나 여러 부수 작업을 넣기보다는 일반 for로 나누는 편이 읽기 좋을 수 있습니다. 여기서는 짧은 변환 하나만 수행하고 결과를 바로 확인합니다.

Python 코드

counts = {"숲": 4, "강": 2}
doubled = {place: count * 2 for place, count in counts.items()}
lengths = {len(place) for place in ["숲", "강", "공원"]}
print(doubled)
print(sorted(lengths))

실행 결과

{'숲': 8, '강': 4}
[1, 2]

값의 구성

딕셔너리 결과: 숲 → 8, 강 → 4 · 집합 결과: 글자 수 1과 2

  1. 키·값 변환

    키를 유지하고 수량만 두 배로 만듭니다.

    counts
    숲: 4 · 강: 2
    doubled
    숲: 8 · 강: 4

    이 단계의 출력: (표준 출력 없음)

  2. 중복 제거

    두 번 나온 길이 1은 한 항목으로 남습니다.

    글자 수
    1 · 1 · 2
    lengths
    1 · 2 (중복 없음)

    이 단계의 출력: (표준 출력 없음)

결과와 관계 확인

counts
숲: 4 · 강: 2
doubled
숲: 8 · 강: 4
lengths
1 · 2 (중복 없음)

[n * 2 for n in [1, -1, 3] if n > 0]의 결과는 무엇인가요?

답을 떠올린 뒤, 조금 더 내려 보세요.

정답[2, 6]

오답: [2, -2, 6]-1은 필터 조건 n > 0을 만족하지 못합니다.

오답: [1, 3]남긴 값에는 결과 식 n * 2도 적용됩니다.

정답: [2, 6]1과 3을 남긴 다음 두 배 값을 새 리스트에 모읍니다.

기억할 한 가지

컴프리헨션에서는 반복할 항목, 남길 조건, 결과 값을 순서대로 읽습니다.
