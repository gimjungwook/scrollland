01

키와 값의 관계 만들기

딕셔너리 dict는 키로 값을 찾는 묶음입니다. 키는 값을 식별하는 이름표이고, 각 키는 값 하나에 연결됩니다. 중괄호 안에 키: 값 형태로 적습니다.

키는 문자열·정수처럼 해시 가능한 값이어야 합니다. 해시 가능은 저장 중 비교와 검색에 쓸 식별값이 안정적으로 유지된다는 뜻입니다. 변경 가능한 리스트는 키로 쓸 수 없습니다.

Python 코드

Python 3.10+
counts = {"숲": 4, "강": 2}
print(counts["강"])
print("숲" in counts)
print(len(counts))

예제 실행 결과

2
True
2

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    매핑 생성

    장소 이름 두 개에 수량을 연결합니다.

  2. 2

    검색

    강이라는 키로 값 2를 찾습니다.

02

없는 키에 응답하기

counts["못"]처럼 없는 키를 직접 읽으면 KeyError라는 예외가 납니다. get()은 키가 없을 때 사용할 기본값을 함께 지정할 수 있습니다.

get()이 기본값을 돌려줘도 딕셔너리에 그 키를 추가하지는 않습니다. in은 값이 아닌 키의 포함 여부를 확인하므로 실제 등록 여부를 따로 확인할 수 있습니다.

Python 코드

Python 3.10+
counts = {"숲": 4}
print(counts.get("못", 0))
print("못" in counts)
print(counts.get("숲", 0))

예제 실행 결과

0
False
4

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    기본값 조회

    못이 없으므로 0을 반환합니다.

  2. 2

    등록 여부 확인

    못은 여전히 딕셔너리에 없습니다.

03

같은 키를 갱신하기

키에 대입하면 기존 키의 값을 바꾸거나 새 키를 추가합니다. update()는 여러 키·값을 한 번에 반영합니다. pop()은 키를 제거하고 그 값을 반환합니다.

keys()는 키들을, values()는 값들을, items()는 키·값 쌍을 보여주는 뷰를 만듭니다. 뷰는 원본 딕셔너리의 변경을 반영하는 조회 대상입니다. 예제에서는 list()로 현재 항목을 한 번 모아 출력합니다.

Python 코드

Python 3.10+
counts = {"숲": 4, "강": 2}
counts["숲"] = 5
counts.update({"못": 3})
removed = counts.pop("강")
print(removed)
print(list(counts.items()))

예제 실행 결과

2
[('숲', 5), ('못', 3)]

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    변경 전

    숲 4, 강 2

  2. 2

    추가와 수정

    숲 5, 강 2, 못 3

  3. 3

    제거 후

    숲 5, 못 3

원할 때 확인하세요

코드를 읽고, 한 번 예측하기

scores.get("못", 0)은 못 키가 없을 때 무엇을 하나요?

정답과 모든 선택지의 해설 읽기
  1. 정답: 0을 반환하지만 키를 추가하지 않습니다.

    get()은 조회이며 딕셔너리를 수정하지 않습니다.

  2. 오답: 못: 0을 자동으로 추가합니다.

    추가하려면 키에 직접 대입해야 합니다.

  3. 오답: 항상 KeyError를 냅니다.

    직접 키 접근과 달리 get()은 기본값을 반환할 수 있습니다.

기억할 내용

딕셔너리는 위치 대신 키로 값을 찾습니다. 같은 키의 값은 하나입니다.
