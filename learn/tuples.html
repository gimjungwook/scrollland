정해진 역할의 묶음

튜플은 순서가 있으면서 항목을 바꿀 수 없는 묶음입니다. 아래 두 숫자는 각각 가로와 세로 좌표를 뜻합니다. 인덱스와 len()은 리스트처럼 사용할 수 있습니다.

튜플을 만드는 핵심은 쉼표입니다. 항목 하나인 (3,)과 단순 괄호 식 (3)은 다릅니다. 불변이라는 말은 튜플 내부 항목이 가리키는 변경 가능한 객체까지 고정한다는 뜻은 아닙니다.

Python 코드

point = (3, 8)
single = (3,)
print(point[0])
print(len(single))
print(type((3)))

실행 결과

3
1
<class 'int'>

값의 구성

좌표 튜플: 가로 3, 세로 8 · 한 항목 튜플: (3,)

  1. 묶음 생성

    쉼표로 두 값을 튜플로 묶습니다.

    point
    (3, 8)

    이 단계의 출력: (표준 출력 없음)

  2. 형태 비교

    (3)은 정수이고 (3,)은 튜플입니다.

    single
    (3,) · tuple
    (3)
    3 · int

    이 단계의 출력: 3 1 <class 'int'>

이름으로 나누어 받기

언패킹은 묶음의 각 항목을 여러 이름에 나누어 연결하는 일입니다. x, y = point는 순서대로 첫 값과 두 번째 값을 받습니다.

별표를 붙인 이름은 남는 여러 항목을 리스트로 받습니다. 아래에서는 first와 last 사이의 항목들을 middle에 모읍니다. 별표가 없으면 이름 수와 항목 수가 맞아야 합니다.

Python 코드

point = (3, 8)
x, y = point
first, *middle, last = (2, 4, 6, 8)
print(x, y)
print(middle)

실행 결과

3 8
[4, 6]

이름과 객체

point의 분해: x → 3, y → 8 · 남는 항목: middle → [4, 6]

    두 이름이 두 항목을 하나씩 받습니다.

    이 단계의 출력: (표준 출력 없음)

바꿔야 할 때 새 튜플 만들기

튜플의 항목에 직접 대입할 수는 없지만 새 튜플을 만들어 이름을 다시 연결할 수 있습니다. list()와 tuple()로 묶음 종류를 변환할 수 있습니다.

두 튜플을 +로 이으면 새 튜플이 생깁니다. 아래 원래 좌표 point는 그대로이고, 수정할 때 쓴 리스트가 바뀐 뒤 updated라는 새 튜플을 만듭니다.

Python 코드

point = (3, 8)
editable = list(point)
editable[0] = 5
updated = tuple(editable)
print(point)
print(updated)
print(updated + (1,))

실행 결과

(3, 8)
(5, 8)
(5, 8, 1)

입력에서 결과로

원본 튜플: (3, 8) · 중간 리스트: [5, 8] · 새 튜플: (5, 8)

  1. 변환

    수정 가능한 리스트를 만듭니다.

    point
    (3, 8)
    editable
    [3, 8]

    이 단계의 출력: (표준 출력 없음)

  2. 수정 후 재구성

    바뀐 리스트에서 새 튜플을 만듭니다.

    point
    (3, 8)
    editable
    [5, 8]
    updated
    (5, 8)

    이 단계의 출력: (표준 출력 없음)

결과와 관계 확인

point
(3, 8)
editable
[5, 8]
updated
(5, 8)
이어 붙인 결과

항목 하나가 정수 5인 튜플은 어느 것인가요?

답을 떠올린 뒤, 조금 더 내려 보세요.

정답(5,)

오답: (5)괄호만 있으면 정수 5입니다.

정답: (5,)항목이 하나여도 쉼표를 적으면 튜플이 됩니다.

오답: [5]대괄호는 리스트를 만듭니다.

기억할 한 가지

튜플은 항목 연결을 바꾸지 않는 순서 묶음이며, 쉼표가 튜플을 만듭니다.
