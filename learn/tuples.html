한 묶음의 의미를 고정하기

좌표 (3, 8)에서 앞의 수와 뒤의 수는 역할이 다릅니다. 두 수를 묶어 전달하면서 그 순서를 유지하려면 어떻게 할까요?

x, y = (3, 8)→x: 3 · y: 8

항목을 바꾸는 리스트를 배웠습니다. 튜플은 정해진 항목의 연결을 유지하는 묶음이며, 각 항목을 이름으로 나누어 받을 수 있습니다.

좌표를 x와 y로 꺼내고, 값을 바꿔야 할 때에는 원래 튜플과 새 튜플을 구별해 만듭니다.

읽고 나면튜플의 불변성과 언패킹을 설명하고 항목을 꺼냅니다.

먼저 익힐 개념 · 리스트의 순서와 항목 바꾸기

01

정해진 역할의 묶음

튜플은 순서가 있으면서 항목을 바꿀 수 없는 묶음입니다. 아래 두 숫자는 각각 가로와 세로 좌표를 뜻합니다. 인덱스와 len()은 리스트처럼 사용할 수 있습니다.

튜플을 만드는 핵심은 쉼표입니다. 항목 하나인 (3,)과 단순 괄호 식 (3)은 다릅니다. 불변이라는 말은 튜플 내부 항목이 가리키는 변경 가능한 객체까지 고정한다는 뜻은 아닙니다.

Pythontuples.py
01point = (3, 8)02single = (3,)03print(point[0])04print(len(single))05print(type((3)))

실행 결과

3
1
<class 'int'>
02

이름으로 나누어 받기

언패킹은 묶음의 각 항목을 여러 이름에 나누어 연결하는 일입니다. x, y = point는 순서대로 첫 값과 두 번째 값을 받습니다.

별표를 붙인 이름은 남는 여러 항목을 리스트로 받습니다. 아래에서는 first와 last 사이의 항목들을 middle에 모읍니다. 별표가 없으면 이름 수와 항목 수가 맞아야 합니다.

Pythontuples.py
01point = (3, 8)02x, y = point03first, *middle, last = (2, 4, 6, 8)04print(x, y)05print(middle)

실행 결과

3 8
[4, 6]
03

바꿔야 할 때 새 튜플 만들기

튜플의 항목에 직접 대입할 수는 없지만 새 튜플을 만들어 이름을 다시 연결할 수 있습니다. list()와 tuple()로 묶음 종류를 변환할 수 있습니다.

두 튜플을 +로 이으면 새 튜플이 생깁니다. 아래 원래 좌표 point는 그대로이고, 수정할 때 쓴 리스트가 바뀐 뒤 updated라는 새 튜플을 만듭니다.

Pythontuples.py
01point = (3, 8)02editable = list(point)03editable[0] = 504updated = tuple(editable)05print(point)06print(updated)07print(updated + (1,))

실행 결과

(3, 8)
(5, 8)
(5, 8, 1)

잠깐, 머릿속으로 실행해 보세요.

항목 하나가 정수 5인 튜플은 어느 것인가요?

  1. (5)
  2. (5,)
  3. [5]

답을 떠올린 뒤, 아래의 설명과 비교해 보세요.

정답(5,)

오답: (5)괄호만 있으면 정수 5입니다.

정답: (5,)항목이 하나여도 쉼표를 적으면 튜플이 됩니다.

오답: [5]대괄호는 리스트를 만듭니다.

기억할 한 가지

튜플은 항목 연결을 바꾸지 않는 순서 묶음이며, 쉼표가 튜플을 만듭니다.
