01

이번 항목만 건너뛰기

continue는 현재 반복의 남은 지시를 건너뛰고 다음 반복으로 이동합니다. 아래에서는 음수인 기록을 제외하고 0 이상의 수만 더합니다.

for에서는 다음 항목을 받지만 while에서는 조건 검사로 돌아갑니다. while의 값 갱신이 continue 아래에 있으면 갱신을 건너뛰어 끝나지 않을 수 있습니다.

Python 코드

Python 3.10+
total = 0
for count in [3, -1, 2]:
    if count < 0:
        continue
    total += count
print(total)

예제 실행 결과

5

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    정상 항목

    3을 더합니다.

  2. 2

    잘못된 항목

    -1은 continue로 누적하지 않습니다.

  3. 3

    다음 항목

    2를 더해 5가 됩니다.

02

발견한 순간 검색 끝내기

break는 현재 속한 가장 안쪽 반복을 즉시 끝냅니다. 다음 항목을 읽지 않고 반복 바깥의 다음 지시로 이동합니다.

아래에서는 첫 번째로 5 이상인 수 7을 찾습니다. 그 뒤의 9는 확인하지 않습니다. 따라서 “첫 번째 일치”를 구하는 문제에 맞는 흐름입니다.

Python 코드

Python 3.10+
found = None
for count in [2, 7, 9]:
    if count >= 5:
        found = count
        break
print(found)

예제 실행 결과

7

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    2 확인

    계속 검색합니다.

  2. 2

    7 확인

    found=7로 대입하고 반복을 종료합니다.

03

끝까지 못 찾은 경우 처리하기

반복문의 else는 break 없이 반복이 정상적으로 끝났을 때 실행됩니다. if의 else와 들여쓰기 위치가 다르다는 점에 주의하세요.

검색 대상이 처음부터 비어 있어도 break가 없으므로 else는 실행됩니다. 아래처럼 찾은 값이 없을 때만 안내를 남길 수 있습니다.

Python 코드

Python 3.10+
for place in ["숲", "강"]:
    if place == "못":
        print("찾음")
        break
else:
    print("못 기록 없음")

예제 실행 결과

못 기록 없음

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    전체 검사

    두 장소 모두 못과 다릅니다.

  2. 2

    정상 종료

    항목을 끝까지 읽었으므로 else를 실행합니다.

원할 때 확인하세요

코드를 읽고, 한 번 예측하기

반복 도중 break가 실행되면 반복문에 붙은 else는 실행되나요?

정답과 모든 선택지의 해설 읽기
  1. 오답: 실행됩니다.

    반복문의 else는 break 없이 끝난 경우에 실행됩니다.

  2. 정답: 실행되지 않습니다.

    break는 반복문 else까지 건너뛰고 반복 바깥으로 이동합니다.

  3. 오답: 마지막 항목일 때만 실행됩니다.

    어느 항목에서든 break가 실행되면 else는 실행되지 않습니다.

기억할 내용

continue는 현재 반복의 나머지를 건너뛰고, break는 가장 안쪽 반복을 끝냅니다.
