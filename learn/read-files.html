저장된 파일에서 기록 읽기

어제 적은 숲:4와 강:2가 파일에 있습니다. 오늘 프로그램에 같은 내용을 다시 입력하지 않고 읽어 올 수 있을까요?

observations.txt→내용: 숲:4 · 강:2

모듈을 불러오고 여러 항목을 반복 처리했습니다. 이제 프로그램 바깥 파일의 경로와 글자 해석 방법을 지정해 기록을 가져옵니다.

파일 전체와 한 줄씩 읽기를 비교합니다. 읽은 내용과 파일의 열림·닫힘 상태, 글자 수와 바이트 수도 구별합니다.

읽고 나면경로·텍스트 인코딩·읽기 범위·자동 닫기를 설명합니다.

먼저 익힐 개념 · 모든 항목에 같은 작업 하기 · 모듈을 불러와 연결하기

01

출력 뒤에도 기록을 남기려면

지금까지의 출력은 실행 결과를 읽는 통로였습니다. 프로그램이 끝난 뒤에도 다른 실행에서 기록을 다시 읽으려면 파일에 저장한 글과 그 파일의 위치를 알아야 합니다.

이번 예제는 준비한 파일을 읽습니다. 파일 경로, 글자를 해석하는 규칙, 열린 파일을 닫는 시점을 차례로 구별하겠습니다.

02

파일 위치와 글자 해석 정하기

경로는 파일이 어디에 있는지 나타내는 값입니다. 상대 경로 observations.txt는 실행 중인 작업 폴더를 기준으로 찾습니다. 예제에 제공된 같은 이름의 파일을 작업 폴더에 준비하세요.

인코딩은 글자와 바이트를 바꾸는 규칙입니다. UTF-8은 한글을 표현할 수 있는 인코딩입니다. Path.read_text(encoding="utf-8")는 파일을 읽고 닫은 뒤 문자열을 반환합니다. 파일이 없으면 FileNotFoundError가 발생합니다.

Path("observations.txt")는 파일의 위치를 나타낼 뿐 아직 내용을 읽지 않습니다. read_text를 호출한 다음에야 text에 "숲:4\n강:2\n" 문자열이 들어옵니다. 마지막 print의 end=""는 파일 내용에 이미 있는 마지막 줄바꿈 외에 하나를 더 붙이지 않게 합니다.

03

한 줄씩 읽고 자동으로 닫기

파일 전체를 한 번에 읽지 않고 각 줄에 번호를 붙여 출력해 보겠습니다. open(..., "r", ...)은 읽기용 파일 객체를 만들며 as source는 그 객체에 source라는 이름을 붙입니다. source는 파일 내용 전체를 담은 문자열과는 다릅니다.

with는 구간을 나갈 때 정리 동작을 보장하는 문법입니다. open()으로 연 파일은 with 구간이 끝날 때 닫히며, 중간에 예외가 나도 닫기 처리를 수행합니다.

파일 객체를 for로 반복하면 한 줄씩 읽습니다. 줄 끝의 줄바꿈은 포함되므로 rstrip("\n")으로 줄바꿈만 제거합니다. strip()은 필요한 앞뒤 공백까지 지울 수 있어 의도에 맞게 선택하세요.

enumerate(source, start=1)는 읽은 줄에 1부터 번호를 붙입니다. 첫 차례의 number는 1, line은 줄바꿈을 포함한 "숲:4\n"입니다. 다음 차례에는 2와 "강:2\n"으로 바뀝니다. rstrip("\n")은 출력 전에 끝의 줄바꿈을 떼고, print가 새 줄바꿈을 붙입니다.

두 줄을 읽는 동안과 with 바깥에서 source.closed는 어떻게 달라질까요?

줄을 읽을 때마다 번호와 내용은 바뀌고, 파일은 with를 나간 뒤에만 닫힙니다.

첫 줄을 읽은 뒤 파일은 계속 열려 있으므로 두 번째 줄을 읽을 수 있습니다. 읽을 줄이 끝나고 with의 들여쓴 구간을 나갈 때 파일 객체가 닫힙니다.

닫기는 source의 사용을 마치는 일이며 파일을 삭제하는 일이 아닙니다. 이미 읽은 마지막 line과 number, 화면에 출력한 두 줄도 사라지지 않습니다.

04

문자 수와 바이트 수 구별하기

바이트는 파일에 저장하는 데이터의 단위입니다. 텍스트 모드는 바이트를 글자로 해석하고, 이진 모드 rb는 해석하지 않은 bytes를 읽습니다. 한글 한 글자가 여러 바이트를 사용할 수 있습니다.

read(1)은 텍스트 모드에서 문자 하나를, 이진 모드에서 바이트 하나를 읽습니다. readline()은 다음 한 줄을 읽습니다. 아래에서는 같은 파일을 텍스트 모드와 이진 모드로 각각 읽어 길이를 비교합니다.

place.txt에는 글자 숲 하나가 있습니다. UTF-8로 표현한 파일 바이트는 세 개이므로 len(text)는 1, len(raw)는 3입니다. raw.decode("utf-8")가 그 세 바이트를 같은 규칙으로 해석하면 다시 숲이라는 문자열이 됩니다.

01with open("place.txt", "r", encoding="utf-8") as source:02    text = source.read()03with open("place.txt", "rb") as source:04    raw = source.read()05print(len(text))06print(len(raw))07print(raw.decode("utf-8"))
