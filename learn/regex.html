01

부분 검색과 전체 검사

정규 표현식은 문자열에서 찾을 모양을 규칙으로 적은 패턴입니다. re 모듈의 search()는 어딘가에서 일치하는 부분을 찾고 fullmatch()는 문자열 전체가 패턴에 맞는지 확인합니다.

[0-9]는 숫자 한 자리, {3}은 바로 앞 규칙의 세 번 반복입니다. r로 시작하는 원시 문자열은 역슬래시를 Python 문자열 단계에서 대부분 그대로 유지해 패턴을 적기 편하게 합니다.

Python 코드

Python 3.10+
import re

pattern = r"OBS-[0-9]{3}"
print(re.search(pattern, "코드 OBS-027 확인") is not None)
print(re.fullmatch(pattern, "OBS-027") is not None)
print(re.fullmatch(pattern, "앞 OBS-027") is not None)

False

02

찾은 결과에서 일부 꺼내기

매치 객체는 패턴에 일치한 결과를 나타냅니다. search()가 못 찾으면 None이므로 먼저 확인해야 group()을 안전하게 호출할 수 있습니다.

괄호로 패턴 일부를 묶으면 그룹이 됩니다. group(0)은 전체 일치 부분이고 group(1)은 첫 괄호 부분입니다. findall()은 모든 일치 결과를 리스트로 모읍니다. +는 바로 앞 규칙을 한 번 이상 반복하므로 [0-9]+는 연속된 숫자 덩어리를 찾습니다. 따라서 12를 두 자리의 별도 결과가 아니라 한 덩어리로 읽습니다.

Python 코드

Python 3.10+
import re

match = re.search(r"OBS-([0-9]{3})", "기록 OBS-027")
if match is not None:
    print(match.group(0))
    print(match.group(1))
print(re.findall(r"[0-9]+", "숲 12, 강 3"))

예제 실행 결과

['12', '3']

03

일치 부분만 치환하기

sub()는 패턴에 맞는 부분을 다른 문자열로 바꿉니다. 숫자 덩어리를 찾을 때 배운 + 규칙을 여기서는 일반 공백에 적용합니다. 패턴 r" +"는 일반 공백 하나 이상이 이어진 부분을 찾습니다.

단순 고정 문자열 교체는 replace()로 충분합니다. 여러 가능한 모양을 같은 규칙으로 찾아야 할 때 정규 표현식을 사용하세요. 복잡한 문서 전체를 무리하게 한 패턴으로 해석하지 마세요.

Python 코드

Python 3.10+
import re

text = "숲   관찰  기록"
cleaned = re.sub(r" +", " ", text)
print(cleaned)
print(text)

예제 실행 결과

코드를 읽고, 한 번 예측하기

입력 전체가 OBS- 뒤 숫자 세 자리인지 확인하려면 무엇을 쓰나요?

정답과 모든 선택지의 해설 읽기
  1. 오답: re.search()만 쓰면 충분합니다.

    search()는 앞뒤에 다른 글이 있어도 일부가 맞으면 성공합니다.

  2. 정답: re.fullmatch()를 씁니다.

    fullmatch()는 입력 전체가 패턴에 맞는지 확인합니다.

  3. 오답: re.sub()로 지웁니다.

    sub()는 일치 부분을 바꾸는 함수이며 형식 검증과 목적이 다릅니다.
