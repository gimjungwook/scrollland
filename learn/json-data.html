01

객체를 JSON 문자열로 바꾸기

JSON은 문자열·숫자·불리언·null·배열·객체를 표현하는 데이터 교환용 텍스트 형식입니다. Python의 dict와 list를 json.dumps()로 JSON 문자열로 바꾸는 일을 직렬화라고 합니다.

ensure_ascii=False는 한글을 이스케이프 표기 대신 읽을 수 있는 글로 남깁니다. 결과 text는 딕셔너리가 아닌 문자열이므로 키로 접근하기 전에 다시 읽어야 합니다.

Python 코드

Python 3.10+
import json

record = {"place": "숲", "count": 4}
text = json.dumps(record, ensure_ascii=False)
print(text)
print(type(text))

예제 실행 결과

{"place": "숲", "count": 4}
<class 'str'>

02

텍스트에서 객체 복원하기

json.loads()는 JSON 문자열을 Python 객체로 읽는 역직렬화 함수입니다. JSON의 true와 false는 Python의 True와 False, null은 None으로 읽힙니다.

JSON은 키에 큰따옴표를 사용합니다. Python 딕셔너리의 출력처럼 작은따옴표를 쓰거나 True를 적은 글을 그대로 JSON이라고 간주하면 안 됩니다.

Python 코드

Python 3.10+
import json

text = '{"place":"강","confirmed":true,"note":null}'
record = json.loads(text)
print(record["place"])
print(record["confirmed"])
print(record["note"] is None)

예제 실행 결과

강
True
True

03

왕복해도 모든 자료형이 같지는 않기

JSON 배열은 loads()에서 리스트가 됩니다. Python 튜플을 dumps()로 쓰면 JSON 배열이 되므로 다시 읽었을 때 튜플로 돌아오지는 않습니다. 집합은 기본 설정으로 JSON에 바로 쓸 수 없습니다.

서로 주고받을 데이터의 구조와 키 이름을 정해야 합니다. JSON은 단지 형식을 읽게 해 줄 뿐, count가 허용한 수량인지 같은 업무 규칙까지 확인하지 않습니다.

isinstance(값, 자료형)은 그 값이 지정한 자료형에 속하는지 확인하는 내장 함수입니다. 여기서는 restored["place"]가 문자열을 나타내는 str 자료형인지 검사하므로 True가 나옵니다.

Python 코드

Python 3.10+
import json

record = {"counts": (2, 4), "place": "숲"}
restored = json.loads(json.dumps(record, ensure_ascii=False))
print(restored["counts"])
print(type(restored["counts"]))
print(isinstance(restored["place"], str))

예제 실행 결과

[2, 4]
<class 'list'>
True

정답과 모든 선택지의 해설 읽기
  1. 오답: dict

    딕셔너리는 입력 객체일 수 있지만 dumps()는 텍스트를 만듭니다.

  2. 정답: str

    JSON 형식으로 적힌 문자열이 반환됩니다.

  3. 오답: 파일

    dumps()는 파일을 만들지 않습니다. 파일 저장은 별도 단계입니다.

기억할 내용

JSON은 텍스트 형식이며, Python 딕셔너리 그 자체가 아닙니다.
