다른 도구에서도 읽을 수 있는 기록 만들기

Python의 딕셔너리를 다른 프로그램에 전달하려 합니다. 화면에 보이는 모양만 복사하면 같은 자료가 될까요?

Python: {"counts": (2, 4)}→왕복 후 counts: [2, 4]

여러 값을 중첩해 담고 모듈을 불러왔습니다. JSON은 그 기록을 프로그램 사이에서 읽을 수 있는 텍스트 형식으로 표현합니다.

객체를 문자열로 바꾸고 다시 복원합니다. true와 True의 차이, 왕복할 때 튜플이 리스트가 되는 경우도 확인합니다.

읽고 나면JSON 문자열과 Python 객체를 구분해 직렬화·역직렬화합니다.

먼저 익힐 개념 · 중첩된 기록 읽기 · 모듈을 불러와 연결하기

01

객체를 JSON 문자열로 바꾸기

Python 딕셔너리의 값은 Python 프로그램 안에서 바로 꺼낼 수 있습니다. 다른 프로그램에도 같은 기록을 보내려면 양쪽이 읽을 수 있는 글 형식이 필요합니다. JSON은 문자열·숫자·불리언·null·배열·객체를 나타내는 데이터 교환용 텍스트 형식입니다.

json.dumps(record)는 딕셔너리 내용을 JSON 규칙에 맞는 한 문자열로 만듭니다. 이 변환을 직렬화라고 합니다. 원래 record는 딕셔너리로 남고 새 text가 문자열입니다. 아직 파일에 쓰거나 어디로 전송하지는 않습니다.

ensure_ascii=False는 한글을 \u 형태의 표기 대신 읽을 수 있는 글자로 남깁니다. 출력이 중괄호와 키로 보여도 text 자체는 문자열입니다. text["count"]처럼 딕셔너리인 것처럼 사용하려면 먼저 다음 예제의 loads()로 읽어야 합니다.

중괄호가 그대로 보이는데 dumps() 뒤의 text는 왜 딕셔너리가 아닐까요?

딕셔너리와 JSON 문자열은 같은 기록을 담지만 사용할 수 있는 동작과 자료형이 다릅니다.

dumps는 record를 없애거나 문자열로 바꾸지 않습니다. record는 계속 딕셔너리이고, text라는 다른 이름이 JSON 문자열을 가리킵니다.

마지막 <class 'str'>가 text의 자료형을 보여 줍니다. JSON 문자열은 저장·전송할 글이며, 값을 키로 읽으려면 loads로 Python 객체를 만듭니다.

02

텍스트에서 객체 복원하기

json.loads()는 JSON 문자열을 Python 객체로 읽는 역직렬화 함수입니다. JSON의 true와 false는 Python의 True와 False, null은 None으로 읽힙니다.

JSON은 키에 큰따옴표를 사용합니다. Python 딕셔너리의 출력처럼 작은따옴표를 쓰거나 True를 적은 글을 그대로 JSON이라고 간주하면 안 됩니다.

입력 text에는 소문자 true와 null이 글자로 적혀 있습니다. loads가 읽은 뒤 record["confirmed"]는 Python의 True, record["note"]는 None이 됩니다. 마지막 출력 True는 note가 비어 있음을 is None으로 확인한 결과입니다.

Pythonjson-data.py
01import json02 03text = '{"place":"강","confirmed":true,"note":null}'04record = json.loads(text)05print(record["place"])06print(record["confirmed"])07print(record["note"] is None)

03

왕복해도 모든 자료형이 같지는 않기

JSON 배열은 loads()에서 리스트가 됩니다. Python 튜플을 dumps()로 쓰면 JSON 배열이 되므로 다시 읽었을 때 튜플로 돌아오지는 않습니다. 집합은 기본 설정으로 JSON에 바로 쓸 수 없습니다.

서로 주고받을 데이터의 구조와 키 이름을 정해야 합니다. JSON은 단지 형식을 읽게 해 줄 뿐, count가 허용한 수량인지 같은 업무 규칙까지 확인하지 않습니다.

isinstance(값, 자료형)은 그 값이 지정한 자료형에 속하는지 확인하는 내장 함수입니다. 여기서는 restored["place"]가 문자열을 나타내는 str 자료형인지 검사하므로 True가 나옵니다.

4행은 안쪽 dumps를 먼저 실행한 뒤 그 문자열을 바깥 loads에 넘깁니다. (2, 4)는 JSON 배열 [2, 4]로 적히고, 다시 읽을 때 리스트가 됩니다. 원래 record의 튜플까지 바뀌지는 않습니다.

Pythonjson-data.py
01import json02 03record = {"counts": (2, 4), "place": "숲"}04restored = json.loads(json.dumps(record, ensure_ascii=False))05print(restored["counts"])06print(type(restored["counts"]))07print(isinstance(restored["place"], str))

실행 결과

<class 'list'>
True
