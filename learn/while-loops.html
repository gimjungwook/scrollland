01

실행 전에 조건 검사하기

while은 조건이 참인 동안 들여쓴 지시를 반복합니다. for가 항목을 하나씩 받는 것과 달리, while은 반복할지를 조건식으로 직접 결정합니다.

아래에서는 collected가 목표 6보다 작은 동안 2씩 늘립니다. 조건 검사는 본문 실행 전에 일어나므로 처음부터 조건이 거짓이면 본문을 한 번도 실행하지 않습니다.

Python 코드

Python 3.10+
collected = 0
while collected < 6:
    collected += 2
    print(collected)

예제 실행 결과

2
4
6

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    1회

    0에서 2로 증가합니다.

  2. 2

    2회

    2에서 4로 증가합니다.

  3. 3

    3회 이후

    6이 된 다음 조건 검사에서 멈춥니다.

02

누적값과 반복 횟수 분리하기

누적은 반복할 때마다 값을 더해 현재까지의 결과를 유지하는 방식입니다. total은 누적 결과이고 step은 다음에 더할 수입니다. 서로 역할이 다른 상태를 별도 이름으로 관리합니다.

반복 본문의 지시 순서를 바꾸면 다른 수를 더할 수 있습니다. 여기서는 step을 더한 뒤 다음 값으로 증가시킵니다.

Python 코드

Python 3.10+
step = 1
total = 0
while step <= 3:
    total += step
    step += 1
print(total)
print(step)

예제 실행 결과

6
4

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    첫 누적

    total=1, step=2

  2. 2

    둘째 누적

    total=3, step=3

  3. 3

    셋째 누적

    total=6, step=4, 반복 종료

03

끝나는 이유를 확인하기

무한 반복은 종료 조건이 계속 참으로 남아 끝나지 않는 반복입니다. while remaining > 0인데 remaining을 줄이지 않으면 같은 조건을 계속 검사할 수 있습니다.

종료를 설명할 때는 “무엇이 어떤 방향으로 바뀌는가”와 “언제 조건이 거짓이 되는가”를 함께 확인하세요. 아래에서는 남은 시도 수가 매번 1씩 줄어 결국 0이 됩니다.

Python 코드

Python 3.10+
remaining = 3
while remaining > 0:
    print("남은 시도", remaining)
    remaining -= 1
print("종료", remaining)

예제 실행 결과

남은 시도 3
남은 시도 2
남은 시도 1
종료 0

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    반복 시작

    남은 수를 먼저 출력합니다.

  2. 2

    갱신

    remaining을 1 줄입니다.

  3. 3

    종료 판정

    0 > 0은 거짓이므로 끝납니다.

원할 때 확인하세요

코드를 읽고, 한 번 예측하기

while count < 3 안에서 count가 전혀 바뀌지 않고 처음 값이 0이면 어떻게 되나요?

정답과 모든 선택지의 해설 읽기
  1. 오답: 한 번만 실행됩니다.

    본문 뒤에 같은 조건을 다시 검사합니다.

  2. 오답: 세 번 실행하고 멈춥니다.

    조건의 숫자 3이 자동 반복 횟수를 정하지는 않습니다.

  3. 정답: 다른 종료 지시가 없다면 계속 반복합니다.

    count < 3이 계속 참이므로 값 갱신이나 종료 지시가 필요합니다.

기억할 내용

while은 매 반복 전에 조건을 검사하므로 조건을 바꿀 값도 갱신해야 합니다.
