실행 전에 조건 검사하기

while은 조건이 참인 동안 들여쓴 지시를 반복합니다. for가 항목을 하나씩 받는 것과 달리, while은 반복할지를 조건식으로 직접 결정합니다.

아래에서는 collected가 목표 6보다 작은 동안 2씩 늘립니다. 조건 검사는 본문 실행 전에 일어나므로 처음부터 조건이 거짓이면 본문을 한 번도 실행하지 않습니다.

Python 코드

collected = 0
while collected < 6:
    collected += 2
    print(collected)

실행 결과

2
4
6

상태의 변화

시작: 0 < 6 → 참 · 반복 중: 2 → 4 → 6 · 다음 검사: 6 < 6 → 거짓

  1. 1회

    0에서 2로 증가합니다.

    반복
    1회
    collected
    0 → 2

    이 단계의 출력: (표준 출력 없음)

  2. 2회

    2에서 4로 증가합니다.

    반복
    2회
    collected
    2 → 4

    이 단계의 출력: 2

  3. 3회 이후

    6이 된 다음 조건 검사에서 멈춥니다.

    collected
    6
    collected < 6
    False · 반복 종료

    이 단계의 출력: 2 4 6

누적값과 반복 횟수 분리하기

누적은 반복할 때마다 값을 더해 현재까지의 결과를 유지하는 방식입니다. total은 누적 결과이고 step은 다음에 더할 수입니다. 서로 역할이 다른 상태를 별도 이름으로 관리합니다.

반복 본문의 지시 순서를 바꾸면 다른 수를 더할 수 있습니다. 여기서는 step을 더한 뒤 다음 값으로 증가시킵니다.

Python 코드

step = 1
total = 0
while step <= 3:
    total += step
    step += 1
print(total)
print(step)

실행 결과

6
4

상태의 변화

누적 결과: 1 + 2 + 3 → 6 · 다음 step: 4, 조건을 만족하지 않음

  1. 첫 누적

    total=1, step=2

    반복
    1회
    total
    1
    step
    2

    이 단계의 출력: (표준 출력 없음)

  2. 둘째 누적

    total=3, step=3

    반복
    2회
    total
    3
    step
    3

    이 단계의 출력: (표준 출력 없음)

  3. 셋째 누적

    total=6, step=4, 반복 종료

    반복
    3회 후 종료
    total
    6

    4

끝나는 이유를 확인하기

무한 반복은 종료 조건이 계속 참으로 남아 끝나지 않는 반복입니다. while remaining > 0인데 remaining을 줄이지 않으면 같은 조건을 계속 검사할 수 있습니다.

종료를 설명할 때는 “무엇이 어떤 방향으로 바뀌는가”와 “언제 조건이 거짓이 되는가”를 함께 확인하세요. 아래에서는 남은 시도 수가 매번 1씩 줄어 결국 0이 됩니다.

Python 코드

remaining = 3
while remaining > 0:
    print("남은 시도", remaining)
    remaining -= 1
print("종료", remaining)

실행 결과

남은 시도 3
남은 시도 2
남은 시도 1
종료 0

상태의 변화

시작 상태: remaining=3 · 변화 규칙: 매번 1 감소 · 종료 상태: remaining=0

  1. 반복 시작

    남은 수를 먼저 출력합니다.

    remaining
    3

    이 단계의 출력: 남은 시도 3

  2. 갱신

    remaining을 1 줄입니다.

    remaining
    3 → 2

    이 단계의 출력: 남은 시도 3

  3. 종료 판정

    0 > 0은 거짓이므로 끝납니다.

    remaining
    0
    remaining > 0
    False

    이 단계의 출력: 남은 시도 3 남은 시도 2 남은 시도 1

결과와 관계 확인

0
remaining > 0
False · 반복 종료
