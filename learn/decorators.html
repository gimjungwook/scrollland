01

함수를 받아 새 함수 돌려주기

고차 함수는 함수를 입력으로 받거나 함수로 결과를 반환하는 함수입니다. 감싸는 함수는 다른 함수를 호출하면서 앞뒤 동작을 덧붙이는 함수입니다.

아래 trace는 전달받은 original을 기억하는 wrapped를 반환합니다. trace(total) 시점에는 total을 실행하지 않으며, 반환한 함수를 호출할 때 원래 계산을 수행합니다.

Python 코드

Python 3.10+
def trace(original):
    def wrapped():
        print("시작")
        result = original()
        print("끝")
        return result
    return wrapped

def total():
    return 4 + 2

tracked = trace(total)
print(tracked())

02

@ 표기로 감싸기 명시하기

데코레이터는 함수 정의에 적용하는 변환 함수입니다. @trace를 붙인 정의는 정의한 함수를 trace에 전달하고 그 결과를 같은 이름에 다시 연결하는 방식입니다.

여러 입력을 받는 원래 함수를 감싸려면 *args와 **kwargs로 받은 값을 그대로 전달할 수 있습니다. 반환값도 돌려줘야 호출자가 계산 결과를 계속 사용할 수 있습니다.

Python 코드

Python 3.10+
def trace(original):
    def wrapped(*args, **kwargs):
        print("계산 요청")
        return original(*args, **kwargs)
    return wrapped

@trace
def add(a, b):
    return a + b

print(add(3, b=4))

03

원래 함수 설명을 보존하기

감싸는 함수로 바꾸면 함수의 이름과 문서 문자열이 감싸는 함수의 것으로 보일 수 있습니다. Python 표준 라이브러리의 functools.wraps는 원래 함수의 이런 설명 정보를 감싼 함수에 복사합니다.

모듈은 불러와 사용할 수 있는 코드 묶음이며 from functools import wraps는 그 안의 wraps를 가져오는 지시입니다. wraps가 모든 동작을 자동 보장하지는 않으므로 인자 전달과 반환값은 직접 유지해야 합니다.

Python 코드

Python 3.10+
from functools import wraps

def trace(original):
    @wraps(original)
    def wrapped(*args, **kwargs):
        return original(*args, **kwargs)
    return wrapped

@trace
def total(count):
    """두 배 수량을 반환합니다."""
    return count * 2

print(total.__name__)
print(total.__doc__)
print(total(3))

원할 때 확인하세요

코드를 읽고, 한 번 예측하기

@trace로 감싼 함수가 원래 결과를 계속 전달하려면 무엇을 확인해야 하나요?

정답과 모든 선택지의 해설 읽기
  1. 정답: 원래 함수의 반환값을 감싸는 함수에서도 return합니다.

    반환을 생략하면 감싸는 함수의 호출 결과가 None으로 바뀔 수 있습니다.

  2. 오답: print()로 출력했으니 반환은 없어도 됩니다.

    출력과 반환은 서로 다른 동작입니다.

  3. 오답: 함수 이름만 같으면 동작은 항상 같습니다.

    감싸는 함수가 입력과 반환을 전달하는 방식에 따라 동작이 달라집니다.
