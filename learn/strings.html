첫 글자와 마지막 글자 찾기

인덱스는 항목의 위치를 나타내는 정수입니다. 문자열의 첫 위치는 0이고, -1은 마지막 위치입니다. 대괄호에 인덱스를 적어 한 글자를 읽습니다.

len()은 문자열의 길이를 구합니다. 존재하지 않는 위치를 하나 선택하면 오류가 납니다. 문자열은 만든 뒤 내부 글자를 직접 바꿀 수 없는 불변 객체입니다.

Python 코드

code = "OBS-27"
print(code[0])
print(code[-1])
print(len(code))

실행 결과

O
7
6

값의 구성

앞에서 센 위치: 0: O, 1: B, 2: S · 뒤에서 센 위치: -1: 7, -2: 2

  1. 문자열 준비

    길이 6의 문자열을 code에 연결합니다.

    code
    "OBS-27"
    길이
    6

    이 단계의 출력: (표준 출력 없음)

  2. 위치 읽기

    0에서 O, -1에서 7을 가져옵니다.

    code[0]
    "O"
    code[-1]
    "7"

    이 단계의 출력: O 7

부분 범위를 잘라 읽기

슬라이스는 시작 위치부터 끝 위치 직전까지의 부분을 가져오는 표기입니다. code[0:3]은 위치 0, 1, 2의 글자를 모으고 3은 포함하지 않습니다.

시작이나 끝을 생략하면 문자열의 처음이나 끝까지 사용합니다. 슬라이스는 원본을 바꾸지 않고 새 문자열을 돌려줍니다.

Python 코드

code = "OBS-27"
print(code[:3])
print(code[4:])
print(code)

실행 결과

OBS
27
OBS-27

값의 구성

전체: OBS-27 · 선택 범위: [:3] → OBS · 다른 범위: [4:] → 27

  1. 선택 전

    code는 OBS-27입니다.

    code
    "OBS-27"

    이 단계의 출력: (표준 출력 없음)

  2. 선택 후

    OBS와 27을 각각 읽어도 원본은 유지됩니다.

    code[:3]
    "OBS"
    code[4:]
    "27"
    code
    "OBS-27" 유지

    이 단계의 출력: OBS 27

결과와 관계 확인

code
"OBS-27" 유지
code[:3] 결과

값을 문장 안에 넣기

f-string은 f를 붙인 문자열 안의 중괄호 자리에 값을 넣는 표기입니다. {distance:.1f}는 숫자를 소수점 아래 한 자리로 표시합니다. 표시 자릿수를 정해도 distance의 저장값은 바뀌지 않습니다.

이스케이프는 역슬래시로 특수 문자를 적는 방법입니다. \n은 줄바꿈이고 \"는 문자열 안의 큰따옴표입니다. 두 줄 안내문을 하나의 문자열로 만들 수 있습니다.

Python 코드

distance = 2.36
print(f"산책 거리: {distance:.1f} km")
print("관찰\n기록")

실행 결과

산책 거리: 2.4 km
관찰
기록

실행 순서

수치: distance → 2.36 · 문장에 표시: 산책 거리: 2.4 km

  1. 서식 적용

    2.36을 소수점 아래 한 자리로 표시합니다.

    distance
    2.36
    표시
    2.4 km

    이 단계의 출력: 산책 거리: 2.4 km

  2. 줄바꿈 처리

    \n 위치에서 다음 출력 줄로 넘어갑니다.

    줄바꿈
    관찰 다음 줄에 기록

    이 단계의 출력: 산책 거리: 2.4 km 관찰 기록

결과와 관계 확인

distance
2.36

산책 거리: 2.4 km
줄바꿈한 출력
