글의 위치와 표현 다루기

기록 코드 OBS-27에서 뒤의 27만 읽고 싶습니다. 원래 코드를 지우지 않고 꺼낼 수 있을까요?

"OBS-27"의 [4:]→"27"

글도 이름에 연결하는 값입니다. 이번에는 문자열의 각 위치를 읽고 필요한 범위만 선택합니다.

첫 글자·끝 글자·일부 범위를 꺼낸 뒤, 계산한 수치를 읽기 좋은 안내문 안에 넣습니다.

읽고 나면문자열의 위치·부분 범위·서식을 구분해 사용합니다.

먼저 익힐 개념 · 같아 보이는 값 구별하기

01

첫 글자와 마지막 글자 찾기

인덱스는 항목의 위치를 나타내는 정수입니다. 문자열의 첫 위치는 0이고, -1은 마지막 위치입니다. 대괄호에 인덱스를 적어 한 글자를 읽습니다.

len()은 문자열의 길이를 구합니다. 존재하지 않는 위치를 하나 선택하면 오류가 납니다. 문자열은 만든 뒤 내부 글자를 직접 바꿀 수 없는 불변 객체입니다.

Pythonstrings.py
01code = "OBS-27"02print(code[0])03print(code[-1])04print(len(code))

실행 결과

O
7
6
02

부분 범위를 잘라 읽기

슬라이스는 시작 위치부터 끝 위치 직전까지의 부분을 가져오는 표기입니다. code[0:3]은 위치 0, 1, 2의 글자를 모으고 3은 포함하지 않습니다.

시작이나 끝을 생략하면 문자열의 처음이나 끝까지 사용합니다. 슬라이스는 원본을 바꾸지 않고 새 문자열을 돌려줍니다.

Pythonstrings.py
01code = "OBS-27"02print(code[:3])03print(code[4:])04print(code)

실행 결과

OBS
27
OBS-27
03

값을 문장 안에 넣기

f-string은 f를 붙인 문자열 안의 중괄호 자리에 값을 넣는 표기입니다. {distance:.1f}는 숫자를 소수점 아래 한 자리로 표시합니다. 표시 자릿수를 정해도 distance의 저장값은 바뀌지 않습니다.

이스케이프는 역슬래시로 특수 문자를 적는 방법입니다. \n은 줄바꿈이고 \"는 문자열 안의 큰따옴표입니다. 두 줄 안내문을 하나의 문자열로 만들 수 있습니다.

Pythonstrings.py
01distance = 2.3602print(f"산책 거리: {distance:.1f} km")03print("관찰\n기록")

실행 결과

산책 거리: 2.4 km
관찰
기록

name = "river"일 때 name[1:4]의 값은 무엇인가요?

  1. ive
  2. iver
  3. riv

답을 떠올린 뒤, 아래의 설명과 비교해 보세요.

정답ive

정답: ive위치 1, 2, 3을 포함하고 끝 위치 4는 제외합니다.

오답: iver끝 위치 4의 r은 포함하지 않습니다.

오답: riv시작 위치 1은 r이 아니라 i입니다.

기억할 한 가지

문자열의 위치는 0부터 세고, 부분 범위의 끝 위치는 포함하지 않습니다.
