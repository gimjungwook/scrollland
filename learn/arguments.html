함수 입력의 규칙 정하기

3마리, 2곳, 4회를 같은 함수로 적고 싶습니다. 수량과 단위를 어떻게 전달해야 서로 뒤바뀌지 않을까요?

label(2, unit="곳")→"2곳"

함수를 호출하고 값을 돌려받는 방법을 배웠습니다. 인자를 순서로 연결할지 이름으로 지정할지 정하면 호출의 뜻을 분명히 할 수 있습니다.

기본 단위를 쓰는 호출과 단위를 바꾸는 호출을 비교하고, 여러 인자와 기본값 객체를 다루는 주의점을 확인합니다.

읽고 나면위치·키워드·기본 인자와 가변 인자의 연결 방식을 설명합니다.

먼저 익힐 개념 · 한 묶음의 의미를 고정하기 · 이름표로 값 찾기 · 계산에 이름을 붙여 재사용하기

01

순서로 전달하거나 이름으로 지정하기

위치 인자는 적은 순서대로 매개변수에 연결됩니다. 키워드 인자는 count=3처럼 매개변수 이름을 지정합니다. 정의에 적은 기본값은 그 인자를 생략했을 때 사용합니다.

같은 매개변수에 위치와 키워드로 값을 두 번 전달할 수 없습니다. 호출할 때는 위치 인자를 먼저 적고 그 뒤에 키워드 인자를 적습니다.

Pythonarguments.py
01def label(count, unit="마리"):02    return f"{count}{unit}"03 04print(label(3))05print(label(2, unit="곳"))06print(label(unit="회", count=4))

실행 결과

3마리
2곳
4회
02

여러 인자를 묶어 받기

*counts는 남는 위치 인자를 튜플로 모읍니다. **details는 남는 키워드 인자를 딕셔너리로 모읍니다. args와 kwargs는 흔한 이름일 뿐, 별표 문법이 동작을 결정합니다.

호출할 때의 *리스트는 항목들을 위치 인자로 풀고 **딕셔너리는 키와 값을 키워드 인자로 풉니다. 정의의 모으기와 호출의 풀기를 구별하세요.

sum(counts)는 counts에 들어 있는 숫자를 모두 더한 값을 반환하는 내장 함수입니다. 내장 함수는 Python이 기본 제공하므로 별도로 정의하지 않고 사용할 수 있는 함수입니다. 이 예제에서는 (2, 3)을 받아 5를 구합니다.

Pythonarguments.py
01def report(*counts, **details):02    return sum(counts), details.get("place", "미지정")03 04print(report(2, 3, place="숲"))05numbers = [4, 1]06options = {"place": "강"}07print(report(*numbers, **options))

실행 결과

(5, '숲')
(5, '강')
03

기본값 객체를 공유하지 않기

함수의 기본값은 함수가 정의될 때 한 번 계산됩니다. 기본값을 []로 두고 계속 추가하면 호출들이 같은 리스트를 공유할 수 있습니다.

호출마다 새 리스트가 필요하면 기본값 None을 사용하고 함수 안에서 만듭니다. 기존 리스트를 전달한 경우에는 그 객체에 추가한다는 동작도 호출자에게 설명해야 합니다.

Pythonarguments.py
01def add_count(count, counts=None):02    if counts is None:03        counts = []04    counts.append(count)05    return counts06 07print(add_count(2))08print(add_count(3))

실행 결과

[2]
[3]
04

실수하기 쉬운 옵션은 이름으로 받기

정의의 / 앞 매개변수는 위치 전용이므로 이름으로 전달할 수 없습니다. * 뒤 매개변수는 키워드 전용이므로 호출에서 이름을 적어야 합니다.

아래 unit은 표시 단위라는 뜻을 호출에도 남기려고 키워드 전용으로 정했습니다. 모든 함수에 복잡한 형식을 쓸 필요는 없으며, 잘못된 순서로 값을 넣을 위험이 있을 때 선택합니다.

Pythonarguments.py
01def label(count, /, *, unit="마리"):02    return f"{count}{unit}"03 04print(label(5, unit="곳"))05print(label(2))

실행 결과

5곳
2마리

정의가 def show(count, *, unit)이라면 올바른 호출은 무엇인가요?

  1. show(3, "곳")
  2. show(3, unit="곳")
  3. show(3)

답을 떠올린 뒤, 아래의 설명과 비교해 보세요.

정답show(3, unit="곳")

오답: show(3, "곳")* 뒤의 unit은 키워드 전용이라 이름을 지정해야 합니다.

정답: show(3, unit="곳")count는 위치로, unit은 키워드로 전달했습니다.

오답: show(3)unit에는 기본값이 없으므로 생략할 수 없습니다.

기억할 한 가지

함수의 입력 규칙을 명시하면 호출하는 사람이 값의 역할을 덜 헷갈립니다.
