01

순서로 전달하거나 이름으로 지정하기

위치 인자는 적은 순서대로 매개변수에 연결됩니다. 키워드 인자는 count=3처럼 매개변수 이름을 지정합니다. 정의에 적은 기본값은 그 인자를 생략했을 때 사용합니다.

같은 매개변수에 위치와 키워드로 값을 두 번 전달할 수 없습니다. 호출할 때는 위치 인자를 먼저 적고 그 뒤에 키워드 인자를 적습니다.

Python 코드

Python 3.10+
def label(count, unit="마리"):
    return f"{count}{unit}"

print(label(3))
print(label(2, unit="곳"))
print(label(unit="회", count=4))

예제 실행 결과

3마리
2곳
4회

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    인자 연결

    위치 또는 이름으로 값을 받습니다.

  2. 2

    기본값 선택

    생략한 unit에만 기본값을 사용합니다.

02

여러 인자를 묶어 받기

*counts는 남는 위치 인자를 튜플로 모읍니다. **details는 남는 키워드 인자를 딕셔너리로 모읍니다. args와 kwargs는 흔한 이름일 뿐, 별표 문법이 동작을 결정합니다.

호출할 때의 *리스트는 항목들을 위치 인자로 풀고 **딕셔너리는 키와 값을 키워드 인자로 풉니다. 정의의 모으기와 호출의 풀기를 구별하세요.

sum(counts)는 counts에 들어 있는 숫자를 모두 더한 값을 반환하는 내장 함수입니다. 내장 함수는 Python이 기본 제공하므로 별도로 정의하지 않고 사용할 수 있는 함수입니다. 이 예제에서는 (2, 3)을 받아 5를 구합니다.

Python 코드

Python 3.10+
def report(*counts, **details):
    return sum(counts), details.get("place", "미지정")

print(report(2, 3, place="숲"))
numbers = [4, 1]
options = {"place": "강"}
print(report(*numbers, **options))

예제 실행 결과

(5, '숲')
(5, '강')

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    입력 모으기

    위치와 키워드 인자를 별도 묶음으로 받습니다.

  2. 2

    반환

    수량 합계와 장소를 튜플로 돌려줍니다.

03

기본값 객체를 공유하지 않기

함수의 기본값은 함수가 정의될 때 한 번 계산됩니다. 기본값을 []로 두고 계속 추가하면 호출들이 같은 리스트를 공유할 수 있습니다.

호출마다 새 리스트가 필요하면 기본값 None을 사용하고 함수 안에서 만듭니다. 기존 리스트를 전달한 경우에는 그 객체에 추가한다는 동작도 호출자에게 설명해야 합니다.

Python 코드

Python 3.10+
def add_count(count, counts=None):
    if counts is None:
        counts = []
    counts.append(count)
    return counts

print(add_count(2))
print(add_count(3))

예제 실행 결과

[2]
[3]

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    각 호출 시작

    counts가 None인지 확인합니다.

  2. 2

    새 객체 생성

    None이면 호출마다 빈 리스트를 만듭니다.

04

실수하기 쉬운 옵션은 이름으로 받기

정의의 / 앞 매개변수는 위치 전용이므로 이름으로 전달할 수 없습니다. * 뒤 매개변수는 키워드 전용이므로 호출에서 이름을 적어야 합니다.

아래 unit은 표시 단위라는 뜻을 호출에도 남기려고 키워드 전용으로 정했습니다. 모든 함수에 복잡한 형식을 쓸 필요는 없으며, 잘못된 순서로 값을 넣을 위험이 있을 때 선택합니다.

Python 코드

Python 3.10+
def label(count, /, *, unit="마리"):
    return f"{count}{unit}"

print(label(5, unit="곳"))
print(label(2))

예제 실행 결과

5곳
2마리

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    호출 확인

    count는 위치로, unit은 이름으로 받습니다.

  2. 2

    생략 처리

    unit을 생략한 두 번째 호출은 마리를 사용합니다.

원할 때 확인하세요

코드를 읽고, 한 번 예측하기

정의가 def show(count, *, unit)이라면 올바른 호출은 무엇인가요?

정답과 모든 선택지의 해설 읽기
  1. 오답: show(3, "곳")

    * 뒤의 unit은 키워드 전용이라 이름을 지정해야 합니다.

  2. 정답: show(3, unit="곳")

    count는 위치로, unit은 키워드로 전달했습니다.

  3. 오답: show(3)

    unit에는 기본값이 없으므로 생략할 수 없습니다.
