지금 실행하는 Python 확인하기

인터프리터는 Python 코드를 읽어 실행하는 프로그램입니다. 한 컴퓨터에 여러 Python이 있을 수 있으므로 실행 파일과 버전을 확인해야 합니다. sys는 실행 환경 정보를 제공하는 표준 모듈입니다.

sys.version_info에는 버전 숫자가 들어 있습니다. 예제에서는 실제 버전 문자열 대신 이 과정의 최소 버전인 3.10 이상인지 검사합니다. 사이트를 읽는 데에는 설치가 필요 없고 직접 실행할 때에만 이 준비가 필요합니다.

Python 코드

import sys

print(sys.version_info >= (3, 10))
print(sys.version_info.major)

임시 폴더에서 가상 환경 만들어 보기

가상 환경은 프로젝트별로 설치한 패키지와 실행 경로를 구분하는 Python 환경입니다. 일반 작업 폴더에서는 터미널에 python3 -m venv .venv를 입력해 만듭니다. Windows에서는 py -m venv .venv를 사용할 수 있습니다.

아래는 실제 프로젝트 대신 예제 전용 임시 폴더에 환경을 만듭니다. with tempfile.TemporaryDirectory() as folder는 새 임시 폴더의 경로를 folder로 받고, 들여쓴 구간이 끝날 때 폴더를 정리합니다. venv.create(folder, with_pip=False)는 그 경로에 가상 환경을 만들되 이번 확인에 필요 없는 pip 준비는 생략합니다. 외부 패키지 설치나 업데이트를 요청하지 않습니다.

os.path.join(folder, "pyvenv.cfg")는 폴더 경로와 설정 파일 이름을 이어 파일 경로를 만듭니다. os.path.isfile()은 그 경로에 파일이 있으면 True를 반환합니다. 이 예제의 True는 가상 환경의 설정 파일이 생겼다는 뜻이며, 현재 코드를 실행하던 Python이 새 환경으로 바뀌었다는 뜻은 아닙니다.

프로젝트 폴더에서 앞의 터미널 명령으로 만든 .venv를 사용하려면 macOS·Linux에서 .venv/bin/python practice.py, Windows에서 .venv\Scripts\python.exe practice.py처럼 환경 안의 Python을 직접 지정합니다. 아래 예제용 임시 환경은 코드 종료 때 삭제되므로 나중에 실행할 경로로 사용하지 않습니다.

Python 코드

import os
import tempfile
import venv

with tempfile.TemporaryDirectory() as folder:
    venv.create(folder, with_pip=False)
    configuration = os.path.join(folder, "pyvenv.cfg")
    print(os.path.isfile(configuration))

실행 결과

True

pip와 설치 범위 구별하기

pip는 Python 패키지를 설치하고 조회하는 도구입니다. 의존성은 프로젝트가 실행에 필요로 하는 외부 패키지입니다. 가상 환경을 활성화하면 python 명령이 그 환경을 가리키게 할 수 있고, 환경 안의 실행 파일을 직접 지정해도 됩니다.

아래 코드는 터미널에서 쓸 명령을 출력할 뿐 실행하거나 설치하지 않습니다. python -m pip는 선택한 Python에 연결된 pip를 사용합니다. 보통 python -m pip install 패키지이름으로 설치하고 python -m pip freeze로 버전 목록을 남깁니다. 이번 학습 예제는 표준 라이브러리만 사용하므로 외부 설치가 필요 없습니다.

Python 코드

commands = ["python -m pip --version", "python -m pip list", "python -m pip freeze"]
for command in commands:
    print(command)

실행 결과
