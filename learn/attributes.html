01

개별 속성을 추가하고 지우기

인스턴스 속성은 각 객체에 붙은 상태입니다. 일반 클래스에서는 생성 뒤 새 속성을 대입할 수 있습니다. hasattr()는 해당 이름의 속성을 읽을 수 있는지 확인합니다.

del record.note는 이 객체의 note 속성을 제거합니다. 객체 전체나 파일을 지우는 지시가 아닙니다. 필요한 필드를 언제나 보장해야 한다면 초기화 단계에서 이름을 정하고 일관되게 유지하세요.

Python 코드

Python 3.10+
class Observation:
    def __init__(self, count):
        self.count = count

record = Observation(4)
record.note = "비 온 뒤"
print(record.note)
del record.note
print(hasattr(record, "note"))

예제 실행 결과

비 온 뒤
False

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    속성 추가

    record에 note를 붙입니다.

  2. 2

    속성 제거

    note만 삭제하고 count는 유지합니다.

02

공통 값과 개별 값 구별하기

클래스 본문에 둔 속성은 여러 인스턴스가 공통으로 조회할 수 있습니다. 인스턴스에 같은 이름의 속성이 있으면 그 값이 클래스 속성을 가립니다.

여러 객체가 각자 다른 목록을 가져야 할 때 빈 리스트를 클래스 속성으로 두면 하나를 공유하게 됩니다. 개별 목록은 __init__ 안에서 self.items = []처럼 매번 만드세요.

Python 코드

Python 3.10+
class Observation:
    unit = "마리"
    def __init__(self, count):
        self.count = count

first = Observation(4)
second = Observation(2)
first.unit = "개체"
print(first.unit)
print(second.unit)
print(Observation.unit)

예제 실행 결과

개체
마리
마리

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    초기 조회

    둘 다 공통 단위를 읽을 수 있습니다.

  2. 2

    개별 대입

    first에만 별도 unit 속성을 만듭니다.

03

공개된 변경 경로에 규칙 두기

캡슐화는 내부 상태와 그 상태를 다루는 규칙을 한곳에 묶고 사용할 접근 방법을 정하는 설계입니다. 밑줄 하나로 시작하는 _count는 내부 구현이라는 관례이며 보안 잠금이 아닙니다.

@property 아래의 count 메서드는 record.count를 읽을 때 실행됩니다. @count.setter 아래의 count 메서드는 record.count = 값처럼 대입할 때 실행됩니다. 두 데코레이터는 이름이 같은 두 메서드를 조회와 대입을 담당하는 한 속성에 연결합니다.

raise ValueError(...)는 허용하지 않는 값이라고 알리고 해당 대입을 중단하는 지시입니다. 아래 대입 메서드는 음수가 아닌 값만 _count에 저장합니다. 예외를 받아 사용자에게 응답하는 방법은 「예외를 구별해 처리하기」 레슨에서 다룹니다.

밑줄 두 개로 시작하는 __count 같은 속성 이름에는 클래스 이름을 포함하는 이름 변환이 적용됩니다. 다른 클래스의 이름과 우연히 충돌하는 일을 줄이지만 외부 접근을 완전히 금지하지는 않습니다. 이 예제는 내부 구현임을 나타내는 밑줄 하나의 _count를 사용합니다.

Python 코드

Python 3.10+
class Observation:
    def __init__(self, count):
        self.count = count
    @property
    def count(self):
        return self._count
    @count.setter
    def count(self, value):
        if value < 0:
            raise ValueError("수량은 0 이상이어야 합니다")
        self._count = value

record = Observation(4)
record.count = 5
print(record.count)

예제 실행 결과

5

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    대입 요청

    count의 대입 메서드가 5를 받습니다.

  2. 2

    검사 통과

    음수가 아니므로 내부 _count를 5로 갱신합니다.

  3. 3

    조회

    record.count를 읽으면 조회 메서드가 저장한 5를 반환합니다.

코드를 읽고, 한 번 예측하기

클래스 속성으로 빈 리스트를 두고 여러 인스턴스가 수정하면 어떤 점을 주의해야 하나요?

정답과 모든 선택지의 해설 읽기
  1. 오답: 각 인스턴스마다 자동으로 복사됩니다.

    개별 속성이 가리지 않는다면 같은 클래스의 리스트를 공유합니다.

  2. 정답: 같은 리스트를 공유해 다른 인스턴스에서도 변경이 보일 수 있습니다.

    각자 목록이 필요하면 __init__ 안에서 새 리스트를 만드세요.

  3. 오답: 클래스 속성은 수정이 불가능합니다.

    리스트 자체는 변경 가능한 객체입니다.
