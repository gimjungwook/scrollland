몫과 나머지를 나누어 묻기

연산자는 +나 /처럼 값에 할 작업을 나타내는 기호입니다. /는 나눈 값을 구하고, //는 나눈 결과보다 크지 않은 가장 가까운 정수 쪽으로 내린 몫을 구하며, %는 그때의 나머지를 구합니다.

17개를 네 개씩 묶으면 완성 묶음은 4개이고 나머지는 1개입니다. 음수에서 //는 0 쪽으로 버리는 연산이 아니므로 -7 // 3은 -3입니다.

Python 코드

print(17 / 4)
print(17 // 4)
print(17 % 4)
print(-7 // 3)

4

-3

값의 구성

전체 수량: 17 · 완성 묶음: 4 × 4 = 16 · 남은 수량: 1

    17개를 4개씩 묶습니다.

    전체
    17개
    한 묶음
    4개

    이 단계의 출력: (표준 출력 없음)

  2. 나누기 후

    몫 4와 나머지 1을 얻습니다.

    몫
    4
    나머지
    1

    이 단계의 출력: 4.25 4 1

계산 순서 드러내기

곱셈과 나눗셈은 덧셈과 뺄셈보다 먼저 계산합니다. 괄호는 먼저 구할 부분을 명시합니다. **는 거듭제곱이며 3 ** 2는 3을 두 번 곱한 값입니다.

이름도 단위가 보이도록 지으면 계산 의도가 읽힙니다. 아래에서 사람마다 필요한 물의 양을 먼저 곱한 뒤 여분을 더합니다. 계산 순서가 헷갈리면 괄호를 남겨 두세요.

Python 코드

people = 3
print(people * 2 + 1)
print(people * (2 + 1))
print(3 ** 2)

9
9

실행 순서

여분을 전체에 추가: 3 × 2 + 1 → 7 · 사람마다 여분 추가: 3 × (2 + 1) → 9

    3 × 2를 먼저 계산합니다.

    people
    3
    먼저 계산
    3 × 2 → 6

    이 단계의 출력: (표준 출력 없음)

  2. 괄호 있는 식

    2 + 1을 먼저 계산합니다.

    people
    3
    먼저 계산
    2 + 1 → 3

    이 단계의 출력: 7

소수 계산의 오차 알아두기

float는 많은 십진 소수를 이진수로 정확히 저장하지 못합니다. 0.1 + 0.2의 출력 끝에 작은 차이가 생기는 이유입니다. round()로 반올림한 결과와 원래 값은 구별해야 합니다.

복소수 complex는 실수부와 허수부를 함께 갖고 j로 허수 단위를 씁니다. 이번 과정은 일반 수량 계산에 int와 float를 사용합니다. 금액처럼 정확한 십진 계산이 필요한 문제는 「수학 도구로 결과 확인하기」 레슨의 Decimal을 참고하세요.

Python 코드

print(0.1 + 0.2)
print(round(0.1 + 0.2, 2))
print((2 + 3j) + (1 - 1j))

실행 결과

0.3
(3+2j)

실행 순서

저장값의 계산: 0.30000000000000004 · 반올림한 값: 0.3

  1. 덧셈

    근사 표현을 더한 값이 출력됩니다.

    0.1 + 0.2
    0.30000000000000004

    이 단계의 출력: 0.30000000000000004

  2. 반올림

    소수 둘째 자리까지 반올림한 새 값을 얻습니다.

    반올림한 값
    0.3

    이 단계의 출력: 0.30000000000000004 0.3
