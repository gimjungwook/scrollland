01

항목마다 지시 실행하기

반복은 같은 지시 묶음을 여러 번 실행하는 일입니다. for place in places는 places에서 항목을 하나씩 받아 place에 연결합니다.

들여쓴 출력은 항목마다 실행되고, 들여쓰기 밖의 출력은 반복이 끝난 뒤 한 번 실행됩니다. 딕셔너리는 기본적으로 키를 순회하며 items()를 쓰면 키와 값을 함께 받을 수 있습니다.

Python 코드

Python 3.10+
places = ["숲", "강", "못"]
for place in places:
    print("관찰:", place)
print("목록 끝")

예제 실행 결과

관찰: 숲
관찰: 강
관찰: 못
목록 끝

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    첫 반복

    숲을 출력합니다.

  2. 2

    다음 반복들

    강과 못을 차례대로 출력합니다.

  3. 3

    반복 종료

    목록 끝을 한 번 출력합니다.

02

정해진 횟수만큼 반복하기

range()는 정수 범위를 나타냅니다. range(1, 4)는 1부터 시작해 끝값 4 직전까지 사용하므로 1, 2, 3을 만듭니다. 범위 전체를 리스트로 저장하지 않고 반복할 수 있습니다.

세 번째 값은 간격입니다. range(5, 0, -2)는 5에서 2씩 줄여 1까지 사용합니다. 시작·끝·간격을 정하면 반복 횟수를 예측할 수 있습니다.

Python 코드

Python 3.10+
for round_no in range(1, 4):
    print(round_no)
print(list(range(5, 0, -2)))

예제 실행 결과

1
2
3
[5, 3, 1]

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    range 순회

    1, 2, 3에 대해 세 번 반복합니다.

  2. 2

    감소 범위

    5, 3, 1을 만들고 0 아래로 가기 전에 멈춥니다.

03

번호와 여러 묶음 함께 읽기

enumerate()는 항목과 함께 번호를 제공하며 start=1이면 1부터 번호를 붙입니다. zip()은 여러 묶음에서 같은 순서의 항목을 한 쌍씩 꺼냅니다. 길이가 다르면 기본적으로 짧은 쪽에서 끝납니다.

중첩 반복은 바깥의 항목 하나마다 안쪽 반복 전체를 실행합니다. 아래 번호 출력과는 별개로 두 장소의 두 시간대를 모두 만들면 네 조합이 됩니다.

Python 코드

Python 3.10+
for no, place in enumerate(["숲", "강"], start=1):
    print(no, place)
for place, count in zip(["숲", "강"], [4, 2]):
    print(place, count)
for place in ["숲", "강"]:
    for period in ["아침", "저녁"]:
        print(place, period)

예제 실행 결과

1 숲
2 강
숲 4
강 2
숲 아침
숲 저녁
강 아침
강 저녁

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    첫 바깥 항목

    숲에 대해 두 시간대를 출력합니다.

  2. 2

    둘째 바깥 항목

    강에 대해 두 시간대를 출력합니다.

코드를 읽고, 한 번 예측하기

range(2, 6)에 대해 for를 실행하면 어떤 수를 받나요?

정답과 모든 선택지의 해설 읽기
  1. 오답: 2, 3, 4, 5, 6

    끝값 6은 범위에 포함되지 않습니다.

  2. 정답: 2, 3, 4, 5

    시작 2는 포함하고 끝 6은 제외합니다.

  3. 오답: 3, 4, 5

    시작값 2도 포함합니다.

기억할 내용

for는 묶음에서 다음 항목을 하나씩 받아 들여쓴 작업을 실행합니다.
