내장 계산과 수학 함수 조합하기

min()과 max()는 가장 작은 값과 큰 값을, abs()는 부호를 제외한 크기를 구합니다. math.sqrt()는 제곱근이며 math.ceil()과 floor()는 각각 위쪽과 아래쪽 정수로 맞춥니다.

반올림과 올림은 다른 작업입니다. 2.1개 분량의 묶음을 담을 용기가 필요하다면 올림한 3개가 적절합니다. 계산 목적을 먼저 문장으로 적으세요.

Python 코드

import math

counts = [4, 2, 7]
print(min(counts), max(counts))
print(abs(-3))
print(math.sqrt(25))
print(math.ceil(2.1), math.floor(2.9))

실행 결과

2 7
3
5.0
3 2

값의 구성

관찰 범위: 최소 2, 최대 7 · 거리 크기: abs(-3) → 3 · 용기 수: ceil(2.1) → 3

    범위·크기·정수 맞춤이 서로 다른 작업입니다.

    범위

    크기
    절댓값·제곱근
    정수 맞춤
    올림·내림

    이 단계의 출력: (표준 출력 없음)

근사 비교와 정확한 십진수

math.isclose()는 허용 오차 안에서 두 값이 가까운지 비교합니다. 실험 측정이나 float 계산에서는 값이 정확히 같은지 묻는 ==와 목적이 다를 수 있습니다.

Decimal은 십진수를 표현하는 decimal 모듈의 자료형입니다. 문자열 "0.1"에서 만들면 float의 근사값을 먼저 거치지 않습니다. 정확한 계산을 요구하는 문제에서는 반올림 규칙도 함께 정해야 합니다.

Python 코드

import math
from decimal import Decimal

print(math.isclose(0.1 + 0.2, 0.3))
print(Decimal("0.1") + Decimal("0.2"))

실행 결과

True
0.3

입력에서 결과로

float 비교: 작은 오차를 허용해 가까운지 확인 · Decimal 계산: 십진 문자열로부터 정확한 덧셈

  1. 근사값 비교

    isclose가 작은 차이를 허용합니다.

    isclose 결과
    True

    이 단계의 출력: True

  2. 십진수 생성

    문자열에서 직접 Decimal을 만듭니다.

    Decimal("0.1") + Decimal("0.2")
    0.3

    이 단계의 출력: True 0.3

결과와 관계 확인

자료의 대표값과 재현 가능한 무작위 선택

statistics.mean()은 평균을 반환합니다. median()은 정렬한 뒤 항목 수가 홀수면 가운데 값, 짝수면 가운데 두 값의 평균을 반환합니다. 큰 값 하나의 영향이 두 계산에서 다를 수 있으므로 대표값을 고르는 이유를 설명해야 합니다.

난수는 무작위처럼 생성한 수입니다. random.Random(7)처럼 시드를 고정하면 같은 입력 상태에서 실험을 재현할 수 있습니다. 시드는 생성기의 초기 상태를 정하는 값입니다. 아래 출력은 임의의 수 자체 대신 생성한 값이 범위 안인지 확인합니다.

Python 코드

import statistics
import random

counts = [2, 3, 10]
print(statistics.mean(counts))
print(statistics.median(counts))
generator = random.Random(7)
value = generator.random()
print(0 <= value < 1)
