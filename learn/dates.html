달력 날짜를 객체로 만들기

datetime 모듈의 date는 연·월·일을 나타냅니다. date(2026, 9, 20)처럼 만들면 달력 규칙에 맞는지 확인하며, 존재하지 않는 날짜에는 오류를 냅니다.

fromisoformat()은 YYYY-MM-DD 형식의 문자열을 날짜로 읽습니다. isoformat()은 같은 형식의 문자열을 만듭니다. 날짜를 그냥 이어 붙이지 않고 객체로 바꾸는 것이 계산의 출발점입니다.

Python 코드

from datetime import date

start = date(2026, 9, 20)
end = date.fromisoformat("2026-09-23")
print(start.isoformat())
print(end > start)

기간을 더하고 날짜를 빼기

timedelta는 두 시점 사이의 기간을 나타냅니다. 날짜에 timedelta(days=3)을 더하면 달력 경계를 넘어도 올바른 날짜를 계산합니다.

날짜에서 날짜를 빼면 timedelta가 됩니다. days로 일수를 읽을 수 있습니다. 아래에서는 월말에서 사흘 뒤가 다음 달이 되는 것을 확인합니다.

Python 코드

from datetime import date, timedelta

start = date(2026, 9, 29)
end = start + timedelta(days=3)
print(end.isoformat())
print((end - start).days)

시각과 시간대를 명시하기

datetime은 날짜와 시각을 함께 나타냅니다. strptime()은 지정 서식의 문자열을 읽고 strftime()은 지정 서식으로 표시합니다. %H는 24시간 기준 시, %M은 분입니다.

시간대는 지역에 따른 시각 기준입니다. 서로 다른 지역의 실제 순간을 비교하려면 UTC 같은 기준을 명시해야 합니다. 아래는 이미 UTC라고 정한 입력에만 timezone.utc를 붙이며, 다른 지역 시각을 UTC로 변환하는 예제는 아닙니다.

Python 코드

from datetime import datetime, timezone

text = "2026-09-23 09:30"
moment = datetime.strptime(text, "%Y-%m-%d %H:%M").replace(tzinfo=timezone.utc)
print(moment.strftime("%H:%M"))
print(moment.isoformat())

실행 결과

09:30
2026-09-23T09:30:00+00:00

date 객체에 사흘을 더하는 올바른 방법은 무엇인가요?

답을 떠올린 뒤, 조금 더 내려 보세요.

정답date 객체에 timedelta(days=3)을 더합니다.

오답: 날짜 문자열 뒤에 "3"을 붙입니다.문자열 연결은 달력 날짜를 계산하지 않습니다.

정답: date 객체에 timedelta(days=3)을 더합니다.timedelta가 기간을 나타내며 날짜 연산이 달력 경계를 처리합니다.

오답: date 객체의 day에 직접 3을 더해 대입합니다.date는 불변 객체이며 월 경계도 별도로 처리해야 하므로 날짜 연산을 사용합니다.
