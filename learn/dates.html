날짜를 값으로 계산하기

9월 29일에서 사흘 뒤는 며칠일까요? 날짜의 일 숫자에 3만 더하면 달의 경계를 놓칩니다.

2026-09-29 + 3일→2026-10-02

표준 모듈을 가져올 수 있습니다. 날짜 도구에 달력 날짜와 기간을 각각 전달하면 월이 바뀌는 계산도 같은 규칙으로 처리합니다.

9월 29일에서 10월 2일로 넘어가는 계산을 확인하고, 날짜 차이와 시간대가 있는 시각을 구별합니다.

읽고 나면date·timedelta·datetime의 역할을 구별하고 날짜 차이를 계산합니다.

먼저 익힐 개념 · 모듈을 불러와 연결하기

01

달력 날짜를 객체로 만들기

datetime 모듈의 date는 연·월·일을 나타냅니다. date(2026, 9, 20)처럼 만들면 달력 규칙에 맞는지 확인하며, 존재하지 않는 날짜에는 오류를 냅니다.

fromisoformat()은 YYYY-MM-DD 형식의 문자열을 날짜로 읽습니다. isoformat()은 같은 형식의 문자열을 만듭니다. 날짜를 그냥 이어 붙이지 않고 객체로 바꾸는 것이 계산의 출발점입니다.

예제의 start와 end는 겉모양만 날짜인 문자열이 아니라 날짜 값입니다. 그래서 end > start는 어느 날이 뒤인지 비교합니다. isoformat()으로 출력할 때만 사람이 읽을 문자열로 바꿉니다.

Pythondates.py
01from datetime import date02 03start = date(2026, 9, 20)04end = date.fromisoformat("2026-09-23")05print(start.isoformat())06print(end > start)

실행 결과

2026-09-20
True
02

기간을 더하고 날짜를 빼기

9월 29일에서 사흘 뒤를 구할 때 날짜의 글자 "29"에 3을 붙이거나 일 숫자를 32로 바꾸면 올바른 달력 날짜가 되지 않습니다. date 값에 기간을 나타내는 timedelta(days=3)을 더하면 월말 규칙까지 적용해 새 날짜를 만듭니다.

아래에서 start는 계속 2026-09-29입니다. 덧셈 결과인 2026-10-02를 end에 따로 연결합니다. 시작 날짜를 직접 바꾼 것이 아닙니다.

반대로 end - start는 두 날짜 사이의 기간입니다. 그 결과의 .days를 읽으면 정수 3을 얻습니다. 날짜에 기간을 더하면 날짜, 날짜에서 날짜를 빼면 기간이라는 결과의 종류를 구별해 보세요.

사흘을 더한 뒤 start도 10월 2일로 바뀔까요?

상태의 변화01 / 04
Pythondates.py
01from datetime import date, timedelta02 03start = date(2026, 9, 29)04end = start + timedelta(days=3)05print(end.isoformat())06print((end - start).days)

03

시각과 시간대를 명시하기

datetime은 날짜와 시각을 함께 나타냅니다. strptime()은 지정 서식의 문자열을 읽고 strftime()은 지정 서식으로 표시합니다. %H는 24시간 기준 시, %M은 분입니다.

시간대는 지역에 따른 시각 기준입니다. 서로 다른 지역의 실제 순간을 비교하려면 UTC 같은 기준을 명시해야 합니다. 아래는 이미 UTC라고 정한 입력에만 timezone.utc를 붙이며, 다른 지역 시각을 UTC로 변환하는 예제는 아닙니다.

이 예제의 입력 09:30은 처음부터 UTC 시각이라고 가정했습니다. replace(tzinfo=timezone.utc)는 시계 숫자 09:30을 바꾸지 않고 그 기준만 붙입니다. 한국 시각 09:30을 UTC로 환산하는 작업과 혼동하지 마세요.

Pythondates.py
01from datetime import datetime, timezone02 03text = "2026-09-23 09:30"04moment = datetime.strptime(text, "%Y-%m-%d %H:%M").replace(tzinfo=timezone.utc)05print(moment.strftime("%H:%M"))06print(moment.isoformat())

실행 결과

09:30
2026-09-23T09:30:00+00:00

date 객체에 사흘을 더하는 올바른 방법은 무엇인가요?

  1. 날짜 문자열 뒤에 "3"을 붙입니다.
  2. date 객체에 timedelta(days=3)을 더합니다.
  3. date 객체의 day에 직접 3을 더해 대입합니다.

답을 떠올린 뒤, 아래의 설명과 비교해 보세요.

정답date 객체에 timedelta(days=3)을 더합니다.

오답: 날짜 문자열 뒤에 "3"을 붙입니다.문자열 연결은 달력 날짜를 계산하지 않습니다.

정답: date 객체에 timedelta(days=3)을 더합니다.timedelta가 기간을 나타내며 날짜 연산이 달력 경계를 처리합니다.

오답: date 객체의 day에 직접 3을 더해 대입합니다.date는 불변 객체이며 월 경계도 별도로 처리해야 하므로 날짜 연산을 사용합니다.

날짜 계산은 날짜 객체로 하고, 입력과 출력 경계에서 문자열로 바꿉니다.
