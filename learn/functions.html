01

작업 정의와 실행 구별하기

def는 함수에 이름을 붙여 작업을 정의합니다. 함수 본문은 들여쓰기로 묶으며, 정의한 순간에는 본문이 실행되지 않습니다. 이름 뒤에 괄호를 붙여 호출해야 실행합니다.

아래에서는 announce를 정의한 뒤 먼저 준비됨을 출력합니다. 함수 호출 위치에 도달하면 본문을 실행하고, 호출한 곳 다음 지시로 돌아옵니다.

Python 코드

Python 3.10+
def announce():
    print("관찰 시작")

print("준비됨")
announce()
print("다음 작업")

예제 실행 결과

준비됨
관찰 시작
다음 작업

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    def 실행

    함수 객체를 만들지만 본문은 실행하지 않습니다.

  2. 2

    본문을 실행합니다.

  3. 3

    호출 종료

    호출 다음 줄로 돌아갑니다.

02

입력으로 다른 계산 하기

매개변수는 함수 정의에서 입력을 받는 이름입니다. 인자는 함수를 호출할 때 전달한 값입니다. count와 extra는 매개변수이고 4와 2는 이 호출의 인자입니다.

return은 함수 실행을 끝내고 값을 호출한 곳에 돌려줍니다. 출력과 반환은 다릅니다. 반환값은 다른 계산에 사용할 수 있고 print()는 화면에 결과를 남깁니다.

Python 코드

Python 3.10+
def total_count(count, extra):
    return count + extra

result = total_count(4, 2)
print(result)
print(total_count(1, 3) * 2)

예제 실행 결과

6
8

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    호출 진입

    인자를 매개변수에 연결합니다.

  2. 2

    return 실행

    6을 호출한 곳에 돌려줍니다.

  3. 3

    후속 사용

    반환값을 출력하거나 다른 계산에 씁니다.

03

계약을 설명하고 None 확인하기

문서 문자열은 함수 본문의 첫 문장으로 적는 문자열이며, 함수가 하는 일을 설명합니다. 보통 큰따옴표 세 개로 감싸며 help() 같은 도구가 설명을 읽을 수 있습니다.

return 없이 본문 끝에 도달하거나 값 없이 return을 쓰면 None을 반환합니다. 아래 display는 출력만 하는 함수입니다. result의 None을 보고 실제 관찰 수량이 없다고 해석하면 안 됩니다.

Python 코드

Python 3.10+
def display(count):
    """관찰 수량을 출력합니다."""
    print("수량:", count)

result = display(4)
print(result)

예제 실행 결과

수량: 4
None

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    본문 실행

    수량을 출력합니다.

  2. 2

    함수 끝

    명시한 반환값이 없어 None을 돌려줍니다.

코드를 읽고, 한 번 예측하기

함수의 계산 결과를 다른 식에서 사용하려면 무엇을 해야 하나요?

정답과 모든 선택지의 해설 읽기
  1. 오답: 결과를 print()로만 출력합니다.

    출력은 화면에 남기는 동작이며 결과값을 반환하는 것과 다릅니다.

  2. 정답: 결과를 return으로 반환합니다.

    호출한 곳이 반환값을 받아 대입하거나 계산에 사용할 수 있습니다.

  3. 오답: 함수 이름만 적습니다.

    괄호 없는 함수 이름은 함수를 실행하지 않습니다.

기억할 내용

함수를 정의하면 작업을 준비하고, 호출하면 입력을 받아 실행합니다.
