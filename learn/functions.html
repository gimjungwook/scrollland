계산에 이름을 붙여 재사용하기

같은 계산을 세 군데에 복사했습니다. 계산 규칙을 고칠 때 세 군데를 모두 찾아야 한다면 어떻게 줄일 수 있을까요?

announce()→출력: 관찰 시작

변수로 값에 이름을 붙였습니다. 이번에는 지시를 묶은 작업에 이름을 붙이고, 필요할 때 그 이름으로 호출합니다.

함수를 정의한 때와 실제로 실행한 때를 구별합니다. 이후 입력을 전달하고 결과를 반환받아 다른 계산에 씁니다.

읽고 나면함수 정의·호출·인자·반환값을 연결해 설명합니다.

작업 정의와 실행 구별하기

def announce():는 announce라는 함수와 그 안에서 할 지시를 준비합니다. 들여쓴 print("관찰 시작")은 준비해 둔 함수 본문입니다. def를 읽은 순간에는 그 print()를 실행하지 않습니다.

바깥 코드는 정의 다음의 print("준비됨")부터 계속 실행합니다. announce()처럼 함수 이름 뒤에 괄호를 붙인 호출에 도달해야 들여쓴 본문으로 들어갑니다. 본문이 끝나면 호출 다음 줄로 돌아옵니다.

따라서 실행은 함수 준비 → 준비됨 출력 → announce() 호출 → 관찰 시작 출력 → 다음 작업 출력 순서입니다. 파일에서 위에 적힌 본문이 먼저 출력된다고 생각하지 말고, 그 본문을 호출하는 줄을 먼저 찾으세요.

함수를 정의한 줄과 실제 본문이 실행되는 줄은 같은 순간일까요?

02

입력으로 다른 계산 하기

매개변수는 함수 정의에서 입력을 받는 이름입니다. 인자는 함수를 호출할 때 전달한 값입니다. count와 extra는 매개변수이고 4와 2는 이 호출의 인자입니다.

return은 함수 실행을 끝내고 값을 호출한 곳에 돌려줍니다. 출력과 반환은 다릅니다. 반환값은 다른 계산에 사용할 수 있고 print()는 화면에 결과를 남깁니다.

result = total_count(4, 2)는 함수가 반환한 6을 result에 연결할 뿐, 이 줄만으로 화면에 6을 쓰지 않습니다. 다음 print(result)가 그 값을 출력합니다. 마지막 줄은 total_count(1, 3)에서 받은 4에 2를 곱한 뒤 8을 출력합니다.

Pythonfunctions.py
01def total_count(count, extra):02    return count + extra03 04result = total_count(4, 2)05print(result)06print(total_count(1, 3) * 2)

계약을 설명하고 None 확인하기

문서 문자열은 함수 본문의 첫 문장으로 적는 문자열이며, 함수가 하는 일을 설명합니다. 보통 큰따옴표 세 개로 감싸며 help() 같은 도구가 설명을 읽을 수 있습니다.

return 없이 본문 끝에 도달하거나 값 없이 return을 쓰면 None을 반환합니다. 아래 display는 출력만 하는 함수입니다. result의 None을 보고 실제 관찰 수량이 없다고 해석하면 안 됩니다.

display(4) 안의 print()가 먼저 수량: 4를 출력합니다. 그 후 display가 별도 return 없이 끝나면 호출 결과 None이 result에 연결됩니다. 바깥 print(result)는 이미 출력한 문장을 다시 받는 것이 아니라 이 None을 출력합니다.

Pythonfunctions.py
01def display(count):02    """관찰 수량을 출력합니다."""03    print("수량:", count)04 05result = display(4)06print(result)
