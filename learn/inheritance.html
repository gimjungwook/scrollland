공통 행동을 이어받아 바꾸기

새를 관찰한 기록에도 기존의 수량 요약을 쓰고 싶습니다. 같은 코드를 다시 적어야 할까요?

BirdObservation(4).summary()→"관찰 4개"

메서드로 객체의 동작을 정했습니다. 상속을 사용하면 기존 클래스의 초기화와 메서드를 이어받고 필요한 부분을 바꿀 수 있습니다.

자식 클래스에서 작성하지 않은 summary()가 실행되는 이유를 보고, 부모 초기화와 메서드 재정의를 구별합니다.

읽고 나면상속·부모 초기화·메서드 재정의의 실행 관계를 설명합니다.

먼저 익힐 개념 · 객체의 행동에 이름 붙이기

01

공통 속성과 행동 이어받기

상속은 기존 클래스의 속성과 메서드를 다른 클래스가 이어받는 방식입니다. 부모 클래스는 공통 규칙을 제공하고 자식 클래스는 그 규칙을 바탕으로 정의됩니다.

class BirdObservation(Observation)은 새 종류가 Observation의 한 종류임을 나타냅니다. 자식 클래스에 같은 이름이 없으면 부모에서 메서드를 찾습니다.

Pythoninheritance.py
01class Observation:02    def __init__(self, count):03        self.count = count04    def summary(self):05        return f"관찰 {self.count}개"06 07class BirdObservation(Observation):08    pass09 10record = BirdObservation(4)11print(record.summary())12print(isinstance(record, Observation))

02

부모 초기화 후 새 정보 더하기

자식에서 __init__을 정의하면 부모의 __init__이 자동으로 추가 실행되는 것은 아닙니다. super().__init__(...)으로 공통 초기화를 호출한 뒤 자식의 정보를 설정할 수 있습니다.

super()는 메서드 탐색 순서에서 다음 구현에 접근하는 도구입니다. 이 단일 상속 예제에서는 부모 Observation의 초기화를 호출합니다.

Pythoninheritance.py
01class Observation:02    def __init__(self, count):03        self.count = count04 05class BirdObservation(Observation):06    def __init__(self, count, species):07        super().__init__(count)08        self.species = species09 10record = BirdObservation(4, "참새")11print(record.count, record.species)

실행 결과

4 참새
03

같은 메서드 이름에 새 행동 제공하기

재정의는 자식 클래스에서 부모와 같은 이름의 메서드를 정의해 동작을 바꾸는 일입니다. record.summary()를 호출하면 자식의 구현을 먼저 찾습니다.

자식 구현 안에서 super().summary()를 호출하면 공통 결과에 글을 덧붙일 수 있습니다. 호출자는 계속 summary()로 문자열을 받으므로 입력과 반환의 약속을 유지합니다.

Pythoninheritance.py
01class Observation:02    def summary(self):03        return "현장 기록"04 05class BirdObservation(Observation):06    def summary(self):07        return super().summary() + " / 조류"08 09print(Observation().summary())10print(BirdObservation().summary())

잠깐, 머릿속으로 실행해 보세요.

자식 클래스가 __init__을 새로 정의한 경우 부모 초기화를 실행하려면 무엇을 하나요?

  1. 항상 자동으로 추가 실행되므로 아무것도 하지 않습니다.
  2. super().__init__(...)을 호출합니다.
  3. 부모 클래스 이름을 문자열로 출력합니다.

답을 떠올린 뒤, 아래의 설명과 비교해 보세요.

정답super().__init__(...)을 호출합니다.

오답: 항상 자동으로 추가 실행되므로 아무것도 하지 않습니다.자식이 초기화를 재정의하면 필요한 부모 초기화를 명시해야 합니다.

정답: super().__init__(...)을 호출합니다.부모의 공통 상태를 초기화하고 자식 상태를 추가할 수 있습니다.

오답: 부모 클래스 이름을 문자열로 출력합니다.이름 출력은 초기화 메서드를 실행하지 않습니다.

기억할 한 가지

상속은 부모의 계약을 이어받는 관계이며, 단순히 코드가 비슷하다는 이유만으로 사용하지 않습니다.
