모듈을 불러와 연결하기

49의 제곱근을 구하려 합니다. 계산 방법을 새로 작성하지 않고 Python에 들어 있는 도구를 부를 수 있을까요?

calculation.sqrt(49)→7.0

함수를 만들어 재사용했습니다. 이제 다른 파일이나 표준 라이브러리에 있는 함수가 어디에 정의돼 있는지 지정해 가져옵니다.

math의 계산 도구를 호출하고 직접 만든 파일도 연결합니다. 리스트와 수치 배열이 어떤 작업에 쓰이는지도 구별합니다.

읽고 나면모듈 가져오기·자체 모듈 연결·리스트와 수치 배열의 차이를 설명합니다.

01

표준 라이브러리의 도구 사용하기

제곱근을 직접 계산하는 함수를 만들 수도 있지만, Python에는 이미 math 모듈의 sqrt()가 있습니다. 모듈은 관련 함수와 값을 이름으로 찾아 쓸 수 있게 묶은 단위입니다. import math로 가져온 뒤 math.sqrt(49)를 호출하면 7.0을 얻습니다.

아래에서는 import math as calculation으로 현재 파일에서 쓸 이름을 calculation으로 정합니다. 따라서 호출도 calculation.sqrt(49)입니다. math의 내용이나 함수 이름을 바꾼 것이 아닙니다.

from math import ceil은 ceil이라는 함수 이름을 현재 파일에서 바로 쓰게 합니다. ceil(2.2)는 2.2 이상인 가장 작은 정수 3을 반환합니다. 두 가져오기 방식의 차이는 계산 결과가 아니라 함수를 부를 때 적는 이름입니다.

Pythonmodules.py
01import math as calculation02from math import ceil03 04print(calculation.sqrt(49))05print(ceil(2.2))

02

자기 파일에서 함수 가져오기

직접 만든 함수도 다른 파일에서 쓸 수 있습니다. 아래 입력 자료의 measures.py에는 수를 두 배로 만드는 double()이 들어 있습니다. 이 파일과 실행할 파일을 같은 폴더에 두고 import measures를 실행합니다.

가져오기는 파일의 글을 복사해 붙이는 일이 아닙니다. Python이 measures 모듈을 처음 읽으며 함수 정의와 바깥 코드를 실행하고, 현재 파일에 measures라는 이름을 연결합니다. double의 본문은 아직 실행하지 않습니다. measures.double(6)으로 호출해야 6 * 2를 계산합니다.

measures.py 안의 __name__은 가져올 때 "measures", 그 파일을 직접 실행할 때 "__main__"입니다. 그래서 if __name__ == "__main__": 안에 둔 시연 출력은 가져오는 이번 예제에서 실행되지 않습니다. 먼저 아래 보조 파일의 함수와 조건을 읽은 뒤 실행 파일을 따라가세요.

모듈이 많아지면 폴더로 묶어 패키지를 만들 수 있습니다. 일반적인 패키지의 __init__.py에는 패키지를 가져올 때 실행할 초기화 코드를 둘 수 있습니다. 파일 이름을 math.py처럼 표준 모듈과 같게 지으면 의도한 모듈 대신 자기 파일을 찾을 수 있으므로 피합니다.

import measures를 실행하는 것과 measures.double(6)을 호출하는 것은 어떤 차이가 있을까요?

모듈을 가져와 함수를 준비한 뒤, 별도 호출에서 12를 계산합니다. 직접 실행용 시연 출력은 나오지 않습니다.

import 뒤에는 함수를 사용할 준비만 끝났습니다. double의 return count * 2는 measures.double(6)을 만났을 때 실행되고 12를 반환합니다.

03

리스트와 수치 배열 선택하기

array 모듈은 같은 기본 수치 자료형의 항목을 저장하는 배열을 제공합니다. array("i", ...)에서 i는 정수 저장 형식을 고르는 형식 코드입니다. 메모리 표현과 지원 범위는 형식 코드에 따라 다릅니다.

일반 작업은 리스트로 충분한 경우가 많습니다. 리스트는 다른 종류의 객체도 담고, array는 지정 수치 형식에 맞는 항목을 담습니다. 별도 설치가 필요한 NumPy 배열은 이번 과정의 범위에 포함하지 않습니다.
