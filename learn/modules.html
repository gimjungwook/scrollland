표준 라이브러리의 도구 사용하기

표준 라이브러리는 Python과 함께 제공되는 도구 묶음입니다. import math는 수학 도구의 모듈을 불러오고 math.sqrt()는 그 안의 제곱근 함수를 사용합니다.

from math import ceil은 특정 이름만 가져옵니다. as는 가져온 이름의 별칭을 정합니다. 모듈 자체에 별칭을 붙이면 어느 도구의 함수인지 호출에서 계속 확인할 수 있습니다.

Pythonmodules.py
01import math as calculation02from math import ceil03 04print(calculation.sqrt(49))05print(ceil(2.2))

실행 결과

7.0
3

자기 파일에서 함수 가져오기

.py 파일 하나도 모듈이 될 수 있습니다. 이 예제는 같은 폴더에 제공된 measures.py를 두고 실행합니다. 모듈을 처음 가져오면 함수·클래스 바깥에 있는 최상위 코드도 실행됩니다. 시연용 출력이나 입력 요청은 if __name__ == "__main__": 안에 두세요.

__name__은 파일을 직접 실행할 때 "__main__", 가져올 때는 모듈 이름입니다. measures.py의 if __name__ == "__main__"은 직접 실행한 경우에만 시연 출력을 내도록 합니다. 패키지는 보통 여러 모듈을 폴더로 묶어 구성하며 __init__.py로 초기화 코드를 둘 수 있습니다.

예제에 제공한 입력 자료

measures.py

def double(count):
    return count * 2

if __name__ == "__main__":
    print("직접 실행 시연")
Pythonmodules.py
01import measures02 03print(measures.double(6))04print(measures.__name__)

실행 결과

12

리스트와 수치 배열 선택하기

array 모듈은 같은 기본 수치 자료형의 항목을 저장하는 배열을 제공합니다. array("i", ...)에서 i는 정수 저장 형식을 고르는 형식 코드입니다. 메모리 표현과 지원 범위는 형식 코드에 따라 다릅니다.

일반 작업은 리스트로 충분한 경우가 많습니다. 리스트는 다른 종류의 객체도 담고, array는 지정 수치 형식에 맞는 항목을 담습니다. 별도 설치가 필요한 NumPy 배열은 이번 과정의 범위에 포함하지 않습니다.

Pythonmodules.py
01from array import array02 03counts = array("i", [2, 4, 6])04counts.append(8)05print(list(counts))06print(counts.typecode)07print(counts[1])

실행 결과

[2, 4, 6, 8]
i
4

import measures로 가져올 때 measures.py의 직접 실행용 예제를 막는 조건은 무엇인가요?

  1. if __name__ == "__main__":
  2. if True:
  3. if __name__ == "measures":

답을 떠올린 뒤, 아래의 설명과 비교해 보세요.

정답if __name__ == "__main__":

정답: if __name__ == "__main__":직접 실행한 파일일 때만 참이 되는 조건입니다.

오답: if True:언제나 참이므로 가져오는 순간에도 실행합니다.

오답: if __name__ == "measures":가져올 때 모듈 이름이 measures이므로 오히려 그때 실행됩니다.

기억할 한 가지

필요한 도구의 출처를 드러내고 같은 이름의 파일로 표준 모듈을 가리지 않습니다.
