표준 라이브러리의 도구 사용하기

표준 라이브러리는 Python과 함께 제공되는 도구 묶음입니다. import math는 수학 도구의 모듈을 불러오고 math.sqrt()는 그 안의 제곱근 함수를 사용합니다.

from math import ceil은 특정 이름만 가져옵니다. as는 가져온 이름의 별칭을 정합니다. 모듈 자체에 별칭을 붙이면 어느 도구의 함수인지 호출에서 계속 확인할 수 있습니다.

Python 코드

import math as calculation
from math import ceil

print(calculation.sqrt(49))
print(ceil(2.2))

실행 결과

7.0
3

이름과 객체

불러온 모듈: calculation → math · 직접 가져온 함수: ceil → math.ceil

    표준 도구를 현재 코드에서 사용할 수 있게 합니다.

    calculation
    math 모듈
    ceil
    math.ceil 함수

    이 단계의 출력: (표준 출력 없음)

  2. 호출

    제곱근과 올림 함수를 사용합니다.

    sqrt(49)
    7.0
    ceil(2.2)
    3

    이 단계의 출력: 7.0 3

자기 파일에서 함수 가져오기

.py 파일 하나도 모듈이 될 수 있습니다. 이 예제는 같은 폴더에 제공된 measures.py를 두고 실행합니다. 모듈을 처음 가져오면 함수·클래스 바깥에 있는 최상위 코드도 실행됩니다. 시연용 출력이나 입력 요청은 if __name__ == "__main__": 안에 두세요.

__name__은 파일을 직접 실행할 때 "__main__", 가져올 때는 모듈 이름입니다. measures.py의 if __name__ == "__main__"은 직접 실행한 경우에만 시연 출력을 내도록 합니다. 패키지는 보통 여러 모듈을 폴더로 묶어 구성하며 __init__.py로 초기화 코드를 둘 수 있습니다.

Python 코드

import measures

print(measures.double(6))
print(measures.__name__)

실행 결과

12

리스트와 수치 배열 선택하기

array 모듈은 같은 기본 수치 자료형의 항목을 저장하는 배열을 제공합니다. array("i", ...)에서 i는 정수 저장 형식을 고르는 형식 코드입니다. 메모리 표현과 지원 범위는 형식 코드에 따라 다릅니다.

일반 작업은 리스트로 충분한 경우가 많습니다. 리스트는 다른 종류의 객체도 담고, array는 지정 수치 형식에 맞는 항목을 담습니다. 별도 설치가 필요한 NumPy 배열은 이번 과정의 범위에 포함하지 않습니다.

Python 코드

from array import array

counts = array("i", [2, 4, 6])
counts.append(8)
print(list(counts))
print(counts.typecode)
print(counts[1])

실행 결과

[2, 4, 6, 8]
i
4

값의 구성

리스트 선택: 일반 객체 묶음에 사용 · array 선택: 정해진 기본 수치 형식으로 저장

  1. 배열 생성

    정수 형식 i의 배열을 만듭니다.

    counts
    array("i", [2, 4, 6])

    이 단계의 출력: (표준 출력 없음)

    같은 형식의 수량을 추가하고 위치로 읽습니다.

    counts
    [2, 4, 6, 8]
    typecode
    i
    counts[1]
    4

    이 단계의 출력: [2, 4, 6, 8] i 4
