01

한 종류의 객체 만들기

객체 지향은 관련 데이터와 그 데이터를 다루는 행동을 객체 중심으로 구성하는 방식입니다. 클래스는 객체의 속성과 행동을 정의하는 규칙이며 class로 작성합니다.

Observation()처럼 클래스를 호출하면 인스턴스라는 개별 객체를 만듭니다. pass는 이 첫 예제의 빈 클래스 본문을 문법적으로 채웁니다. isinstance()는 객체가 지정한 종류에 속하는지 확인합니다.

Python 코드

Python 3.10+
class Observation:
    pass

first = Observation()
second = Observation()
print(isinstance(first, Observation))
print(first is second)

예제 실행 결과

True
False

    Observation이라는 종류를 정의합니다.

  2. 2

02

생성할 때 상태 준비하기

속성은 객체에 붙어 있는 이름과 값입니다. __init__은 새 인스턴스가 만들어진 뒤 초기 상태를 설정할 때 자동 호출되는 메서드입니다. 그 자체가 새 객체를 반환하는 함수는 아닙니다.

self는 현재 인스턴스를 받는 첫 매개변수의 관례적 이름입니다. self.place = place에서 왼쪽은 객체 속성이고 오른쪽은 전달받은 지역 매개변수입니다. 클래스를 호출할 때 self 인자는 직접 넣지 않습니다.

Python 코드

Python 3.10+
class Observation:
    def __init__(self, place, count):
        self.place = place
        self.count = count

record = Observation("숲", 4)
print(record.place)
print(record.count)

예제 실행 결과

숲
4

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    인스턴스 생성

    새 객체를 만들고 __init__을 호출합니다.

  2. 2

    초기화

    전달한 값으로 속성을 설정합니다.

03

개별 객체의 상태 구별하기

같은 클래스로 만든 객체도 인스턴스 속성은 각자 갖습니다. first.count를 바꾸면 second.count까지 자동으로 바뀌지는 않습니다.

다만 같은 변경 가능한 객체를 두 속성에 연결하면 그 안의 내용은 공유할 수 있습니다. 리스트에서 배운 이름과 객체의 연결 규칙이 속성에도 적용됩니다.

Python 코드

Python 3.10+
class Observation:
    def __init__(self, place, count):
        self.place = place
        self.count = count

first = Observation("숲", 4)
second = Observation("강", 2)
first.count += 1
print(first.place, first.count)
print(second.place, second.count)

예제 실행 결과

숲 5
강 2

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    초기 상태

    서로 다른 인스턴스에 수량 4와 2가 있습니다.

  2. 2

    개별 갱신

    first.count만 5로 바뀝니다.

코드를 읽고, 한 번 예측하기

__init__(self, place)에서 self는 무엇을 가리키나요?

정답과 모든 선택지의 해설 읽기
  1. 정답: 현재 초기화하는 인스턴스

    현재 객체의 속성을 설정하기 위해 인스턴스를 첫 인자로 받습니다.

  2. 오답: 모든 클래스를 한 번에 담은 리스트

    self는 현재 호출 대상인 개별 객체입니다.

  3. 오답: 호출자가 매번 직접 넣어야 할 문자열

    클래스 호출 시 Python이 인스턴스를 전달하므로 직접 넣지 않습니다.

기억할 내용

클래스는 같은 종류의 객체를 만들 규칙이고, 인스턴스는 그 규칙으로 만든 개별 객체입니다.
