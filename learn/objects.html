데이터와 행동을 객체로 묶기

숲의 기록은 4마리, 강의 기록은 2마리입니다. 숲에 한 마리를 더했을 때 강의 수량은 그대로 두려면요?

first.count += 1→숲: 5 · 강: 2

값에는 이름을 붙이고 작업은 함수로 묶었습니다. 클래스로는 같은 구조의 객체를 여러 개 만들고 각자의 값을 둘 수 있습니다.

한 클래스에서 만든 두 객체를 구별하고, 초기화와 self가 어느 객체의 장소·수량을 다루는지 확인합니다.

읽고 나면클래스·인스턴스·초기화·self의 관계를 설명합니다.

먼저 익힐 개념 · 값에 이름을 연결하기 · 계산에 이름을 붙여 재사용하기

01

한 종류의 객체 만들기

객체 지향은 관련 데이터와 그 데이터를 다루는 행동을 객체 중심으로 구성하는 방식입니다. 클래스는 객체의 속성과 행동을 정의하는 규칙이며 class로 작성합니다.

Observation()처럼 클래스를 호출하면 인스턴스라는 개별 객체를 만듭니다. pass는 이 첫 예제의 빈 클래스 본문을 문법적으로 채웁니다. isinstance()는 객체가 지정한 종류에 속하는지 확인합니다.

first와 second는 같은 규칙으로 만들었지만 서로 다른 두 객체입니다. isinstance(first, Observation)는 종류를 물어 True이고, first is second는 바로 그 하나의 객체인지 물어 False입니다.

02

생성할 때 상태 준비하기

한 관찰 기록에는 장소와 수량이 함께 필요합니다. record.place와 record.count처럼 객체에 이름을 붙여 저장한 값을 속성이라고 합니다. Observation("숲", 4)로 새 기록을 만들 때 두 속성도 준비해 보겠습니다.

클래스를 호출해 새 인스턴스가 만들어지면 __init__이 초기 상태를 설정합니다. 이때 self에는 바로 그 새 인스턴스가, place에는 "숲"이, count에는 4가 전달됩니다. 호출하는 쪽은 self 인자를 직접 쓰지 않습니다.

self.place = place의 왼쪽은 새 객체에 남길 속성이고, 오른쪽 place는 이번 호출로 받은 값입니다. 다음 줄도 같은 방식으로 수량을 저장합니다. 초기화가 끝나면 바깥의 record가 준비된 객체를 가리킵니다. __init__ 자체가 새 객체를 반환하는 함수는 아닙니다.

place라는 이름이 두 번 나오는데, 어느 값이 객체에 남을까요?

객체의 구조01 / 05

01class Observation:02    def __init__(self, place, count):03        self.place = place04        self.count = count05 06record = Observation("숲", 4)07print(record.place)08print(record.count)

초기화에 전달한 장소와 수량이 객체의 속성으로 남아 record에서 다시 읽힙니다.

place와 count는 초기화 호출의 입력입니다. self.place와 self.count는 그 값을 객체에 남긴 속성이므로 초기화 호출이 끝난 뒤에도 record로 읽을 수 있습니다.

self는 다른 객체를 추가로 만든 이름이 아닙니다. 초기화 중의 self와 초기화 후의 record가 같은 새 인스턴스를 가리킵니다.

03

개별 객체의 상태 구별하기

같은 클래스로 만든 객체도 인스턴스 속성은 각자 갖습니다. first.count를 바꾸면 second.count까지 자동으로 바뀌지는 않습니다.

다만 같은 변경 가능한 객체를 두 속성에 연결하면 그 안의 내용은 공유할 수 있습니다. 리스트에서 배운 이름과 객체의 연결 규칙이 속성에도 적용됩니다.

6·7행은 초기화를 각각 한 번씩 호출합니다. 그래서 처음 수량은 first가 4, second가 2입니다. 8행은 first의 수량만 5로 바꾸므로 아래 두 출력에서 숲의 수만 증가합니다.

Pythonobjects.py
01class Observation:02    def __init__(self, place, count):03        self.place = place04        self.count = count05 06first = Observation("숲", 4)07second = Observation("강", 2)08first.count += 109print(first.place, first.count)10print(second.place, second.count)
