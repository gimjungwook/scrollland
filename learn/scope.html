01

함수 안 이름과 바깥 이름

이름 범위는 이름을 찾아 사용할 수 있는 영역입니다. 함수 안에서 대입한 지역 이름은 보통 그 함수 안에서만 유효합니다. 모듈의 바깥 수준 이름은 전역 이름입니다.

지역 이름이 있으면 같은 철자의 전역 이름보다 먼저 찾습니다. 아래 count = 2는 함수의 지역 이름을 만들며, 전역 count = 10을 바꾸지 않습니다.

Python 코드

Python 3.10+
count = 10
def local_count():
    count = 2
    return count

print(local_count())
print(count)

예제 실행 결과

2
10

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    호출 중

    함수 안의 count는 지역 값 2입니다.

  2. 2

    호출 후

    바깥 count는 10을 유지합니다.

02

전역 변경이 필요한지 먼저 판단하기

global은 이 함수에서 해당 이름을 전역 이름으로 다루겠다는 선언입니다. 아래 함수는 전역 calls의 값을 바꿉니다.

전역 상태에 의존하면 호출 순서에 따라 결과가 달라집니다. 보통은 값을 인자로 받고 반환하는 방식이 관계를 더 분명히 드러냅니다. 공유 상태가 필요한지 먼저 결정하세요.

Python 코드

Python 3.10+
calls = 0
def record_call():
    global calls
    calls += 1

record_call()
record_call()
print(calls)

예제 실행 결과

2

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    global 선언

    지역 이름을 새로 만들지 않습니다.

  2. 2

    공유 상태 갱신

    두 호출이 같은 전역 이름을 바꿉니다.

03

바깥 함수의 값을 기억하기

함수 안에 함수를 정의할 수 있습니다. 안쪽 함수가 바깥 함수의 지역 이름을 계속 사용하는 구조를 클로저라고 부릅니다. nonlocal은 가장 가까운 바깥 함수의 이름을 재대입하게 합니다.

여기서 count는 전역이 아닙니다. make_counter() 호출마다 별도 count가 생기며, 반환한 add 함수는 자기 count를 사용합니다. 괄호 없이 add를 반환하므로 그때 실행하지는 않습니다.

Python 코드

Python 3.10+
def make_counter():
    count = 0
    def add():
        nonlocal count
        count += 1
        return count
    return add

first = make_counter()
second = make_counter()
print(first(), first(), second())

예제 실행 결과

1 2 1

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    첫 생성

    first가 사용할 count=0을 준비합니다.

  2. 2

    둘째 생성

    second가 사용할 별도 count=0을 준비합니다.

  3. 3

    호출 결과

    first는 두 번, second는 한 번 증가합니다.

원할 때 확인하세요

코드를 읽고, 한 번 예측하기

nonlocal count는 어떤 이름을 변경하도록 하나요?

정답과 모든 선택지의 해설 읽기
  1. 오답: 어디서나 같은 전역 count

    전역 이름을 지정하는 선언은 global입니다.

  2. 오답: 현재 함수만의 새 count

    nonlocal은 현재 함수에 새 지역 이름을 만들지 않습니다.

  3. 정답: 가장 가까운 바깥 함수의 count

    전역을 제외한 바깥 함수 범위의 기존 이름을 재대입합니다.

기억할 내용

같은 철자의 이름도 정의된 범위에 따라 다른 연결일 수 있습니다.
