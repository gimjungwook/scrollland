한 줄로 말을 건네기

Python은 컴퓨터가 실행할 지시를 적는 프로그래밍 언어입니다. 코드는 그 언어로 작성한 지시이고, 실행은 컴퓨터가 지시를 수행하는 일입니다.

print()는 괄호 안의 값을 출력하는 함수입니다. 함수는 이름으로 부르는 작업 묶음입니다. 문자열은 따옴표로 둘러싼 글이며, 출력에는 바깥 따옴표가 나타나지 않습니다.

Python 코드

print("오늘의 관찰을 시작합니다")

실행 결과

오늘의 관찰을 시작합니다

실행 순서

코드: print("오늘의 관찰을 시작합니다") · 출력: 오늘의 관찰을 시작합니다

  1. 호출 전

    아직 출력이 없습니다.

    출력
    아직 없음

    이 단계의 출력: (표준 출력 없음)

  2. 호출 후

    괄호 안 글이 출력에 한 줄 남습니다.

    print
    문자열 한 줄

    이 단계의 출력: 오늘의 관찰을 시작합니다

결과와 관계 확인

출력한 한 줄
오늘의 관찰을 시작합니다

위에서 아래로 읽기

각 줄의 지시는 특별한 흐름 변경이 없으면 위에서 아래로 실행됩니다. 숫자의 덧셈은 +로 적으며, 먼저 계산한 결과를 print()에 전달합니다.

#부터 줄 끝까지는 사람이 읽는 주석입니다. 주석은 결과를 바꾸지 않습니다. 글의 따옴표 안에 있는 #은 주석이 아니라 글의 일부입니다.

Python 코드

# 관찰한 새의 수를 더합니다
print(4 + 3)
print("기록 #1")

실행 결과

7
기록 #1

실행 순서

첫 지시: 4 + 3을 계산하고 7 출력 · 다음 지시: 기록 #1 출력

  1. 주석 줄

    Python은 이 줄의 설명을 실행하지 않습니다.

    주석
    실행하지 않는 설명

    이 단계의 출력: (표준 출력 없음)

  2. 두 번째 줄

    덧셈 결과 7을 출력합니다.

    4 + 3
    7

    이 단계의 출력: 7

  3. 세 번째 줄

    문자열을 출력하고 다음 줄로 이동합니다.

    문자열
    기록 #1

    이 단계의 출력: 7 기록 #1
