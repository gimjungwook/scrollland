처음 실행하고 결과 읽기

따옴표와 괄호가 들어간 지시 한 줄, 화면에는 어느 부분이 나타날까요?

print("오늘의 관찰을 시작합니다")→오늘의 관찰을 시작합니다

Python을 처음 본다고 가정합니다. 먼저 컴퓨터에 적는 지시와 그 지시가 만든 결과를 나란히 읽습니다.

안내문을 출력한 뒤 지시를 여러 줄로 늘려, 컴퓨터가 어느 순서로 결과를 내놓는지 확인합니다.

읽고 나면코드와 출력을 구분하고 세 줄의 실행 순서를 설명합니다.

01

처음에는 결과부터 읽어 봅니다

짧은 지시 한 줄이 화면에 어떤 글을 남기는지부터 살펴보겠습니다. 예제의 코드와 출력은 이미 함께 준비되어 있으므로, 설치하거나 버튼을 누르지 않고 아래로 읽어 가면 됩니다.

02

한 줄로 말을 건네기

컴퓨터에 “오늘의 관찰을 시작합니다”라는 안내를 표시해 달라고 해 보겠습니다. Python은 이런 지시를 적는 언어이고, 그 언어로 적은 글을 코드라고 부릅니다. 컴퓨터가 코드를 따라 작업하는 것이 실행입니다.

아래 코드에서 print는 화면에 값을 표시하는 작업의 이름입니다. 괄호 안에는 표시할 값을 적습니다. 여기서는 “오늘의 관찰을 시작합니다”라는 글을 건넵니다.

코드의 큰따옴표는 글의 시작과 끝을 표시합니다. 이렇게 따옴표로 적은 글을 문자열이라고 부릅니다. 바깥 따옴표와 print라는 이름은 출력할 글에 포함되지 않습니다. print처럼 이름을 불러 사용하는 작업은 함수라고 하며, 지금은 쓰는 방법부터 익히면 됩니다.

03

위에서 아래로 읽기

여러 줄을 적으면 Python은 위의 지시부터 차례로 처리합니다. 아래에서 첫 줄은 #으로 시작합니다. 따옴표 밖의 # 뒤에 적은 내용은 사람이 읽는 메모인 주석이므로, 화면에 표시할 지시로 실행하지 않습니다.

둘째 줄의 4 + 3에는 따옴표가 없습니다. 글 “4 + 3”을 표시하는 대신, 먼저 덧셈으로 7을 구하고 print가 그 7을 출력합니다. 셋째 줄은 따옴표 안의 글 “기록 #1”을 그대로 출력합니다. 이때 #은 글의 일부라서 사라지지 않습니다.

주석은 실행할 지시가 아닙니다. 덧셈 결과 7을 먼저 출력한 뒤 문자열 기록 #1을 다음 줄에 출력합니다.

코드 줄 번호 2와 출력 줄 번호 1은 다릅니다. 주석처럼 출력하지 않는 줄도 있기 때문입니다.

print(4 + 3)은 계산한 값 7을 출력합니다. print("4 + 3")처럼 따옴표로 감싸면 계산하지 않고 글 4 + 3을 출력합니다.

04

직접 실행할 준비

지금까지는 이 페이지에 준비된 코드와 결과를 읽었습니다. 그림은 Python을 실행하는 화면이 아니라, 실제 실행으로 확인한 과정을 설명하는 자료입니다. 이 레슨을 읽는 데 설치는 필요하지 않습니다.

직접 코드를 바꾸어 시험해 보고 싶다면 Python 3.10 이상을 설치합니다. 텍스트 편집기에서 새 파일을 만들고 아래 세 줄을 적어 practice.py라는 이름으로 저장하세요. .py는 Python 코드 파일에 붙이는 확장자입니다.

터미널은 명령을 입력하는 창입니다. practice.py를 저장한 폴더에서 macOS·Linux는 python3 practice.py, Windows는 py practice.py를 입력해 실행합니다. 설치 환경에 따라 명령 이름이나 경로 설정이 다를 수 있습니다. 실행되면 아래의 세 줄이 위에서 아래로 출력됩니다.

문법은 코드를 적는 규칙입니다. 따옴표나 괄호를 짝에 맞게 닫지 않으면 Python이 코드를 해석할 수 없어 문법 오류를 표시합니다. 먼저 세 줄을 그대로 실행해 결과를 비교하고, 그다음 숫자를 바꿔 보세요.
