01

한 줄로 말을 건네기

Python은 컴퓨터가 실행할 지시를 적는 프로그래밍 언어입니다. 코드는 그 언어로 작성한 지시이고, 실행은 컴퓨터가 지시를 수행하는 일입니다.

print()는 괄호 안의 값을 출력하는 함수입니다. 함수는 이름으로 부르는 작업 묶음입니다. 문자열은 따옴표로 둘러싼 글이며, 출력에는 바깥 따옴표가 나타나지 않습니다.

Python 코드

Python 3.10+
print("오늘의 관찰을 시작합니다")

예제 실행 결과

오늘의 관찰을 시작합니다

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    호출 전

    아직 출력이 없습니다.

  2. 2

    호출 후

    괄호 안 글이 출력에 한 줄 남습니다.

02

위에서 아래로 읽기

각 줄의 지시는 특별한 흐름 변경이 없으면 위에서 아래로 실행됩니다. 숫자의 덧셈은 +로 적으며, 먼저 계산한 결과를 print()에 전달합니다.

#부터 줄 끝까지는 사람이 읽는 주석입니다. 주석은 결과를 바꾸지 않습니다. 글의 따옴표 안에 있는 #은 주석이 아니라 글의 일부입니다.

Python 코드

Python 3.10+
# 관찰한 새의 수를 더합니다
print(4 + 3)
print("기록 #1")

예제 실행 결과

7
기록 #1

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    주석 줄

    Python은 이 줄의 설명을 실행하지 않습니다.

  2. 2

    두 번째 줄

    덧셈 결과 7을 출력합니다.

  3. 3

    세 번째 줄

    문자열을 출력하고 다음 줄로 이동합니다.

03

직접 실행할 준비

이 사이트에서는 설명과 검증한 출력을 읽습니다. 코드가 브라우저에서 실행되는 것은 아닙니다. 직접 실험하려면 Python 3.10 이상을 설치하고, 텍스트 편집기로 practice.py라는 파일에 아래 코드를 저장합니다.

터미널은 명령을 입력하는 창입니다. 파일이 있는 폴더에서 macOS·Linux는 python3 practice.py, Windows는 py practice.py로 실행합니다. Python의 문법은 코드 작성 규칙이며 괄호나 따옴표가 빠지면 문법 오류가 납니다. 아래 출력과 한 줄씩 비교하세요.

Python 코드

Python 3.10+
print("준비")
print(12 - 5)
print("끝")

예제 실행 결과

준비
7
끝

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    실행 시작

    Python이 파일의 첫 지시를 읽습니다.

  2. 2

    계산 실행

    12에서 5를 뺀 7을 출력합니다.

  3. 3

    파일 끝

    끝을 출력한 뒤 실행을 마칩니다.

원할 때 확인하세요

코드를 읽고, 한 번 예측하기

print(2 + 6)에서 출력되는 것은 무엇인가요?

정답과 모든 선택지의 해설 읽기
  1. 오답: 2 + 6

    따옴표가 없으므로 글을 그대로 출력하지 않고 덧셈부터 계산합니다.

  2. 정답: 8

    2 + 6을 계산한 값 8을 print()가 출력합니다.

  3. 오답: "8"

    계산 결과는 숫자이며, print()는 숫자에 따옴표를 붙이지 않습니다.
