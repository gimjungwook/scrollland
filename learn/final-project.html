01

한 줄의 입력 계약 정하기

입력은 장소:수량 형식으로 정하고, 장소는 비어 있지 않아야 하며 수량은 0 이상인 정수여야 합니다. parse_line은 그 계약을 확인해 장소와 수량의 튜플을 반환합니다.

문자열에 콜론이 정확히 하나 있다는 조건도 검사합니다. int() 자체가 발생시키는 ValueError도 호출자가 처리할 수 있습니다. 먼저 한 줄을 함수로 검증하면 여러 줄 처리와 파일 저장에서 같은 규칙을 재사용합니다.

Python 코드

Python 3.10+
def parse_line(line):
    parts = line.strip().split(":")
    if len(parts) != 2 or not parts[0].strip():
        raise ValueError("장소:수량 형식이 필요합니다")
    place = parts[0].strip()
    count = int(parts[1])
    if count < 0:
        raise ValueError("수량은 0 이상이어야 합니다")
    return place, count

print(parse_line(" 숲 : 4 "))
try:
    parse_line("강:-1")
except ValueError as error:
    print(error)

02

유효한 줄만 장소별로 더하기

여러 줄을 처리할 때는 실패한 줄 번호와 이유를 남기고 다음 줄로 진행할지 정합니다. 여기서는 오류를 보고한 뒤 다음 줄을 계속 처리하는 규칙을 선택합니다.

totals.get(place, 0)은 첫 기록의 기본 합계이고, 다음 기록부터는 기존 합계에 더합니다. 계산 결과와 오류 목록을 따로 보관하면 잘못된 입력을 정상 수량으로 오해하지 않습니다.

Python 코드

Python 3.10+
def parse_line(line):
    parts = line.strip().split(":")
    if len(parts) != 2 or not parts[0].strip():
        raise ValueError("장소:수량 형식이 필요합니다")
    count = int(parts[1])
    if count < 0:
        raise ValueError("수량은 0 이상이어야 합니다")
    return parts[0].strip(), count

totals = {}
errors = []
for number, line in enumerate(["숲:4", "강:2", "숲:3", "못:-1"], start=1):
    try:
        place, count = parse_line(line)
    except ValueError as error:
        errors.append(f"{number}행: {error}")
        continue
    totals[place] = totals.get(place, 0) + count
print(totals)
print(errors[0])

예제 실행 결과

{'숲': 7, '강': 2}
4행: 수량은 0 이상이어야 합니다

  1. 1

    정상 줄 처리

    장소별 딕셔너리에 합계를 누적합니다.

  2. 2

    실패 줄 처리

    오류를 기록하고 그 수량은 누적하지 않습니다.

  3. 3

    결과 확인

    숲 7, 강 2와 오류 1건을 구별합니다.

03

저장한 파일을 다시 읽어 대조하기

마지막 예제는 입력 파일을 읽고 같은 검증 규칙으로 집계한 뒤 summary.json에 저장합니다. 파일은 모두 새 임시 폴더에서 만들므로 실제 기록에 영향을 주지 않습니다.

쓰기 호출이 끝난 것만 확인하지 않고 파일을 다시 읽어 예상 구조와 같은지 비교합니다. 오류 건수도 요약에 남깁니다. 직접 확장할 때는 입력 경로, 덮어쓰기 정책, 허용 형식을 먼저 정하세요.

splitlines()는 읽은 문자열을 줄바꿈을 제외한 줄 목록으로 나눕니다. json.dump(객체, 열린 파일)은 JSON을 그 파일에 씁니다. 앞에서 배운 dumps()는 JSON 문자열을 반환하므로 결과를 받을 대상이 다릅니다.

Python 코드

Python 3.10+
import json
from pathlib import Path
from tempfile import TemporaryDirectory

def parse_line(line):
    parts = line.strip().split(":")
    if len(parts) != 2 or not parts[0].strip():
        raise ValueError("장소:수량 형식이 필요합니다")
    count = int(parts[1])
    if count < 0:
        raise ValueError("수량은 0 이상이어야 합니다")
    return parts[0].strip(), count

with TemporaryDirectory() as folder:
    root = Path(folder)
    source = root / "observations.txt"
    source.write_text("숲:4\n강:2\n숲:3\n못:-1\n", encoding="utf-8")
    totals = {}
    errors = []
    for number, line in enumerate(source.read_text(encoding="utf-8").splitlines(), start=1):
        try:
            place, count = parse_line(line)
        except ValueError as error:
            errors.append({"line": number, "reason": str(error)})
            continue
        totals[place] = totals.get(place, 0) + count
    summary = {"totals": totals, "error_count": len(errors)}
    target = root / "summary.json"
    with target.open("x", encoding="utf-8") as output:
        json.dump(summary, output, ensure_ascii=False)
    restored = json.loads(target.read_text(encoding="utf-8"))
    print(restored["totals"])
    print(restored["error_count"])
    print(restored == summary)

코드를 읽고, 한 번 예측하기

최종 결과에서 숲:4와 숲:3은 어떻게 처리하고 못:-1은 어떻게 처리하나요?

정답과 모든 선택지의 해설 읽기
  1. 정답: 숲은 7로 합치고, 못의 음수는 오류로 기록해 합계에서 제외합니다.

    수량 계약을 통과한 줄만 합계에 반영하고 실패를 따로 남깁니다.

  2. 오답: 모든 값을 더해 전체 6만 저장합니다.

    이 실습은 장소별로 집계하고 음수 입력은 허용하지 않습니다.

  3. 오답: 오류가 한 건 있으므로 정상 기록도 설명 없이 모두 버립니다.

    정한 규칙은 오류를 기록하고 다음 줄을 계속 처리하는 것입니다.
