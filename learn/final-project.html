관찰 기록을 읽고 요약해 저장하기

숲:4, 강:2, 숲:3, 못:-1이 함께 들어왔습니다. 잘못된 줄 하나를 빼고 어떤 합계를 파일에 남겨야 할까요?

숲:4 · 강:2 · 숲:3 · 못:-1→숲:7 · 강:2 · 오류 1건

문자열 정리·딕셔너리·반복·함수·예외·파일 처리를 배웠습니다. 이 도구들을 입력 검증, 합계 계산, 저장이라는 한 작업에 연결합니다.

숲 7, 강 2와 오류 한 건을 따로 기록하고, 저장한 JSON을 다시 읽어 원래 요약과 같은지 확인합니다.

읽고 나면입력 검증·집계·JSON 저장을 각각 검증 가능한 단계로 연결합니다.

먼저 익힐 개념 · 입력한 글을 정리하기 · 이름표로 값 찾기 · 건너뛸 때와 멈출 때 정하기 · 계산에 이름을 붙여 재사용하기 · 다른 도구에서도 읽을 수 있는 기록 만들기 · 예외를 구별해 처리하기 · 파일을 만들고 안전하게 정리하기

01

작은 규칙을 하나의 작업으로 연결하기

이제 장소와 수량이 적힌 여러 줄을 읽어 장소별 합계를 만들고 파일에 남깁니다. 앞에서 읽은 문자열 처리, 딕셔너리, 함수, 예외, 파일 처리를 한 작업에 연결합니다.

입력을 읽었다는 사실만으로 올바른 기록이라고 볼 수는 없습니다. 먼저 허용할 입력을 정하고, 실패한 줄을 구분한 뒤, 저장한 결과를 다시 읽어 확인하겠습니다.

02

한 줄의 입력 계약 정하기

입력은 장소:수량 형식으로 정하고, 장소는 비어 있지 않아야 하며 수량은 0 이상인 정수여야 합니다. parse_line은 그 계약을 확인해 장소와 수량의 튜플을 반환합니다.

문자열에 콜론이 정확히 하나 있다는 조건도 검사합니다. int() 자체가 발생시키는 ValueError도 호출자가 처리할 수 있습니다. 먼저 한 줄을 함수로 검증하면 여러 줄 처리와 파일 저장에서 같은 규칙을 재사용합니다.

Pythonfinal-project.py
01def parse_line(line):02    parts = line.strip().split(":")03    if len(parts) != 2 or not parts[0].strip():04        raise ValueError("장소:수량 형식이 필요합니다")05    place = parts[0].strip()06    count = int(parts[1])07    if count < 0:08        raise ValueError("수량은 0 이상이어야 합니다")09    return place, count10 11print(parse_line(" 숲 : 4 "))12try:13    parse_line("강:-1")14except ValueError as error:15    print(error)

03

유효한 줄만 장소별로 더하기

여러 줄을 처리할 때는 실패한 줄 번호와 이유를 남기고 다음 줄로 진행할지 정합니다. 여기서는 오류를 보고한 뒤 다음 줄을 계속 처리하는 규칙을 선택합니다.

totals.get(place, 0)은 첫 기록의 기본 합계이고, 다음 기록부터는 기존 합계에 더합니다. 계산 결과와 오류 목록을 따로 보관하면 잘못된 입력을 정상 수량으로 오해하지 않습니다.

Pythonfinal-project.py
01def parse_line(line):02    parts = line.strip().split(":")03    if len(parts) != 2 or not parts[0].strip():04        raise ValueError("장소:수량 형식이 필요합니다")05    count = int(parts[1])06    if count < 0:07        raise ValueError("수량은 0 이상이어야 합니다")08    return parts[0].strip(), count09 10totals = {}11errors = []12for number, line in enumerate(["숲:4", "강:2", "숲:3", "못:-1"], start=1):13    try:14        place, count = parse_line(line)15    except ValueError as error:16        errors.append(f"{number}행: {error}")17        continue18    totals[place] = totals.get(place, 0) + count19print(totals)20print(errors[0])

04

저장한 파일을 다시 읽어 대조하기

마지막 예제는 입력 파일을 읽고 같은 검증 규칙으로 집계한 뒤 summary.json에 저장합니다. 파일은 모두 새 임시 폴더에서 만들므로 실제 기록에 영향을 주지 않습니다.

쓰기 호출이 끝난 것만 확인하지 않고 파일을 다시 읽어 예상 구조와 같은지 비교합니다. 오류 건수도 요약에 남깁니다. 직접 확장할 때는 입력 경로, 덮어쓰기 정책, 허용 형식을 먼저 정하세요.

splitlines()는 읽은 문자열을 줄바꿈을 제외한 줄 목록으로 나눕니다. json.dump(객체, 열린 파일)은 JSON을 그 파일에 씁니다. 앞에서 배운 dumps()는 JSON 문자열을 반환하므로 결과를 받을 대상이 다릅니다.

Pythonfinal-project.py
01import json02from pathlib import Path03from tempfile import TemporaryDirectory04 05def parse_line(line):06    parts = line.strip().split(":")07    if len(parts) != 2 or not parts[0].strip():08        raise ValueError("장소:수량 형식이 필요합니다")09    count = int(parts[1])10    if count < 0:11        raise ValueError("수량은 0 이상이어야 합니다")12    return parts[0].strip(), count13 14with TemporaryDirectory() as folder:15    root = Path(folder)16    source = root / "observations.txt"17    source.write_text("숲:4\n강:2\n숲:3\n못:-1\n", encoding="utf-8")18    totals = {}19    errors = []20    for number, line in enumerate(source.read_text(encoding="utf-8").splitlines(), start=1):21        try:22            place, count = parse_line(line)23        except ValueError as error:24            errors.append({"line": number, "reason": str(error)})25            continue26        totals[place] = totals.get(place, 0) + count27    summary = {"totals": totals, "error_count": len(errors)}28    target = root / "summary.json"29    with target.open("x", encoding="utf-8") as output:30        json.dump(summary, output, ensure_ascii=False)31    restored = json.loads(target.read_text(encoding="utf-8"))32    print(restored["totals"])33    print(restored["error_count"])34    print(restored == summary)

저장한 결과에서 다시 질문하기

예제에서는 한 줄의 기록이 파일에 남았습니다. 저장한 파일을 다시 읽었을 때 같은 합계와 오류 건수가 확인되는지까지 살폈습니다.

자신의 기록으로 확장한다면 어떤 입력을 거절할지, 오류 뒤에 계속할지, 기존 파일을 어떻게 보존할지부터 정해 보세요. 코드를 실행했다는 사실과 결과가 목적에 맞는지는 서로 다른 확인입니다.

잠깐, 머릿속으로 실행해 보세요.

최종 결과에서 숲:4와 숲:3은 어떻게 처리하고 못:-1은 어떻게 처리하나요?

  1. 숲은 7로 합치고, 못의 음수는 오류로 기록해 합계에서 제외합니다.
  2. 모든 값을 더해 전체 6만 저장합니다.
  3. 오류가 한 건 있으므로 정상 기록도 설명 없이 모두 버립니다.

오답: 모든 값을 더해 전체 6만 저장합니다.이 실습은 장소별로 집계하고 음수 입력은 허용하지 않습니다.
