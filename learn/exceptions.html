예외를 구별해 처리하기

수량 칸에 6 대신 여섯이 들어왔습니다. int()의 변환이 실패해도 다음 기록을 받을 수 있을까요?

int("여섯")→ValueError → 입력 안내

문자열을 숫자로 바꾸고 조건에 따라 실행을 나눴습니다. 변환 도중 발생한 예외에는 종류에 맞는 처리 경로가 필요합니다.

ValueError를 처리한 뒤 다음 안내가 출력되는 흐름을 확인하고, 정상 경로와 정리 작업을 따로 배치합니다.

01

예상한 입력 오류에 응답하기

숫자처럼 보이는 입력도 정수로 바꿀 수 없는 경우가 있습니다. int("6")은 6을 만들지만 int("여섯")은 그 글을 숫자로 해석하지 못합니다. Python은 이런 실패를 예외로 알립니다. 이 경우의 예외 이름이 ValueError입니다.

try는 실패할 수 있는 변환을 시도하는 구간이고, except ValueError는 그 종류의 실패가 났을 때 대신 실행할 구간입니다. 변환에 실패하면 count에 값을 대입하지 못한 채 예외 처리로 이동합니다.

except에서 안내문을 출력한 뒤에는 try·except 바깥의 다음 줄을 계속 실행합니다. 실패한 변환을 자동으로 다시 하거나 글 "여섯"을 정수 6으로 고치는 것은 아닙니다. 아래 text는 미리 적어 둔 문자열이며 사이트에서 입력을 기다리지 않습니다.

처리할 수 있는 실패의 종류를 지정해야 코드 실수까지 조용히 넘어가지 않습니다. 여기서는 정수 변환에서 예상한 ValueError만 받습니다.

안내문을 낸 다음 바깥 줄을 실행할 수는 있지만 잘못된 입력이 정상 수량으로 바뀐 것은 아닙니다. 다시 수량을 받는 일은 별도 코드가 필요합니다.

02

정상 경로와 정리 구별하기

try의 else는 try가 예외 없이 끝났을 때 실행됩니다. finally는 정상·예외 여부와 관계없이 정리 지시를 실행하는 구간입니다. 파일처럼 반드시 닫아야 하는 대상에는 다음 레슨의 with를 주로 사용합니다.

아래는 정상 변환 예제입니다. else에서 성공 결과를 쓰고 finally에서 처리 종료를 알립니다. finally 안의 return으로 앞의 반환이나 예외를 덮지 않도록 주의하세요.

이번에는 int("6")이 성공하므로 except는 건너뜁니다. else에서 수량 6을 출력한 뒤 finally에서 처리 종료를 출력합니다. finally가 실행됐다는 사실만으로 변환 성공 여부를 판단할 수는 없습니다.

Pythonexceptions.py
01try:02    count = int("6")03except ValueError:04    print("입력 오류")05else:06    print("수량", count)07finally:08    print("처리 종료")

함수의 입력 규칙 위반 알리기

raise는 예외를 직접 발생시키는 지시입니다. 자료형이 맞지 않으면 TypeError, 정수이지만 허용 범위를 벗어나면 ValueError처럼 이유를 구분할 수 있습니다.

except ... as error는 예외 객체에 이름을 붙여 메시지를 읽게 합니다. 호출자는 처리할 수 있는 오류에 응답하고, 예상하지 못한 예외는 조용히 성공으로 바꾸지 않습니다.

checked_count(-2)는 정수 검사에는 통과하지만 0 이상 검사에서 실패합니다. 그래서 return value까지 가지 않고 ValueError를 발생시키며 except가 그 메시지를 출력합니다. 뒤의 checked_count(3)은 두 검사를 통과해 3을 반환합니다.

Pythonexceptions.py
01def checked_count(value):02    if not isinstance(value, int) or isinstance(value, bool):03        raise TypeError("수량은 정수여야 합니다")04    if value < 0:05        raise ValueError("수량은 0 이상이어야 합니다")06    return value07 08try:09    checked_count(-2)10except ValueError as error:11    print(error)12print(checked_count(3))

  1. 이유에 상관없이 except: pass
  2. int() 변환을 감싼 except ValueError
  3. 모든 코드를 try 바깥에 두기

정답: int() 변환을 감싼 except ValueError예상한 변환 오류를 좁은 범위에서 처리합니다.

기억할 한 가지

예상한 예외만 좁은 범위에서 처리하고, 성공과 실패를 숨기지 않습니다.
