01

예상한 입력 오류에 응답하기

예외는 실행을 계속할 수 없는 상황을 알리는 객체입니다. try 안에서 예외가 발생하면 해당 종류를 받는 except로 이동하고, 오류가 난 뒤의 try 지시는 건너뜁니다.

숫자 변환 실패는 ValueError로 처리합니다. 모든 오류를 한꺼번에 무시하면 코드 실수까지 숨길 수 있으므로 위험한 변환 부분만 try로 감싸세요. 아래 입력 문자열은 예제 안에 고정되어 있습니다.

Python 코드

Python 3.10+
text = "여섯"
try:
    count = int(text)
except ValueError:
    print("정수로 입력해 주세요")
print("다음 기록을 받을 수 있습니다")

예제 실행 결과

정수로 입력해 주세요
다음 기록을 받을 수 있습니다

02

정상 경로와 정리 구별하기

try의 else는 try가 예외 없이 끝났을 때 실행됩니다. finally는 정상·예외 여부와 관계없이 정리 지시를 실행하는 구간입니다. 파일처럼 반드시 닫아야 하는 대상에는 다음 레슨의 with를 주로 사용합니다.

아래는 정상 변환 예제입니다. else에서 성공 결과를 쓰고 finally에서 처리 종료를 알립니다. finally 안의 return으로 앞의 반환이나 예외를 덮지 않도록 주의하세요.

Python 코드

Python 3.10+
try:
    count = int("6")
except ValueError:
    print("입력 오류")
else:
    print("수량", count)
finally:
    print("처리 종료")

예제 실행 결과

수량 6
처리 종료

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    try 성공

    예외가 없으므로 except를 건너뜁니다.

  2. 2

    else 실행

    성공한 값을 사용합니다.

  3. 3

    finally 실행

    종료 작업을 수행합니다.

03

함수의 입력 규칙 위반 알리기

raise는 예외를 직접 발생시키는 지시입니다. 자료형이 맞지 않으면 TypeError, 정수이지만 허용 범위를 벗어나면 ValueError처럼 이유를 구분할 수 있습니다.

except ... as error는 예외 객체에 이름을 붙여 메시지를 읽게 합니다. 호출자는 처리할 수 있는 오류에 응답하고, 예상하지 못한 예외는 조용히 성공으로 바꾸지 않습니다.

Python 코드

Python 3.10+
def checked_count(value):
    if not isinstance(value, int) or isinstance(value, bool):
        raise TypeError("수량은 정수여야 합니다")
    if value < 0:
        raise ValueError("수량은 0 이상이어야 합니다")
    return value

try:
    checked_count(-2)
except ValueError as error:
    print(error)
print(checked_count(3))

수량은 0 이상이어야 합니다

코드를 읽고, 한 번 예측하기

숫자 변환 실패만 처리하려면 어떤 예외를 받는 것이 알맞나요?

정답과 모든 선택지의 해설 읽기
  1. 오답: 이유에 상관없이 except: pass

    오류를 모두 숨기면 프로그램의 다른 문제도 발견하기 어렵습니다.

  2. 정답: int() 변환을 감싼 except ValueError

    예상한 변환 오류를 좁은 범위에서 처리합니다.

  3. 오답: 모든 코드를 try 바깥에 두기

    처리 구간이 없으면 실패가 호출한 쪽으로 전파됩니다.

기억할 내용

예상한 예외만 좁은 범위에서 처리하고, 성공과 실패를 숨기지 않습니다.
