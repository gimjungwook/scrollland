장면 1

자료형으로 역할 확인하기

자료형은 객체의 종류이며 어떤 연산을 할 수 있는지 정합니다. int는 정수, float는 소수 계산에 쓰는 부동소수점 수, str은 문자열입니다. type()으로 자료형을 확인할 수 있습니다.

12와 "12"는 출력 모양이 비슷해도 다릅니다. 정수끼리 +를 쓰면 더하고, 문자열끼리 +를 쓰면 글을 잇습니다. 정수와 문자열을 바로 더하면 오류가 납니다.

Python 코드

print(type(12))
print(type("12"))
print(12 + 3)
print("12" + "3")

실행 결과

<class 'int'>
<class 'str'>
15
123

실행 순서

정수 계산: 12 + 3 → 15 · 문자열 연결: "12" + "3" → "123"

  1. 자료형 확인

    숫자 12는 int, 따옴표 안 12는 str입니다.

    12
    int
    "12"
    str

    이 단계의 출력: <class 'int'> <class 'str'>

  2. 연산 선택

    같은 +라도 객체의 종류에 따라 동작이 다릅니다.

    숫자의 +
    15
    문자열의 +
    123

    이 단계의 출력: <class 'int'> <class 'str'> 15 123

결과와 관계 확인

12의 자료형
int
"12"의 자료형
str
숫자 덧셈 결과
15
문자열 연결 결과
"123"

장면 2

계산할 값으로 변환하기

형 변환은 한 종류의 값에서 다른 종류의 값을 만드는 작업입니다. int("12")는 정수 12를 만들고, float("2.5")는 소수 계산용 값을 만듭니다.

str()은 값을 문자열로 만듭니다. 변환해도 원래 이름의 연결은 자동으로 바뀌지 않습니다. 숫자로 읽을 수 없는 "열둘"은 int()로 바꿀 수 없으며, 그런 입력은 「예외를 구별해 처리하기」 레슨에서 처리합니다.

Python 코드

text = "12"
amount = int(text)
print(amount + 3)
print(type(text))
print(str(2.5))

실행 결과

15
<class 'str'>
2.5

이름과 객체

입력 객체: text → 문자열 "12" · 변환 결과: amount → 정수 12

  1. 변환 전

    text는 문자열입니다.

    text
    "12" · str

    이 단계의 출력: (표준 출력 없음)

  2. 변환 후

    amount는 계산할 수 있는 정수입니다.

    text
    "12" · str
    amount
    12 · int

    이 단계의 출력: (표준 출력 없음)

  3. 원본 확인

    text의 자료형은 str로 유지됩니다.

    text
    "12" · str
    amount
    12 · int

    이 단계의 출력: 15 <class 'str'>

결과와 관계 확인

text
"12" · str
amount
12 · int

참·거짓과 값 없음 구별하기

bool은 참을 뜻하는 True와 거짓을 뜻하는 False의 자료형입니다. None은 아직 값이 없거나 결과가 없음을 나타내는 별도의 객체입니다.

숫자 0, 빈 문자열 "", None은 서로 같은 값이 아닙니다. 예약한 좌석이 0개인 상태와 좌석 수를 아직 확인하지 않은 상태를 구별하려면 None을 사용할 수 있습니다.

Python 코드

confirmed = True
seat_count = 0
unknown_count = None
print(type(confirmed))
print(seat_count)
print(unknown_count)

실행 결과

<class 'bool'>
0
None

이름과 객체

확인한 수량: seat_count → 0 · 미확인 수량: unknown_count → None

  1. 확인 여부

    confirmed는 bool의 참 값입니다.

    confirmed
    True · bool

    이 단계의 출력: (표준 출력 없음)

  2. 수량 비교

    0은 확인한 숫자이고 None은 수량이 없다는 표시입니다.

    confirmed
    True
    seat_count
    0 · int
    unknown_count
    None

    이 단계의 출력: (표준 출력 없음)

결과와 관계 확인

confirmed
True
seat_count
0 · int
unknown_count
None
