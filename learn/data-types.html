같아 보이는 값 구별하기

"12"와 "3"을 더했는데 15가 아닌 123이 나옵니다. 컴퓨터는 어떤 덧셈을 한 걸까요?

"12" + "3"→"123"

이름에 연결한 값은 숫자일 수도, 글일 수도 있습니다. 모양이 비슷해도 자료형에 따라 같은 기호의 뜻이 달라집니다.

숫자의 덧셈과 글의 연결을 비교하고, 입력한 글을 계산할 수 있는 값으로 바꾸는 시점을 찾습니다.

읽고 나면자료형에 따라 가능한 연산이 달라짐을 설명하고 필요한 변환을 선택합니다.

먼저 익힐 개념 · 값에 이름을 연결하기

01

자료형으로 역할 확인하기

숫자 12와 글 "12"는 화면에 출력하면 비슷하게 보입니다. 하지만 Python은 둘을 다르게 다룹니다. 값의 종류를 자료형이라고 하며, 같은 + 기호라도 자료형에 따라 작업이 달라집니다.

int는 정수의 자료형이고 str은 문자열의 자료형입니다. type(12)는 값 12의 종류를 확인합니다. 결과 <class 'int'>에서는 int라는 이름을 읽으면 됩니다. class의 자세한 뜻은 뒤의 클래스 레슨에서 다룹니다.

아래에서는 종류를 먼저 확인하고 같은 +를 두 번 사용합니다. 숫자끼리는 수량을 더하고, 문자열끼리는 글을 순서대로 이어 붙입니다. 문자열을 숫자로 계산하는 방법은 다음 구간에서 배웁니다.

같은 +인데 왜 15와 123이라는 다른 결과가 나올까요?

  1. 정수의 종류 확인

    따옴표 없는 12는 정수입니다. type(12)의 결과에서 int를 확인합니다.

    코드의 값
    12
    자료형
    int · 정수

    이 단계의 출력: <class 'int'>

  2. 문자열의 종류 확인

    따옴표로 적은 "12"는 숫자가 아니라 글입니다. type의 결과도 str로 달라집니다.

    코드의 값
    "12"
    자료형
    str · 문자열

    이 단계의 출력: <class 'int'> <class 'str'>

  3. 정수는 수량 더하기

    12와 3은 모두 정수이므로 수량을 더한 15를 출력합니다.

    왼쪽 값
    12 · int
    오른쪽 값
    3 · int
    +의 결과
    15 · int

    이 단계의 출력: <class 'int'> <class 'str'> 15

  4. 문자열은 글 이어 붙이기

    "12" 뒤에 "3"을 붙이면 "123"입니다. 출력은 바깥 따옴표를 표시하지 않습니다.

    왼쪽 값
    "12" · str
    오른쪽 값
    "3" · str
    +의 결과
    "123" · str

    이 단계의 출력: <class 'int'> <class 'str'> 15 123

실행 후 관계와 값

정수의 +
12 + 3 = 15
문자열의 +
"12" + "3" = "123"

연산 전에 값의 자료형을 확인합니다. 정수의 +는 덧셈, 문자열의 +는 글의 연결입니다.

출력에 123이 보인다고 해서 정수가 된 것은 아닙니다. print가 따옴표를 생략해 보여 주어도 원래 결과는 문자열 "123"입니다.

int와 str을 섞어 12 + "3"처럼 쓰면 Python이 어느 연산을 할지 임의로 고르지 않고 TypeError를 냅니다. 숫자로 더하려면 int("3")처럼 먼저 변환합니다.

02

계산할 값으로 변환하기

형 변환은 한 종류의 값에서 다른 종류의 값을 만드는 작업입니다. int("12")는 정수 12를 만들고, float("2.5")는 소수 계산용 값을 만듭니다.

str()은 값을 문자열로 만듭니다. 변환해도 원래 이름의 연결은 자동으로 바뀌지 않습니다. 숫자로 읽을 수 없는 "열둘"은 int()로 바꿀 수 없으며, 그런 입력은 「예외를 구별해 처리하기」 레슨에서 처리합니다.

amount = int(text)는 새 정수 12를 amount에 연결합니다. text 자체를 바꾸는 지시가 없으므로 text는 계속 문자열 "12"입니다. float는 2.5처럼 소수점이 있는 수를 계산할 때 쓰는 자료형입니다.

Pythondata-types.py
01text = "12"02amount = int(text)03print(amount + 3)04print(type(text))05print(str(2.5))

참·거짓과 값 없음 구별하기

bool은 참을 뜻하는 True와 거짓을 뜻하는 False의 자료형입니다. None은 아직 값이 없거나 결과가 없음을 나타내는 별도의 객체입니다.

숫자 0, 빈 문자열 "", None은 서로 같은 값이 아닙니다. 예약한 좌석이 0개인 상태와 좌석 수를 아직 확인하지 않은 상태를 구별하려면 None을 사용할 수 있습니다.
