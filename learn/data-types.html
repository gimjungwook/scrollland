같아 보이는 값 구별하기

"12"와 "3"을 더했는데 15가 아닌 123이 나옵니다. 컴퓨터는 어떤 덧셈을 한 걸까요?

"12" + "3"→"123"

이름에 연결한 값은 숫자일 수도, 글일 수도 있습니다. 모양이 비슷해도 자료형에 따라 같은 기호의 뜻이 달라집니다.

숫자의 덧셈과 글의 연결을 비교하고, 입력한 글을 계산할 수 있는 값으로 바꾸는 시점을 찾습니다.

읽고 나면자료형에 따라 가능한 연산이 달라짐을 설명하고 필요한 변환을 선택합니다.

먼저 익힐 개념 · 값에 이름을 연결하기

01

자료형으로 역할 확인하기

자료형은 객체의 종류이며 어떤 연산을 할 수 있는지 정합니다. int는 정수, float는 소수 계산에 쓰는 부동소수점 수, str은 문자열입니다. type()으로 자료형을 확인할 수 있습니다.

12와 "12"는 출력 모양이 비슷해도 다릅니다. 정수끼리 +를 쓰면 더하고, 문자열끼리 +를 쓰면 글을 잇습니다. 정수와 문자열을 바로 더하면 오류가 납니다.

Pythondata-types.py
01print(type(12))02print(type("12"))03print(12 + 3)04print("12" + "3")

실행 결과

<class 'int'>
<class 'str'>
15
123
02

계산할 값으로 변환하기

형 변환은 한 종류의 값에서 다른 종류의 값을 만드는 작업입니다. int("12")는 정수 12를 만들고, float("2.5")는 소수 계산용 값을 만듭니다.

str()은 값을 문자열로 만듭니다. 변환해도 원래 이름의 연결은 자동으로 바뀌지 않습니다. 숫자로 읽을 수 없는 "열둘"은 int()로 바꿀 수 없으며, 그런 입력은 「예외를 구별해 처리하기」 레슨에서 처리합니다.

Pythondata-types.py
01text = "12"02amount = int(text)03print(amount + 3)04print(type(text))05print(str(2.5))

실행 결과

15
<class 'str'>
2.5
03

참·거짓과 값 없음 구별하기

bool은 참을 뜻하는 True와 거짓을 뜻하는 False의 자료형입니다. None은 아직 값이 없거나 결과가 없음을 나타내는 별도의 객체입니다.

숫자 0, 빈 문자열 "", None은 서로 같은 값이 아닙니다. 예약한 좌석이 0개인 상태와 좌석 수를 아직 확인하지 않은 상태를 구별하려면 None을 사용할 수 있습니다.

Pythondata-types.py
01confirmed = True02seat_count = 003unknown_count = None04print(type(confirmed))05print(seat_count)06print(unknown_count)

실행 결과

<class 'bool'>
0
None

text = "8"을 정수로 계산하려면 어떤 식을 사용하나요?

  1. int(text) + 2
  2. text + 2
  3. text + "2"

답을 떠올린 뒤, 아래의 설명과 비교해 보세요.

정답int(text) + 2

정답: int(text) + 2숫자를 나타내는 문자열을 정수로 바꾼 뒤 더합니다.

오답: text + 2문자열과 정수는 +로 바로 더할 수 없습니다.

오답: text + "2"이 식은 계산 결과 10이 아니라 문자열 "82"를 만듭니다.
