조건을 참과 거짓으로 읽기

새를 6마리 관찰했습니다. 기준인 5마리를 넘겼다는 사실을 프로그램 안에서는 어떤 값으로 나타낼까요?

6 >= 5→True

지금까지는 수량 자체를 다뤘습니다. 이제 두 값을 비교한 결과도 True 또는 False라는 값으로 다룹니다.

수량이 기준 이상인지 묻고 여러 조건을 조합합니다. 비어 있는 값과 값이 없다는 표시도 구별합니다.

읽고 나면비교 결과와 논리 연산을 bool 값으로 설명합니다.

먼저 익힐 개념 · 같아 보이는 값 구별하기

01

비교로 질문 만들기

비교는 두 값의 관계를 묻고 True 또는 False를 만듭니다. ==는 값이 같은지, !=는 다른지, >=는 크거나 같은지 묻습니다. =의 대입과 구별하세요.

아래 질문은 각각 “관찰 수가 5 이상인가?”와 “관찰 수가 정확히 0인가?”입니다. 조건을 질문으로 읽으면 결과를 예측하기 쉽습니다.

Pythonbooleans.py
01count = 602print(count >= 5)03print(count == 0)04print(count != 0)

실행 결과

True
False
True
02

여러 조건을 연결하기

and는 두 조건이 모두 참인지, or는 적어도 하나가 참인지, not은 참·거짓을 뒤집어 묻습니다. 이 예제처럼 비교식끼리 연결하면 결과는 bool입니다.

Python의 and와 or는 일반적으로 피연산자 중 하나를 반환하고 결과가 정해지면 나머지 식을 계산하지 않습니다. 피연산자는 연산자의 대상인 값이나 식입니다. 이 성질을 이용한 안전한 조건은 「연산의 뜻과 우선순위 확인하기」 레슨에서 다룹니다.

Pythonbooleans.py
01count = 602raining = False03print(count >= 5 and not raining)04print(count == 0 or raining)

실행 결과

True
False
03

비어 있음과 값 없음 구별하기

bool()로 참값 판정을 확인할 수 있습니다. 0, 빈 문자열, 빈 묶음, None은 거짓으로 판정됩니다. 값이 없음을 확인하려면 is None을 사용합니다.

"0"은 글자 하나가 있는 문자열이라 참으로 판정됩니다. bool(value)가 False라는 이유만으로 그 값이 None이라고 결론 내리면 안 됩니다.

Pythonbooleans.py
01print(bool(0))02print(bool("0"))03print(bool(""))04value = None05print(value is None)

실행 결과

False
True
False
True

count가 0일 때 count > 0 and count < 10은 어떤 값인가요?

  1. True
  2. False
  3. None

답을 떠올린 뒤, 아래의 설명과 비교해 보세요.

정답False

오답: True첫 조건 count > 0이 거짓이므로 두 조건을 모두 만족하지 못합니다.

정답: Falseand는 두 조건이 모두 참이어야 합니다.

오답: None두 비교식을 연결한 결과는 여기서 bool입니다.

기억할 한 가지

조건의 결과를 먼저 읽고, 여러 조건을 연결한 이유를 말로 설명합니다.
