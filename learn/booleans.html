장면 1

비교로 질문 만들기

비교는 두 값의 관계를 묻고 True 또는 False를 만듭니다. ==는 값이 같은지, !=는 다른지, >=는 크거나 같은지 묻습니다. =의 대입과 구별하세요.

아래 질문은 각각 “관찰 수가 5 이상인가?”와 “관찰 수가 정확히 0인가?”입니다. 조건을 질문으로 읽으면 결과를 예측하기 쉽습니다.

Python 코드

count = 6
print(count >= 5)
print(count == 0)
print(count != 0)

실행 결과

True
False
True

조건과 선택

질문 1: 6은 5 이상인가? → 참 · 질문 2: 6은 0인가? → 거짓

  1. 값 준비

    count는 정수 6입니다.

    count
    6

    이 단계의 출력: (표준 출력 없음)

  2. 비교 후

    각 비교는 bool 값을 만듭니다.

    count >= 5
    True
    count == 0
    False
    count != 0
    True

    이 단계의 출력: True False True

결과와 관계 확인

count
6
count >= 5 결과
True
count == 0 결과
False
count != 0 결과
True

장면 2

여러 조건을 연결하기

and는 두 조건이 모두 참인지, or는 적어도 하나가 참인지, not은 참·거짓을 뒤집어 묻습니다. 이 예제처럼 비교식끼리 연결하면 결과는 bool입니다.

Python의 and와 or는 일반적으로 피연산자 중 하나를 반환하고 결과가 정해지면 나머지 식을 계산하지 않습니다. 피연산자는 연산자의 대상인 값이나 식입니다. 이 성질을 이용한 안전한 조건은 「연산의 뜻과 우선순위 확인하기」 레슨에서 다룹니다.

Python 코드

count = 6
raining = False
print(count >= 5 and not raining)
print(count == 0 or raining)

실행 결과

True
False

조건과 선택

충분한 수량: 6 >= 5 → True · 비가 오지 않음: not False → True · 함께 충족: True and True → True

  1. 첫 조건

    수량 조건이 참입니다.

    count >= 5
    True
    raining
    False

    이 단계의 출력: (표준 출력 없음)

  2. 둘째 조건

    비가 오지 않는 조건도 참이라 전체가 참입니다.

    count >= 5
    True
    not raining
    True
    and 결과
    True

    이 단계의 출력: True

결과와 관계 확인

count
6
raining
False
and 식 결과
True
or 식 결과
False

장면 3

비어 있음과 값 없음 구별하기

bool()로 참값 판정을 확인할 수 있습니다. 0, 빈 문자열, 빈 묶음, None은 거짓으로 판정됩니다. 값이 없음을 확인하려면 is None을 사용합니다.

"0"은 글자 하나가 있는 문자열이라 참으로 판정됩니다. bool(value)가 False라는 이유만으로 그 값이 None이라고 결론 내리면 안 됩니다.

Python 코드

print(bool(0))
print(bool("0"))
print(bool(""))
value = None
print(value is None)

실행 결과

False
True
False
True

값의 구성

숫자 0: 거짓으로 판정 · 문자열 "0": 비어 있지 않아 참으로 판정 · None: 값 없음

  1. 참값 검사

    같아 보이는 0도 자료형에 따라 판정이 다릅니다.

    bool(0)
    False
    bool("0")
    True
    bool("")
    False

    이 단계의 출력: False True False

  2. None 검사

    is None으로 값 없음 자체를 확인합니다.

    value
    None
    value is None
    True

    이 단계의 출력: False True False True

결과와 관계 확인

bool(0) 결과
False
bool("0") 결과
True
bool("") 결과
False
value · is None 검사
None · True
