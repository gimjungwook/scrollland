조건을 참과 거짓으로 읽기

새를 6마리 관찰했습니다. 기준인 5마리를 넘겼다는 사실을 프로그램 안에서는 어떤 값으로 나타낼까요?

6 >= 5→True

지금까지는 수량 자체를 다뤘습니다. 이제 두 값을 비교한 결과도 True 또는 False라는 값으로 다룹니다.

수량이 기준 이상인지 묻고 여러 조건을 조합합니다. 비어 있는 값과 값이 없다는 표시도 구별합니다.

읽고 나면비교 결과와 논리 연산을 bool 값으로 설명합니다.

먼저 익힐 개념 · 같아 보이는 값 구별하기

01

비교로 질문 만들기

관찰 수가 6일 때 “5 이상인가?”와 “0인가?”는 서로 다른 질문입니다. Python은 비교의 답을 참인 True 또는 거짓인 False로 표현합니다. 이 두 값의 자료형이 불리언(bool)입니다.

count = 6은 count에 값을 연결하는 대입입니다. count == 0은 count를 0으로 바꾸지 않고 현재 값이 0과 같은지 묻는 비교입니다. 등호 하나와 둘을 구별하세요.

>=는 “크거나 같은가?”, ==는 “같은가?”, !=는 “다른가?”라고 읽습니다. 아래에서는 count를 바꾸지 않은 채 세 질문의 답만 차례로 출력합니다.

같은 count를 비교했는데 왜 True, False, True가 차례로 나올까요?

02

여러 조건을 연결하기

“관찰 수가 5 이상이고 비가 오지 않는가?”처럼 질문을 합칠 수 있습니다. 아래 count >= 5는 True이고 raining은 False입니다. not raining은 “비가 오지 않는가?”라고 묻기 때문에 True가 됩니다. 두 답이 모두 True이므로 and로 연결한 첫 결과는 True입니다.

or는 적어도 한쪽이 참인지 묻습니다. 두 번째 식의 count == 0과 raining은 모두 False여서 결과도 False입니다. not은 참·거짓 판정을 뒤집습니다.

and와 or는 답이 이미 정해지면 뒤 식을 계산하지 않습니다. 여기처럼 불리언끼리 연결하면 bool이 나오지만, 일반적으로는 계산한 값 중 하나를 그대로 돌려줍니다. 뒤 계산을 건너뛰는 예는 「연산의 뜻과 우선순위 확인하기」 레슨에서 확인합니다.

Pythonbooleans.py
01count = 602raining = False03print(count >= 5 and not raining)04print(count == 0 or raining)

비어 있음과 값 없음 구별하기

조건에 숫자나 문자열을 넣었을 때 Python이 어떻게 판단하는지는 bool()로 확인할 수 있습니다. 수량 0, 빈 문자열 "", 빈 묶음, 값 없음을 나타내는 None은 False로 판정됩니다.

숫자 0과 문자열 "0"은 다릅니다. "0"에는 글자 한 개가 들어 있으므로 빈 문자열이 아니며 bool("0")은 True입니다. 여기서 문자열을 숫자로 변환한 것은 아닙니다.

거짓으로 판정되는 값이 모두 None인 것은 아닙니다. 정말 값이 없는지 확인할 때는 value is None처럼 묻습니다. 아래 마지막 줄은 value에 None을 연결했기 때문에 True입니다.

Pythonbooleans.py
01print(bool(0))02print(bool("0"))03print(bool(""))04value = None05print(value is None)
