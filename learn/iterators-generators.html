01

다음 항목을 꺼내는 대상

반복 가능한 객체는 for가 항목을 받을 수 있는 대상입니다. iter()는 그 대상에서 다음 항목의 위치를 기억하는 반복자를 만듭니다. next()로 항목을 하나씩 꺼냅니다.

모두 소비한 반복자는 처음으로 자동 돌아가지 않습니다. next()의 두 번째 인자는 끝났을 때 돌려줄 기본값입니다. 기본값이 없으면 StopIteration이라는 종료 신호가 나고 for는 이를 정상 종료로 처리합니다.

Python 코드

Python 3.10+
cursor = iter([4, 2])
print(next(cursor))
print(next(cursor))
print(next(cursor, "끝"))

예제 실행 결과

4
2
끝

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    첫 next

    4를 받고 위치가 이동합니다.

  2. 2

    둘째 next

    2를 받고 항목이 없어집니다.

  3. 3

    셋째 next

    종료 기본값을 받습니다.

02

yield에서 멈추고 재개하기

제너레이터는 값을 필요할 때 만드는 반복자의 한 종류입니다. yield가 있는 함수를 호출하면 본문을 바로 끝까지 실행하지 않고 제너레이터 객체를 돌려줍니다.

next()가 요청될 때 본문을 진행하고 yield에서 값 하나를 내보내며 멈춥니다. 다음 요청은 멈춘 다음 줄에서 이어집니다. return이나 본문 끝은 제너레이터를 종료합니다.

Python 코드

Python 3.10+
def milestones():
    yield 2
    yield 5
    yield 9

stream = milestones()
print(next(stream))
print(list(stream))

예제 실행 결과

2
[5, 9]

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    객체 생성

    아직 yield를 실행하지 않았습니다.

  2. 2

    next 실행

    첫 yield가 2를 내보냅니다.

  3. 3

    list 실행

    남아 있는 5와 9를 소비합니다.

03

짧은 제너레이터 식 쓰기

괄호 안의 (값 식 for ...)는 제너레이터 식입니다. 리스트 컴프리헨션과 달리 모든 결과를 미리 리스트에 모으지 않습니다. sum()처럼 항목을 순서대로 소비하는 함수에 전달할 수 있습니다.

아래 stream은 sum()을 한 번 계산하면서 끝까지 소비됩니다. 다시 sum()에 전달하면 남은 항목이 없어서 합계 0이 됩니다. 다시 계산하려면 새 제너레이터를 만들어야 합니다.

Python 코드

Python 3.10+
stream = (n * n for n in range(1, 4))
print(sum(stream))
print(sum(stream))
print(sum(n * n for n in range(1, 4)))

예제 실행 결과

14
0
14

실행 흐름 살펴보기

검증한 예제의 상태를 순서대로 읽습니다.

  1. 1

    첫 합계

    세 결과를 소비합니다.

  2. 2

    둘째 합계

    같은 stream은 이미 끝났습니다.

  3. 3

    새 식

    새 제너레이터를 만들어 다시 계산합니다.

정답과 모든 선택지의 해설 읽기
  1. 오답: 처음 값부터 모든 값

    반복자는 자동으로 처음으로 되돌아가지 않습니다.

  2. 정답: 아직 꺼내지 않은 나머지 값

    next()가 소비한 첫 값 이후부터 계속 진행합니다.

  3. 오답: 항상 빈 리스트

    남은 값이 있다면 계속 꺼내 모읍니다.

기억할 내용

반복자는 다음 항목을 기억하고, 제너레이터는 멈춘 위치에서 다시 값을 만듭니다.
