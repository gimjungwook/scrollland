사용자 표시와 개발 확인 구별하기

특수 메서드는 앞뒤에 밑줄 두 개가 있는 이름으로 Python의 기본 동작과 연결됩니다. 매직 메서드라고도 불리지만 이 과정에서는 특수 메서드로 표기를 통일합니다.

__str__은 print()처럼 사람이 읽을 표시를, __repr__은 repr()처럼 개발 중 객체를 구별할 표현을 제공합니다. 둘 다 문자열을 반환해야 합니다.

Python 코드

class Observation:
    def __init__(self, count):
        self.count = count
    def __str__(self):
        return f"관찰 {self.count}개"
    def __repr__(self):
        return f"Observation(count={self.count})"

record = Observation(4)
print(record)
print(repr(record))

실행 결과

관찰 4개
Observation(count=4)

    __str__ 결과

    이 단계의 출력: 관찰 4개

  2. repr 요청

    __repr__의 구별 가능한 표현을 사용합니다.

    __repr__ 결과

길이와 포함 여부 제공하기

__len__은 len()의 결과를, __contains__는 in의 포함 여부를 제공합니다. 길이는 0 이상의 정수여야 합니다. 객체가 목록을 감싸고 있다면 내부 목록에 질문을 전달할 수 있습니다.

직접 __len__을 호출하기보다 len(record)처럼 표준 연산을 사용하면 다른 자료형과 같은 문법으로 읽힙니다. 포함 여부 역시 객체가 가진 항목이라는 의미가 분명해야 합니다.

Python 코드

class Places:
    def __init__(self, names):
        self.names = list(names)
    def __len__(self):
        return len(self.names)
    def __contains__(self, name):
        return name in self.names

places = Places(["숲", "강"])
print(len(places))
print("강" in places)
print("못" in places)

값 비교와 정렬 기준 정의하기

__eq__는 ==의 값 비교를, __lt__는 < 비교를 제공합니다. 아래에서는 관찰 수량을 비교 기준으로 정해 sorted()가 사용할 수 있게 합니다.

지원하지 않는 상대 자료형에는 NotImplemented를 반환할 수 있습니다. 이는 오류를 직접 던지는 지시가 아니라 다른 비교 처리 기회를 Python에 돌려주는 특별한 값입니다. 비교 규칙은 서로 일관되어야 합니다.

Python 코드

class Observation:
    def __init__(self, count):
        self.count = count
    def __eq__(self, other):
        if not isinstance(other, Observation):
            return NotImplemented
        return self.count == other.count
    def __lt__(self, other):
        if not isinstance(other, Observation):
            return NotImplemented
        return self.count < other.count

print(Observation(4) == Observation(4))
print([item.count for item in sorted([Observation(4), Observation(2)])])

실행 결과

True
[2, 4]

덧셈과 호출에 의미 부여하기

__add__는 + 연산, __call__은 객체 자체에 괄호를 붙인 호출을 정의합니다. 여기서 두 수량 묶음의 덧셈은 합계를 가진 새 객체를 반환합니다.

__call__은 배수를 인자로 받아 계산값을 반환합니다. 이런 연결이 코드를 더 어렵게 만든다면 combine()이나 scaled()처럼 이름 있는 일반 메서드를 쓰는 편이 낫습니다. 원본 변경 여부도 명시하세요.

Python 코드

class Count:
    def __init__(self, value):
        self.value = value
    def __add__(self, other):
        if not isinstance(other, Count):
            return NotImplemented
        return Count(self.value + other.value)
    def __call__(self, factor=1):
        return self.value * factor

a = Count(2)
b = Count(3)
combined = a + b
print(combined())
print(combined(2))
print(a.value)

실행 결과

5
10
2
