기본 연산과 객체 연결하기

직접 만든 관찰 객체를 print에 전달했습니다. 관찰 4개라는 안내문을 나오게 하려면 어디에 규칙을 적어야 할까요?

print(record)→관찰 4개

객체의 메서드를 직접 호출할 수 있습니다. 특수 메서드는 print·len·덧셈 같은 표준 도구가 객체의 동작을 요청하는 연결점입니다.

사용자에게 보일 문자열과 개발 중 확인할 표현을 구별하고, 길이·비교·덧셈·호출의 의미를 객체에 정합니다.

읽고 나면특수 메서드가 표준 연산과 연결되는 방식을 설명합니다.

01

사용자 표시와 개발 확인 구별하기

직접 만든 객체도 print(record)처럼 평소 쓰던 문법으로 보여 주고 싶습니다. 클래스에 __str__을 정의하면 Python이 문자열 표시가 필요할 때 이 메서드를 사용합니다. 이런 기본 동작에 연결되는 이름을 특수 메서드라고 합니다. 이름 앞뒤에 밑줄 두 개가 있습니다.

__str__은 사람이 읽을 "관찰 4개"를, __repr__은 개발 중 객체를 구별할 "Observation(count=4)"를 돌려주도록 하겠습니다. 두 메서드는 출력하지 않고 문자열을 반환합니다. 실제 화면 출력은 바깥의 print가 합니다.

repr(record)는 __repr__에 해당하는 표현을 요청합니다. 같은 객체와 수량을 두 방식으로 읽는 것이므로 count는 바뀌지 않습니다. 특수 메서드를 직접 호출하기보다 print·repr처럼 뜻이 익숙한 연산을 통해 사용합니다.

같은 record인데 print(record)와 print(repr(record))의 글은 왜 다를까요?

바뀐 것은 객체의 수량이 아니라 요청한 표시 방식과 그에 맞는 문자열입니다.

첫 print는 읽기 쉬운 표현을 받아 출력하고, 두 번째는 repr가 받은 개발 확인용 문자열을 출력합니다. 같은 수량 4를 다른 형식으로 보여 준 것입니다.

__str__과 __repr__이 직접 print를 하는 것은 아닙니다. 문자열을 반환해야 바깥의 출력이나 다른 문자열 작업에서도 사용할 수 있습니다.

02

길이와 포함 여부 제공하기

__len__은 len()의 결과를, __contains__는 in의 포함 여부를 제공합니다. 길이는 0 이상의 정수여야 합니다. 객체가 목록을 감싸고 있다면 내부 목록에 질문을 전달할 수 있습니다.

직접 __len__을 호출하기보다 len(record)처럼 표준 연산을 사용하면 다른 자료형과 같은 문법으로 읽힙니다. 포함 여부 역시 객체가 가진 항목이라는 의미가 분명해야 합니다.

places가 가진 names는 ["숲", "강"]입니다. len(places)는 __len__이 안쪽 리스트에 물은 결과 2를 받고, "강" in places와 "못" in places는 __contains__가 같은 목록을 검사한 True와 False를 받습니다.

Pythonspecial-methods.py
01class Places:02    def __init__(self, names):03        self.names = list(names)04    def __len__(self):05        return len(self.names)06    def __contains__(self, name):07        return name in self.names08 09places = Places(["숲", "강"])10print(len(places))11print("강" in places)12print("못" in places)

값 비교와 정렬 기준 정의하기

__eq__는 ==의 값 비교를, __lt__는 < 비교를 제공합니다. 아래에서는 관찰 수량을 비교 기준으로 정해 sorted()가 사용할 수 있게 합니다.

지원하지 않는 상대 자료형에는 NotImplemented를 반환할 수 있습니다. 이는 오류를 직접 던지는 지시가 아니라 다른 비교 처리 기회를 Python에 돌려주는 특별한 값입니다. 비교 규칙은 서로 일관되어야 합니다.

Observation(4) 두 개는 서로 다른 객체여도 count가 같아서 == 결과가 True입니다. 정렬은 __lt__가 정한 수량 비교를 이용하므로 수량 2가 4보다 앞에 놓입니다. 마지막 리스트는 정렬된 객체에서 count만 다시 꺼낸 결과입니다.

Pythonspecial-methods.py
01class Observation:02    def __init__(self, count):03        self.count = count04    def __eq__(self, other):05        if not isinstance(other, Observation):06            return NotImplemented07        return self.count == other.count08    def __lt__(self, other):09        if not isinstance(other, Observation):10            return NotImplemented11        return self.count < other.count12 13print(Observation(4) == Observation(4))14print([item.count for item in sorted([Observation(4), Observation(2)])])

실행 결과

덧셈과 호출에 의미 부여하기

__add__는 + 연산, __call__은 객체 자체에 괄호를 붙인 호출을 정의합니다. 여기서 두 수량 묶음의 덧셈은 합계를 가진 새 객체를 반환합니다.

__call__은 배수를 인자로 받아 계산값을 반환합니다. 이런 연결이 코드를 더 어렵게 만든다면 combine()이나 scaled()처럼 이름 있는 일반 메서드를 쓰는 편이 낫습니다. 원본 변경 여부도 명시하세요.

a + b는 2와 3을 합한 새 Count(5)를 만듭니다. combined()는 기본 배수 1을 사용해 5, combined(2)는 배수 2를 사용해 10을 돌려줍니다. 이 호출은 곱셈 결과만 반환하므로 a의 2와 combined의 5는 그대로입니다.

Pythonspecial-methods.py
01class Count:02    def __init__(self, value):03        self.value = value04    def __add__(self, other):05        if not isinstance(other, Count):06            return NotImplemented07        return Count(self.value + other.value)08    def __call__(self, factor=1):09        return self.value * factor10 11a = Count(2)12b = Count(3)13combined = a + b14print(combined())15print(combined(2))16print(a.value)

실행 결과
