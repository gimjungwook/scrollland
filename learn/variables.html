값에 이름을 연결하기

오늘 센 새는 7마리입니다. 이 수를 두 번 계산에 써야 한다면 무엇이라고 불러 두면 좋을까요?

birds = 7→print(birds): 7

앞에서는 값을 직접 출력했습니다. 이제 값에 이름을 연결해 다음 지시에서도 같은 값을 사용할 수 있게 합니다.

birds를 읽으면 왜 7이 나오는지, 한 이름에 새 값을 대입하면 다른 이름의 연결은 어떻게 되는지 살펴봅니다.

읽고 나면대입과 재대입을 이름과 객체의 연결로 설명합니다.

먼저 익힐 개념 · 처음 실행하고 결과 읽기

01

관찰한 수에 이름 붙이기

관찰한 새가 7마리라면 숫자 7만 적어 둘 수도 있습니다. 하지만 그 수가 무엇을 뜻하는지, 다음 계산에서 어떤 수를 쓸지 알려면 이름이 필요합니다.

먼저 이름과 값의 관계를 글과 짧은 예제로 읽겠습니다. 두 이름 중 하나를 다시 대입할 때에는 연결이 어떻게 달라지는지 함께 보겠습니다.

02

이름과 값 구분하기

값은 7이나 "산책"처럼 프로그램이 다루는 내용입니다. Python에서 값은 객체로 표현됩니다. 객체는 자료형과 값을 갖는 프로그램 안의 대상입니다. 변수는 그 객체에 연결한 이름입니다.

birds = 7은 birds라는 이름을 값 7인 객체에 연결합니다. 빈 상자를 먼저 만들고 숫자를 집어넣는 과정으로 생각하지 마세요. 이름을 읽으면 현재 연결된 객체를 사용합니다.

Pythonvariables.py
01birds = 702print(birds)

실행 결과

7
03

오른쪽을 먼저 계산하기

=는 같다는 질문이 아니라 대입을 하는 기호입니다. 오른쪽의 4 + 3을 먼저 계산하고, 그 결과 7에 total이라는 이름을 연결합니다.

이름에는 공백을 넣지 않고 숫자로 시작하지 않습니다. 단어를 이을 때 total_birds처럼 밑줄을 사용할 수 있습니다. 대문자와 소문자는 구별되므로 total과 Total은 다른 이름입니다.

Pythonvariables.py
01total = 4 + 302print(total)

실행 결과

7
04

이름으로 값을 사용하기

기존 이름을 식에서 사용하면 그 이름이 현재 가리키는 값을 계산에 넣습니다. 계산에 썼다는 이유만으로 원래 이름의 연결이 바뀌지는 않습니다.

doubled = birds * 2에서는 birds의 값 7을 두 배로 만들어 doubled에 연결합니다. birds를 다시 출력하면 여전히 7입니다.

Pythonvariables.py
01birds = 702doubled = birds * 203print(birds)04print(doubled)

실행 결과

05

재대입으로 연결 바꾸기

재대입은 이미 있는 이름을 다른 객체에 다시 연결하는 일입니다. birds = birds + 1은 오른쪽에서 이전 값 7을 사용한 뒤 birds의 연결을 8로 바꿉니다.

saved = birds는 그때 birds가 가리킨 객체에 saved도 연결합니다. 이후 birds를 재대입해도 saved의 연결은 바뀌지 않습니다. 여러 이름이 변경 가능한 객체를 함께 가리키는 경우는 「리스트를 복사하고 정렬하기」 레슨에서 비교합니다.

재대입하면 birds와 saved의 연결 중 무엇이 바뀔까요?

재대입은 이름의 연결을 바꿉니다. 다음에 리스트 항목을 바꿀 때에는 이름을 옮긴 것인지, 함께 가리키는 객체의 내용을 바꾼 것인지 다시 구별하겠습니다.
