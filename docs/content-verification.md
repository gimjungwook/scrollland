# 콘텐츠 검증 기록

## 2026-09-23 본문 중심 구성 반영 후 확인

현재 교육 원본은 8개 코스·44개 레슨·141개 구간입니다. 읽기 구간 127개 중 6개는 글만 있고, 관계나 실행 과정을 추적할 필요가 있는 14개 구간을 시각화로 지정했습니다. 시각화 중 12개는 고정을 허용하고 2개는 고정하지 않습니다. 고정을 허용한 구간도 화면에 무대 전체가 들어가지 않으면 고정을 해제합니다. 본문 속 6개 문구에는 명시적인 글자 효과가 있습니다.

기존 예제 135개의 코드·예상 출력·제공 입력·보조 파일을 보존했습니다. 읽기 구간의 예제도 동일하게 실행 검사하며, 코드가 없는 구간은 실행 대상에서 제외합니다. 본문과 정적 예제는 일반적인 문서 흐름에 남고, 시각화의 관찰 질문·채택 이유·해석을 별도로 작성했습니다. 구간을 나눈 근거는 [콘텐츠 선택 기록](content-presentation.md)에 있습니다.

이번 반영 후 로컬 Python 3.14.6에서 `npm run build`, 자동 검사 78개, `npm run check`, 135개 예제의 실행·표준 출력 대조를 통과했습니다. 이 결과는 아래에 보존한 이전 구현의 검사 횟수·실행 시간·GitHub Actions 결과와 별개입니다. 이후 브라우저 검사와 공개 커밋의 검증 결과는 [구현 검증 기록](verification.md)을 기준으로 확인합니다.

현행 구조 검사는 다음을 확인합니다.

- 레슨별 문제·목표·선행 관계·주제·요약·공식 출처·확인 문항과 전체 8코스·44레슨의 참조가 유효합니다.
- 구간 식별자가 전체 교육 원본에서 중복되지 않고, `kind`가 `reading` 또는 `visualization`입니다.
- 읽기 구간은 본문만으로 구성할 수 있습니다. 예제·도식·상태 설명의 일률적인 최소 개수나 본문 2~4단락 제한은 없습니다.
- 시각화에는 관찰 질문·채택 이유·해석·도식·상태 자료가 있고, 상태 경계 `stops`가 각 단계 및 최종 상태와 대응합니다. 코드는 해당 예제가 필요할 때만 지정하며 코드 없는 관계 시각화도 허용합니다.
- 굵게 표시와 글자 효과를 따로 지정하며, 효과에는 표현·목적·진입 방식·시작과 종료·재진입·이탈·초기 진입 규칙이 있습니다.
- 확인 문항은 질문·선택지 3개·정답 1개·각 선택지의 이유를 갖습니다. 정답은 제출이나 긴 고정 연출 없이 이어 읽습니다.

## 현재 스크롤 상태 자료의 범위

`motion.json`은 `version: 2`이며 `scenes`에는 채택한 시각화 14개의 자료만 있습니다. 50개 중간 상태는 해당 구간의 `trace` 설명과 함께 읽는 코드 줄·이름과 값·그때까지의 출력을 기록합니다. 이는 사전에 작성한 학습 설명 자료이며 브라우저가 Python을 실행하거나 모든 내부 명령을 자동 추적한 결과가 아닙니다.

최종 단계에는 `finalNodes`, 검증한 전체 출력과 `diagram.caption`을 표시합니다. `finalNodes`는 실행 후 비교 자료이며 반환값·출력값·이전 값을 함께 비교할 때는 라벨로 시점을 구별합니다. `objectId`는 같은 객체와 별도 복사본을 구별합니다. 스크롤 진행률은 제작자가 지정한 `stops`를 따르며 본문 단락을 교체하지 않습니다. 글자 효과는 `motion.json`과 별도로 문구의 `effect`에 지정합니다.

예제 출력 검사는 중간 상태의 교육적 정확성이나 실제 화면 동작을 입증하지 않습니다. 자동 동작 검사의 범위도 실제 브라우저·기기 검사와 구별합니다. 교수의 교육 내용 승인, 학생 체험·학습 효과 검증, 사이트 배포는 각각 확인한 증거가 있을 때 기록합니다.

## 이전 콘텐츠 검토·실행 기록 보존

아래는 본문 중심 구성으로 전환하기 전의 검토 이력입니다. 당시에는 예제 단위를 ‘장면’으로 불렀으며 135개 장면 모두에 도식·상태 설명을 붙이는 자료 계약을 사용했습니다. 아래의 ‘모든 장면’, 본문 2~4단락, 레슨당 3~4장면 조건과 당시 실행 시간은 **이전 구현의 기록**입니다. 현행 제작 기준은 위 「2026-09-23 본문 중심 구성 반영 후 확인」과 [기여 안내](../CONTRIBUTING.md)를 따릅니다.

당시 기록 환경: 2026-09-23, Python 3.14.6 / Darwin arm64.

- 각 장면의 예제를 서로 다른 임시 작업 폴더에서 독립 실행했습니다.

### 독립 검수 후 수정과 재검증

- 문자열 메서드의 반환형을 하나로 일반화한 핵심문장과 잘못된 후속 레슨 참조를 수정했습니다.

- 일반 for와 컴프리헨션이 같은 리스트 결과를 만드는 실제 비교 예제를 추가했습니다. 코드·출력·도식·상태 설명을 함께 바꿨습니다.
- 가상 환경 예제는 필요 없는 프로세스 실행·출력 수집·클래스 API를 제거했습니다. 임시 환경을 실제로 생성하고 설정 파일이 생겼는지 검사하는 목표로 단순화했습니다. 현재 Python이 바뀌었다고 주장하지 않습니다. 환경의 Python을 직접 지정하는 명령은 본문에서 설명합니다.

### 후속 제목·문제·선행 관계 검토

JSON 레슨 제목을 ‘다른 도구에서도 읽을 수 있는 기록 만들기’로 명확히 했습니다. 수량 레슨은 포장 수·나머지를 구하는 문제로, 재귀 레슨은 1부터 n까지의 합과 n이 0일 때의 규칙을 묻는 문제로 구체화했습니다.

44개 레슨의 135개 장면 설명·코드를 다시 대조해 선행 링크 35개를 바꾸고 9개를 유지했습니다. 예외 처리에서 중첩 클래스를, JSON에서 정규 표현식을 선행으로 가리키던 연결 등을 실제로 쓰는 자료형·분기·함수·모듈·중첩 자료구조에 맞췄습니다. 이전·다음 레슨 순서와 8코스·44레슨 범위는 유지했습니다. 예제 코드·출력·장면 본문은 이 단계에서 바꾸지 않았습니다.
