# 시작·코스·레슨 페이지의 경계

2026-09-23 페이지 분리 기준입니다. 연속 스크롤은 한 레슨의 설명·예제·확인 문항을 읽는 방식입니다. 8개 코스와 44개 레슨을 한 페이지에 모두 넣는다는 뜻은 아닙니다. 교육 범위와 원고, 도입·시각화·본문 효과의 관찰 동작은 유지합니다.

## 주소와 포함 내용

| 페이지 | 포함할 내용 | 포함하지 않을 내용 |
| --- | --- | --- |
| `index.html` | 서비스 소개, 8개 코스의 제목·질문·코스 링크, 각 코스에 속한 레슨의 제목·레슨 링크 | 코스의 큰 도입 연출, 레슨 도입·본문·예제·확인 문항 |
| `courses/<courseId>.html` | 해당 코스의 큰 도입 1개, 그 코스의 레슨 목차, 필요한 외부 선행 레슨 링크, 첫 레슨 링크, 전체 목차 링크 | 다른 코스의 큰 도입, 모든 레슨의 도입·본문·예제·확인 문항 |
| `learn/<slug>.html` | 해당 레슨의 도입·본문·예제·확인 문항·정답 해설·정리·출처, 선행 레슨 링크, 이전·다음 레슨 링크, 소속 코스 목차 링크 | 다른 레슨 본문, 코스의 큰 도입, 전체 코스별 레슨 목차 |

학습 페이지는 시작 1개·코스 8개·레슨 44개로 총 53개입니다. `404.html`은 별도의 오류 안내 페이지이며 이 수에 포함하지 않습니다. 모든 페이지는 JavaScript 없이도 해당 글과 탐색 링크를 읽고 사용할 수 있어야 합니다.

## 이동과 연속 읽기

- 레슨 안에서는 스크롤만으로 도입부터 정답 해설과 정리까지 읽습니다. 단계 이동·재생·답 제출은 요구하지 않습니다.
- 코스·레슨 사이에서는 독자가 링크를 눌러 이동합니다. 레슨 끝에 도달해도 다음 페이지로 자동 이동하지 않습니다.
- 이전·다음 레슨은 `curriculum.json`의 코스 순서와 각 코스의 레슨 순서를 펼친 학습 순서를 따릅니다. 처음에는 이전 링크, 마지막에는 다음 링크를 만들지 않습니다.
- 선행·이전·다음 링크는 목적 레슨의 `learn/<slug>.html`로 직접 연결합니다. 이전 `index.html#lesson-…` 주소를 새 탐색 링크에 사용하지 않습니다.
- 링크에는 목적 레슨 제목을 표시합니다. 코스 경계를 넘는 이전·다음 링크에는 목적 코스 제목도 함께 표시해 어디로 이동하는지 알 수 있게 합니다.
- 각 레슨에서 `courses/<courseId>.html`의 소속 코스 목차로 돌아갈 수 있습니다. 코스 페이지에는 목적 레슨 제목을 표시한 첫 레슨 링크를 제공합니다. 다른 코스의 선행 레슨은 해당 코스에 속한 레슨 목록과 구별해 표시합니다.
- 기존 읽기 위치 복원은 각 페이지의 동일 URL에서 새로고침·방문 기록 복원을 돕습니다. 다른 페이지로 진도나 답안을 전달하는 기능으로 사용하지 않습니다.

## 제목 위계와 자료 보존

시작 페이지의 서비스 제목, 코스 페이지의 주제 제목, 레슨 페이지의 레슨 제목은 각각 페이지의 유일한 `h1`입니다. 코스 분류 제목과 큰 주제 제목을 별도의 `h1` 두 개로 표시하지 않습니다. 하위 제목은 한 단계씩 내려가며 본문 소제목·예제 입력·확인 문항을 구분합니다.

레슨 페이지의 본문은 해당 원고의 순서를 보존합니다. 각 구간의 식별자, 예제 코드와 출력, 제공 입력·파일, 시각화 상태 자료, 본문 효과, 확인 문항과 해설을 유지합니다. 페이지 분리 때문에 다른 레슨의 본문을 끼워 넣거나 내용을 생략하지 않습니다.

## 이전 주소 호환

기존 `index.html#course-<courseId>`는 `courses/<courseId>.html`에, `index.html#lesson-<slug>`는 `learn/<slug>.html`에 대응합니다. 시작 페이지에는 이 52개 식별자를 해당 목차 항목에 남깁니다.

JavaScript를 사용할 수 있으면 알려진 52개 해시만 대응하는 내부 페이지로 이동시킵니다. 목적지는 교육 원본에서 만든 명시적인 대응표를 따릅니다. `#courses`·알 수 없는 해시·외부 주소를 이 대응 규칙으로 이동시키지 않습니다. JavaScript를 사용할 수 없으면 기존 해시의 목차 항목에 도착하고, 그 자리에 있는 코스·레슨 링크로 이동합니다.

## 생성과 확인

`scripts/generate.mjs`는 53개 학습 페이지와 `404.html`을 생성하고 두 하위 폴더의 누락·불필요한 페이지와 내부 파일 링크를 검사합니다. 모든 탐색·정적 자원 링크는 루트 주소와 하위 경로 호스팅에서 같은 파일로 연결되어야 합니다.

자동 검사는 53개 페이지의 단일 `h1`·제목 단계, 시작·코스 페이지의 레슨 본문 부재, 8개 코스의 정확한 레슨 소속, 44개 레슨의 본문·예제 보존과 선행·이전·다음 링크, 이전 주소 대응표와 정적 목차 앵커를 확인합니다. 실제 스크롤 관찰·위치 복원·JavaScript 미사용 탐색 결과는 [구현 검증 기록](verification.md)에 별도로 남깁니다.
