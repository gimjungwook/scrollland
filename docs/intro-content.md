# 코스와 레슨 도입의 원고 선택

각 코스의 시작에는 주제를 상징하는 짧은 전후 장면을, 각 레슨의 시작에는 그 장면을 이해할 구체적인 상황과 질문을 둡니다. 도입은 이어질 학습의 대상을 미리 보여주며, 연출을 다 볼 때까지 본문을 기다리게 하는 관문으로 사용하지 않습니다.

코스의 분류 제목과 순서, 레슨의 기존 문제·목표·선행 관계·본문·예제·출력·문항은 유지했습니다. 도입 원고는 별도의 `intro` 자료입니다. 아래 표는 원고와 상징 장면의 선택 근거이며 화면 연출의 구현·검증 완료를 뜻하지 않습니다.

## 제작 자료

- 코스 `intro`: 비어 있지 않은 제목 줄 배열인 `headline`, 다룰 상황인 `premise`, 배운 뒤 확인할 일인 `payoff`, `scene.before`·`after`·`caption`을 갖습니다. 각 제목 줄도 비어 있지 않아야 하며 줄 수는 의미에 맞춰 정합니다. 이번 8개 코스는 두 줄로 작성했습니다. 코스의 `title`은 분류 제목으로 그대로 둡니다.
- 레슨 `intro`: 구체적인 질문인 `hook`, 앞서 배운 것과 이번 학습의 관계인 `connection`, 이번에 확인할 일인 `payoff`, 짧은 `preview.before`·`after`를 갖습니다. 화면에는 제목 아래 전체 폭의 `hook`과 `connection`·`payoff`·기존 `goal`을 표시합니다. 기존 `problem`은 원고에 보존하고 도입에서 같은 질문을 다시 표시하지 않습니다.
- 전후 표기는 코드·값·일부 출력 또는 상황의 요약입니다. 모든 왼쪽 항목이 독립 실행 코드이거나, 모든 오른쪽 항목이 전체 표준 출력인 것은 아닙니다. `출력:`, `반환값`, `count`, `오류` 같은 구분을 유지하고, `·`와 `→`는 여러 줄이나 순서를 압축한 표기로 읽습니다.
- 상징 장면에서 유지되는 값과 바뀌는 값을 구별합니다. 객체 이름이 값 자체로 변하거나, 반환과 출력이 같거나, 독자가 이미 과제를 완료한 것처럼 연출하지 않습니다.

## 여덟 코스의 상징 장면

| 코스 | 두 줄의 주제 제목 | 전후 장면 | 선택 근거 |
| --- | --- | --- | --- |
| 값으로 생각하기 (`values`) | 숫자 하나가 / 내가 쓰는 값이 되기까지 | `birds = 7` → `7` | 변수 레슨의 이름·값·출력 관계를 출발점으로 삼습니다. |
| 입력을 판단으로 바꾸기 (`decisions`) | 상황을 읽고 / 답을 고르다 | `"  PARK  "` → `"park"` | 사람이 입력한 글을 판단에 쓰기 전에 표기를 맞추는 첫 작업입니다. |
| 여러 값을 정리하기 (`collections`) | 흩어진 기록을 / 다시 찾을 수 있게 | `["숲", "강", "공원"]` → `"강"` | 묶음 전체에서 필요한 위치의 한 항목으로 시선을 옮깁니다. |
| 반복을 맡기기 (`repetition`) | 한 번 쓴 지시로 / 다음 항목까지 | `[3, -1, 2]` → `5` | 반복에 조건을 붙이면 모든 수를 더하지 않고 필요한 수만 합산할 수 있음을 보입니다. |
| 해결 방법을 재사용하기 (`reuse`) | 한 번 만든 계산을 / 다시 부르는 방법 | `label(2, unit="곳")` → `"2곳"` | 같은 label 함수에 수량과 단위를 달리 전달하는 실제 사용을 대표 장면으로 선택했습니다. |
| 외부 도구와 데이터 연결하기 (`tools`) | 직접 만든 코드에 / 이미 있는 도구 연결하기 | `2026-09-29 + 3일` → `2026-10-02` | 달력 규칙을 직접 다시 만들지 않고 날짜 도구에 맡기는 장면으로 모듈 활용의 이유를 보여줍니다. |
| 함께 움직이는 데이터 만들기 (`objects`) | 각자의 값을 가진 / 같은 종류의 기록들 | `record.add(2)` → `count: 4 → 6` | 같은 객체가 자신의 상태를 바꾸는 호출과 결과를 짝지었습니다. |
| 결과를 안전하게 남기기 (`persistence`) | 실행이 끝나도 / 기록은 남도록 | `숲:4 · 강:2 · 숲:3` → `숲:7 · 강:2` | 종합 예제의 합계를 코스 앞에서 예고해, 저장과 재확인의 목적을 구체화합니다. |

각 코스의 `scene.caption`에는 전후 표기가 무엇을 뜻하는지, 실제로 어떤 연산이나 변화가 일어나는지 적었습니다. 제목과 장면을 따로 읽어도 학습 대상을 추측하지 않게 하기 위한 설명입니다.
