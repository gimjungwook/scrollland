# 스크롤 학습 구현 검증 기록

검증일: 2026-09-23. 기존 정적 읽기·단계 버튼 구현은 사용자의 스크롤 연출 요구를 충족하지 못했습니다. 이 문서는 교체한 구현에서 직접 확인한 결과입니다. 이전 검색·재시도·단계 버튼 검사는 새 화면의 완료 근거로 사용하지 않습니다.

## 범위와 환경

- macOS arm64, Node.js 22.23.2, Python 3.14.6, Codex 인앱 브라우저의 Chromium.
- 8코스·44레슨·135장면, 314개 중간 단계와 135개 종료 비교 자료.
- 기본 페이지는 44개 레슨 전체가 연속으로 이어집니다. 각 레슨 주소도 제공합니다.
- 학습 진행에 필요한 버튼·입력창은 0개입니다. 목차·출처·선행 레슨 링크는 선택 탐색입니다.

자동 검사는 실제 컨트롤러의 DOM 대역 검사와 순수 상태 계산을 포함합니다. 브라우저의 글자 배치·네이티브 스크롤·GSAP 실행을 모두 대신하는 검사는 아니므로 위의 실제 화면 확인과 구분합니다.

## 검수 중 수정한 문제

1. 같은 리스트의 내용 변경을 새 객체 생성처럼 보이게 하던 식별자를 바로잡았습니다.
2. 마지막 중간 단계와 코드의 실제 종료가 다른 장면에 별도 `finalNodes`를 작성했습니다. 반환값·과거 호출·정리 이전 파일은 해당 시점을 이름에 표시합니다. 전체 도식 설명은 ‘실행 과정 요약’으로 구분합니다.
3. 연출 모드에서 입력 자료가 가려지지 않도록 표준 입력과 파일 내용을 장면 앞에 항상 펼쳤습니다.
4. 정적 대체에도 단계별 값·출력·종료 비교 자료를 포함했습니다.
5. 첫 강조 줄 이전의 코드, 화면 크기 변경 후의 코드 위치, 여러 줄 출력을 모두 페이지 스크롤에 연결했습니다.
6. 작은 화면의 긴 정답 줄바꿈·본문 간격·문항 높이를 수정했습니다.
7. 네 개 상태가 좁은 화면에서 겹치던 도식을 2×2 배치로 바꾸고 실제 반복문 예제에서 확인했습니다.

## 문서와 검증 한계

원본 문서의 5개 탭에서 버튼 조작·정적 화면을 기준으로 한 계약을 교체했습니다. 최종 62쪽을 나누어 모두 시각 검수하고, 후속으로 달라진 페이지는 다시 확인했습니다. 날짜 칩·링크·탭 구조·교육 범위는 보존했습니다. 공개 저장소에는 개인 기획 문서나 계정 정보를 넣지 않습니다.

실제 휴대전화·Safari·Firefox·화면 낭독기 전체 흐름·브라우저 200% 확대·저성능 기기의 전체 여정 성능은 이번에 검증하지 않았습니다. 화면 크기 검사는 브라우저 모의 설정이며 물리 기기 검사가 아닙니다. 모든 135개 장면의 모든 중간 지점을 시각적으로 개별 검수한 것은 아닙니다. 데이터와 상태의 전수 검사는 자동 검사로, 대표 장면의 배치는 실제 브라우저로 확인했습니다.

GitHub 코드 공개와 운영 사이트 배포는 별개입니다. 사용자의 디자인 승인이나 학생 대상 학습 효과 검증은 아직 받지 않았습니다. 새 환경에서는 실제 호스팅 경로·없는 주소·모션 감소·연출 실패·긴 콘텐츠 표시를 다시 확인해야 합니다.

## 재현

콘텐츠나 생성기를 바꾸면 `npm run build` 후 `npm run validate`를 실행합니다. 동작·스타일을 바꾸면 해당 기능을 실제 브라우저에서도 다시 확인합니다. GitHub Actions는 Python 3.10·3.14 환경에서 같은 자동 검사를 실행합니다. 개별 실행 결과는 저장소의 Actions 기록에서 확인할 수 있습니다.
