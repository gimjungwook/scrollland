# 도입·본문 읽기·선택 연출의 디자인 근거

확인일: 2026-09-23. 이번 기준은 한 레슨 안에서 연속해서 읽는 Python 학습 자료입니다. 코스·레슨 사이는 링크로 이동합니다. 레슨 내용을 스크롤로 읽는 조건이 모든 구간을 움직이거나 모든 레슨을 한 페이지에 넣으라는 뜻은 아닙니다. 본문·정적 예제를 읽는 흐름 안에 코스·레슨의 상징적 도입, 제작자가 지정한 본문 문구 효과, 채택 근거가 있는 학습 상태 시각화를 각각 배치합니다.

## 화면의 의도와 구성

학습자는 설치나 실행 환경을 먼저 준비하지 않고, 한 문제를 설명하는 글과 예제의 결과를 읽습니다. 읽던 문단으로 돌아가 비교할 수 있어야 합니다. 코스 시작은 큰 제목과 상징 그림으로 주제를 드러내고, 레슨 도입 뒤에는 형광펜으로 중요한 연결을 표시한 학습 노트처럼 본문과 예제를 읽게 합니다.

도입 연출이 있다는 이유로 본문의 관찰 과정까지 충분하다고 본 기존 판단은 철회했습니다. 현재 44개 레슨에서 핵심 오해를 풀 과정 하나씩을 선택했고, 나머지 98개 구간은 일반 읽기로 남겼습니다. 관찰 질문·실제 값의 변화·누적 출력·결과 해석을 연결하는 [레슨 관찰·설명 기준](lesson-observation.md)을 적용합니다. 숫자는 선정 결과이며 화면마다 효과를 채우기 위한 할당량이 아닙니다.

## 코스와 레슨 도입의 형식

`scripts/render-intro.mjs`의 공통 형식에 주제별 제목·상황·결과와 직접 작성한 SVG를 넣습니다. 그림은 이름과 값의 연결, 분기, 묶음, 반복 경로, 함수, 도구, 객체, 저장을 각각 상징합니다. 구체적인 예제의 전후 표현과 설명은 그림 아래에 별도로 남깁니다. 코스별 선택 근거와 원고는 [도입 콘텐츠 기록](intro-content.md)을 따릅니다.

8개 코스 페이지에는 각 코스의 큰 도입과 레슨 목차를, 44개 레슨 페이지에는 각 레슨의 작은 도입과 본문을 제공합니다. 서비스 소개와 전체 목차는 시작 페이지에 둡니다. 레슨마다 큰 코스 도입을 반복하지 않으며, 한 레슨의 끝에서 다음 페이지를 자동으로 열지 않습니다. [페이지 경계](page-structure.md)에 주소·제목 위계·이전 주소 호환을 기록했습니다.

`lib/intro-motion.js`는 제목의 작은 이동·크기 변화, 그림 조각의 배치·회전·크기와 선의 표시를 스크롤 위치에 연결합니다. 코스 도입은 화면에 전체가 들어가면 전체를 고정하고, 설명이 길면 그림·캡션·전후 미리보기만 고정합니다. 그 영역도 화면에 담기지 않으면 완성된 정적 그림을 표시합니다. 고정 위치는 머리말 아래 12px, 관찰용 추가 거리는 화면 높이의 70%를 320~720px로 제한한 값이며 마지막 15%는 완성된 모양을 유지합니다. 작은 레슨 도입은 제목과 그림 영역의 위쪽이 화면 높이의 85%에서 45%로 이동하는 동안 마치며 고정하지 않습니다. 글과 그림의 의미를 연출 진행률에 따라 바꾸거나 글을 숨기지 않습니다.

## 도입·본문 효과·학습 상태 시각화의 경계

- 본문에서 굵게 표시한 글자는 기본적으로 정적입니다. 본문 문구 효과는 `.text-effect`가 있는 문구에만 연결합니다. 도입 제목·상징 그림은 별도의 도입 연출 경로를 사용합니다. 본문 문구 주변의 입자 장식은 줄 배치에 영향을 주지 않게 그리며 입력을 받지 않고 보조 기술에서도 제외합니다.
- 글자 움직임·빛·색종이·폭죽 효과는 해당 표현을 강조합니다. 본문을 감추거나 줄 배치를 바꾸거나 다음 내용을 읽기 위해 종료를 기다리게 하지 않습니다. 문구에서 벗어나면 정한 규칙에 따라 장식만 사라지고 문구는 남습니다.
- 학습 상태 시각화는 `.visualization-track` 안에서 강화됩니다. 본문·관찰 질문·해석 본문은 그 바깥의 일반 문서 흐름에 있습니다. 강화가 성공하면 해당 시각화의 정적 대체 표시만 교체하고 본문은 숨기지 않습니다.
- 학습 상태 시각화의 고정 표시는 `data-pin="true"`인 선택 구간에 적용합니다. 현재 선택한 44개 모두 고정을 요청하며, 이동 거리 `--travel`은 해당 원고에 기록한 값입니다. 거리의 앞 90%에서 원고의 학습 진행률 0~1을 진행하고 마지막 10%에서는 완성 상태를 유지합니다. 전체 장면 수나 실행 단계 수로 거리를 자동 할당하지 않습니다. 무대가 읽을 수 있는 크기로 화면에 들어오지 않으면 동적 무대를 숨기고 모든 상태를 순서대로 나열한 정적 자료로 대체합니다. 코스 도입의 고정은 앞 절에서 정한 별도 관찰 구간을 사용합니다.
- 문자열의 `sequence` 도식은 글자와 위치를 그대로 두고 선택 범위만 바꿉니다. 선택 여부는 `nodes[].active`의 불리언으로 기록하며 색과 “선택” 표시를 함께 제공합니다. 원본을 지우거나 글자를 옮겨 슬라이스를 원본 변경처럼 보이게 하지 않습니다. 서로 독립인 값의 비교에는 연속 실행 화살표를 붙이지 않습니다.
- 확인 문항은 질문·선택지 다음에 정답과 해설을 그대로 놓습니다. 정답 공개용 고정 무대, 효과가 끝나야 열리는 답, 화면 단위 진행을 만들지 않습니다.
- 움직임 줄이기·라이브러리 실패·JavaScript 미사용에서는 도입 제목·설명·완성된 상징 그림과 본문·정적 예제를 유지합니다. 선택한 학습 상태 시각화는 순서 있는 상태 설명으로, 본문 문구 효과는 정적 강조로 바꿉니다.

이 디자인 기록은 제작 선택과 구현 근거입니다. 교수 검토·사용자 디자인 승인·학생의 학습 효과 검증을 완료했다는 뜻은 아닙니다.
