# ScrollLand 디자인 참고 조사

확인일: 2026-09-23. 공개 서비스와 제작자의 원문 18개를 직접 열어 확인했습니다. 15개는 Codex 인앱 브라우저에서 화면도 확인했고, Seeing Theory는 본문을 확인했으나 진입 화면의 전환이 끝난 상태를 확인하지 못했습니다. The Pudding과 Explorable Explanations는 공개 본문만 확인했습니다. 아래의 학습 방해 가능성은 관찰한 구성에 대한 설계 판단이며, 학생 실험으로 입증한 효과가 아닙니다.

## 1. 이번 구현에 적용할 방향

Python을 처음 배우거나 막힌 개념을 복습하는 사람이 **설명 → 코드 → 출력 → 실행 전후 상태**를 같은 장면에서 비교하게 합니다. 읽는 속도와 순서는 학생이 정합니다. 본문을 읽기 위해 정답 입력, 로그인, 재생, 도식 조작을 요구하지 않습니다.

- 학습 영역의 개념: 이름과 값의 연결, 실행 순서, 분기, 반복, 호출, 데이터 변경, 이전 상태와 이후 상태, 선행 개념, 되읽기.
- 색의 출발점: 밝은 종이색, 진한 글씨색, 연필 같은 회색 보조 글씨, 옅은 회색 코드 바탕, 중요한 연결을 가리키는 청록색, 오류의 원인을 알려주는 절제된 적색. 색상값은 아래의 구현 제안이며 참고 사이트에서 추출한 값이 아닙니다.
- 고유한 구성: 매 장면에서 **실행한 코드와 전후 상태를 함께 보여주는 구성**. 코드의 이름, 도식의 이름, 설명의 이름을 동일하게 표시합니다. 조작 후에도 기본 예제와 비교 근거가 사라지지 않습니다.
- 배제할 기본형: 큰 홍보 화면으로 본문을 밀어내는 구성, 모든 단락을 같은 크기 카드에 넣는 구성, 정답·점수·연속 접속으로 다음 내용을 잠그는 구성.
- 채택할 전체 인상: 밝은 학습 문서. 제목과 여백으로 읽는 순서를 드러내고, 도식과 코드에 필요한 만큼만 선과 바탕색을 사용합니다.

## 4. 핵심 채택 패턴과 검증 항목

1. **MDN·React의 목표와 위치 표시**: 레슨 진입 후 무엇을 배우고 선행 개념이 무엇인지 찾을 수 있어야 합니다.
2. **Josh Comeau·Svelte의 설명과 예제 근접 배치**: 읽은 설명에 해당하는 코드와 결과가 명확히 연결되어야 합니다.
3. **Python Tutor·Red Blob Games의 실행 단계와 상태 대응**: 같은 이름을 코드·도식·설명에서 사용하고, 이전 상태와 현재 상태의 차이를 비교할 수 있어야 합니다.
4. **Rust Book의 오류와 수정 결과 연결**: 오류를 장식적 경고로 처리하지 않고 원인·수정·결과를 구체적으로 읽을 수 있어야 합니다.

6. **Python 공식 문서의 명시적 참조**: 모든 장면·레슨 링크에 제목을 포함하고, 코드와 출력이 구분되어야 합니다.
