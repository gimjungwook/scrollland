# 본문 읽기와 선택 연출의 디자인 근거

확인일: 2026-09-23. 이번 기준은 연속해서 읽는 Python 학습 자료입니다. 학습에 필요한 입력이 스크롤 하나라는 조건과 모든 구간을 움직여야 한다는 조건은 다릅니다. 본문·정적 예제가 정상 기본이며, 제작자가 지정한 글자 효과와 채택 근거가 있는 시각화만 더합니다.

## 화면의 의도와 구성

학습자는 설치나 실행 환경을 먼저 준비하지 않고, 한 문제를 설명하는 글과 예제의 결과를 읽습니다. 읽던 문단으로 돌아가 비교할 수 있어야 합니다. 화면은 형광펜으로 중요한 연결을 표시한 학습 노트의 성격으로 구성합니다.

| 설계 항목 | 선택 |
| --- | --- |
| 내용의 중심 | 이름, 값, 관계, 순서, 예측, 해석. 본문이 이유를 설명하고 필요한 자료가 가까이 따릅니다. |
| 색의 기준 | 밝은 종이색 `#f7f7f0`, 접힌 종이색 `#eeefe6`, 짙은 잉크색 `#183127`, 녹색 표시 `#27623e`, 선택한 관찰 무대의 짙은 녹색 `#13221b`. 다른 사이트에서 추출한 색상이 아닙니다. |
| 고유한 구성 | 정적 코드와 출력이 한 예제로 이어지고, 필요한 경우 그 사이에서 이름·값의 관계를 관찰한 뒤 같은 너비의 해석 본문으로 돌아옵니다. |
| 본문 | Noto Sans KR, 기본 18px·행간 1.95·최대 읽기 폭 720px. 작은 화면에서도 17px 본문을 유지하고 내용만큼 높이가 늘어납니다. |
| 코드 | IBM Plex Mono, 정적 예제 15px. 긴 정적 코드만 영역 안에서 가로로 읽습니다. 해당 영역에 키보드 초점 표시를 둡니다. |
| 위계 | 레슨 제목 → 소제목 → 본문 → 예제 표제·출처. 큰 글자만으로 구분하지 않고 굵기·색·여백을 함께 사용합니다. |
| 공간 | 4px 기준 간격. 같은 설명의 문단은 가까이, 다른 설명 단위는 넓게 둡니다. 본문 뒤에 화면 하나 크기의 빈 공간을 자동 배정하지 않습니다. |
| 깊이 | 종이색의 작은 차이와 얇은 경계선. 반복 카드·큰 그림자·장식 그라디언트를 기본 틀로 사용하지 않습니다. |
| 탐색 | 작은 고정 머리말은 현재 레슨과 선택 목차 이동을 제공합니다. 본문 진행은 기본 스크롤만으로 이어집니다. |

## 본문·효과·시각화의 경계

- 굵게 표시한 글자는 기본적으로 정적입니다. 효과는 `.text-effect`가 있는 문구에만 연결합니다. 장식은 본문 레이아웃 바깥에 그리며 입력을 받지 않고 보조 기술에서도 제외합니다.
- 글자 움직임·빛·색종이·폭죽 효과는 해당 표현을 강조합니다. 본문을 감추거나 줄 배치를 바꾸거나 다음 내용을 읽기 위해 종료를 기다리게 하지 않습니다. 문구에서 벗어나면 정한 규칙에 따라 장식만 사라지고 문구는 남습니다.
- 시각화는 `.visualization-track` 안에서만 강화됩니다. 본문·관찰 질문·해석 본문은 그 바깥의 일반 문서 흐름에 있습니다. 강화가 성공하면 해당 시각화의 정적 대체 표시만 교체하고 본문은 숨기지 않습니다.
- 고정 표시는 `data-pin="true"`인 선택 구간에만 적용합니다. 이동 거리 `--travel`은 해당 원고에 기록한 값이며 전체 장면 수나 실행 단계 수로 자동 할당하지 않습니다. 무대가 읽을 수 있는 크기로 화면에 들어오지 않으면 고정을 풀고 일반 흐름으로 표시하며, 지나친 초기 상태도 읽을 수 있도록 순서 있는 정적 자료를 함께 제공합니다.
- 확인 문항은 질문·선택지 다음에 정답과 해설을 그대로 놓습니다. 정답 공개용 고정 무대, 효과가 끝나야 열리는 답, 화면 단위 진행을 만들지 않습니다.
- 움직임 줄이기·라이브러리 실패·JavaScript 미사용에서는 본문과 정적 예제를 유지합니다. 선택한 시각화만 순서 있는 상태 설명으로, 글자 효과만 정적 강조로 바꿉니다.

이 디자인 기록은 제작 선택과 구현 근거입니다. 교수 검토·사용자 디자인 승인·학생의 학습 효과 검증을 완료했다는 뜻은 아닙니다.
