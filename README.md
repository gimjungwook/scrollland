# ScrollLand

스크롤 하나로 Python 코드·값·도식·출력·설명을 함께 바꾸며 배우는 한국어 학습 자료입니다. 기본 화면은 8개 코스·44개 레슨이 하나의 여정으로 이어지고 개별 레슨 주소에서도 같은 방식으로 읽습니다. 전체 목차의 44개 제목은 원하는 위치로 바로 가는 선택 탐색이며 검색 입력은 제공하지 않습니다. W3Schools Python Tutorial은 주제 범위만 참고했으며 문장·예제·코스 경계는 새로 작성했습니다.

브라우저에서 로그인이나 설치 없이 읽습니다. 스크롤을 내리면 고정된 학습 무대의 코드·변수 상태·도식·출력·설명이 같은 단계로 갱신되고, 위로 돌아가면 해당 상태를 복원합니다. 단계·재생·답 제출 버튼은 없습니다. 질문 뒤의 스크롤 구간에서 정답과 모든 선택지의 근거를 읽습니다. JavaScript·연출 실패 또는 움직임 줄이기에서는 같은 자료를 정적으로 제공합니다. 음성·자동 스크롤·브라우저 Python 실행기·학습 기록 수집은 없습니다.

## 로컬에서 읽기

저장소를 내려받아 이 폴더에서 정적 파일 서버를 실행합니다.

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8765/`를 엽니다. 학습할 때는 Node.js나 Python 설치가 필요하지 않습니다. 위 Python 명령은 개발자가 로컬 파일을 제공하는 방법입니다. 정적 호스팅에 게시하면 웹 주소만으로 읽을 수 있습니다.

## 원본 수정과 검증

개발에는 Node.js 20 이상, 예제 검사에는 Python 3.10 이상이 필요합니다. npm 패키지 설치 과정은 없습니다.

```sh
npm run build
npm run validate
```

- `curriculum.json`: 코스 순서와 레슨 식별자.
- `lessons/<slug>.json`: 레슨 설명·독립 예제·출력·도식·확인 문항 원본.
- `motion.json`: 135개 장면의 314개 중간 상태. 각 `steps` 항목은 `trace` 설명과 대응하는 코드 줄 `lines`, 이름과 값 `nodes`, 그 단계까지의 `output`을 담습니다. 각 장면의 `finalNodes`는 끝에서 비교할 관계·값이며, 반환값·출력값·삭제 전 자료를 비교할 때는 라벨에 그 시점을 구분합니다. 노드의 선택 `objectId`는 같은 객체와 별도 복사본을 구분합니다.
- `lib/scroll-state.js`: 스크롤 진행률에서 현재 단계와 코드·값·출력·설명을 계산합니다.
- `scripts/generate.mjs`: 교육 내용과 상태 대응을 검증하고 전체 여정 `index.html`, 개별 레슨 `learn/<slug>.html`, `404.html`을 생성합니다. 필요한 상태 자료를 HTML에 함께 넣습니다.
- `scripts/validate-examples.mjs`: 각 예제를 4초 제한으로 별도 임시 폴더에서 실행합니다. `stdin`과 `files` 입력 자료를 준비하고 표준 출력을 대조합니다. 자체 모듈 예제를 위해 이 임시 폴더만 모듈 검색 경로의 앞에 추가합니다.
- `lib/contract.js`: 교육 원본의 데이터 계약과 생성물 일치 확인 규칙.
- `app.js`, `styles.css`: 고정 학습 무대·스크롤 상태 동기화·시각 연출·목차 탐색과 정적 대체 표시.

예제 출력은 줄바꿈을 LF로 맞춘 뒤 마지막 줄바꿈 하나를 제외한 문자열을 `output`에 저장합니다. 내부의 빈 줄이나 공백은 그대로 비교합니다. Python 실행 파일을 지정하려면 `SCROLLLAND_PYTHON=/path/to/python3 npm run validate:examples`를 사용합니다. 생성된 HTML을 직접 편집하지 마세요. `npm run check`는 생성물과 원본의 불일치, 누락 파일과 깨진 내부 파일 링크를 검사합니다.

입력 파일 경로에는 절대 경로, 상위 폴더 이동, 역슬래시와 콜론을 사용할 수 없습니다. 예제 검사는 신뢰한 저장소 코드를 실행하는 개발 도구이며, 임의의 외부 코드를 격리하는 보안 실행기는 아닙니다.

## 정적 호스팅

`npm run build`와 `npm run validate`를 통과한 프로젝트 루트 전체를 정적 호스팅에 게시합니다. 정상 페이지는 상대 경로를 사용합니다. 없는 주소에서 표시할 `404.html`의 목차 링크는 `SCROLLLAND_BASE_PATH`로 정합니다. 기본값은 `/`이며, `/scrollland/` 같은 하위 경로에 게시할 때는 `SCROLLLAND_BASE_PATH=/scrollland/ npm run build`와 같은 값의 `SCROLLLAND_BASE_PATH=/scrollland/ npm run validate`를 실행합니다. `learn/`과 `lessons/`를 포함한 동일 버전의 산출물을 함께 게시해야 합니다. GitHub 코드 공개와 웹사이트 배포는 별도 작업입니다.

필요한 상태 자료는 HTML에 함께 들어 있어 별도 레슨 JSON 요청·8초 대기·재시도 버튼이 없습니다. GSAP 또는 ScrollTrigger를 불러오지 못하거나 연출 초기화에 실패하면 정적 학습 자료와 실패 안내를 제공합니다. 움직임 줄이기에서도 모든 단계와 해설을 정적으로 읽습니다. 없는 주소에서는 `404.html`이 전체 여정으로 안내합니다. 호스팅 제공자가 사용자 정의 404 페이지를 지원해야 이 안내가 표시됩니다.

## 자료와 권리

각 레슨의 `sourceUrls`와 페이지 하단은 개념 확인에 사용한 Python 공식 자료를 연결합니다. [디자인 참고 조사](docs/design-references.md)는 참고한 공개 원문과 채택한 구성을 구분합니다. 외부 문서·이미지·로고의 복사본을 배포하지 않습니다.

`lib/gsap.min.js`와 `lib/ScrollTrigger.min.js`는 GSAP 3.15.0 공식 npm 배포의 파일입니다. 해당 파일의 원래 저작권 고지를 보존하고 [GSAP 라이선스 고지·공식 조건 링크](lib/GSAP-LICENSE.txt)를 기록했습니다. [외부 의존성 기록](THIRD_PARTY.md)을 확인하세요. 제품 자체 코드와 교육 자료의 재사용 라이선스는 별도로 지정하지 않았습니다.
