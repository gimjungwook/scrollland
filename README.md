# ScrollLand

스크롤하며 글을 읽고, 필요한 순간에 코드의 변화를 살펴보는 한국어 Python 학습 자료입니다. 8개 코스·44개 레슨이 한 문서처럼 이어지며 개별 레슨 주소에서도 읽을 수 있습니다. W3Schools Python Tutorial은 다룰 주제의 범위만 참고했고 문장·예제·코스 경계는 새로 작성했습니다.

본문과 정적 예제는 읽던 자리에 남습니다. 관계나 실행 과정의 변화가 중요한 구간에서는 스크롤 위치에 맞춰 코드 줄·이름과 값·도식·출력·상태 설명을 함께 갱신합니다. 위로 돌아가면 해당 위치의 상태를 복원합니다. 제작자가 지정한 일부 문구에는 작은 움직임·빛·입자 효과를 더합니다. 일반적인 굵게 표시는 움직이지 않습니다.

학습을 진행하는 데 필요한 입력은 스크롤뿐입니다. 목차와 선행 레슨 링크는 원하는 위치로 이동하는 선택 탐색입니다. 확인 문항의 질문·선택지 3개·정답과 각 선택지의 이유도 본문처럼 이어 읽습니다. 재생·단계 이동·답 제출 버튼, 자동 스크롤, 강제 스냅은 없습니다. 브라우저에서 로그인이나 설치 없이 읽으며 음성·Python 실행기·개인 학습 기록 수집은 제공하지 않습니다.

## 현재 교육 구성

| 구성 | 수량 | 표시 방식 |
| --- | ---: | --- |
| 코스 / 레슨 | 8 / 44 | 문제와 선행 개념을 따라 연결 |
| 읽기 구간 | 127 | 글과 필요한 정적 예제·비교 자료. 이 중 6개는 글만 있는 구간 |
| 시각화 구간 | 14 | 관찰 질문과 본문 → 상태 변화 → 해석 본문 |
| 실행 가능한 예제 | 135 | 읽기·시각화 구간 전체에 걸쳐 보존 |
| 명시적인 글자 효과 | 6 | 지정 문구에만 적용 |

시각화 14개 중 12개는 화면에 무대 전체가 들어갈 때 고정하고, 2개는 고정 없이 표시합니다. 낮거나 좁은 화면에서 무대가 들어가지 않으면 고정을 해제하고, 지나친 초기 상태도 읽을 수 있도록 순서 있는 정적 자료를 함께 제공합니다. 구간·단락·시각화 개수에 일률적인 최소 수량은 두지 않습니다. 각 선택의 근거는 [본문과 연출의 콘텐츠 선택 기록](docs/content-presentation.md)에 있습니다.

## 로컬에서 읽기

저장소를 내려받아 이 폴더에서 정적 파일 서버를 실행합니다.

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8765/`를 엽니다. 학습할 때는 Node.js나 Python 설치가 필요하지 않습니다. 위 Python 명령은 개발자가 로컬 파일을 제공하는 방법입니다. 정적 호스팅에 게시하면 웹 주소만으로 읽을 수 있습니다.

## 원본 수정과 검증

개발에는 Node.js 20 이상, 예제 검사에는 Python 3.10 이상이 필요합니다. npm 패키지 설치 과정은 없습니다.

```sh
npm run build
npm run validate
```

| 원본 / 구현 | 역할 |
| --- | --- |
| `curriculum.json` | 코스 순서와 레슨 식별자 |
| `lessons/<slug>.json` | 레슨 목표·본문·예제·출력·확인 문항. 각 구간의 `kind`와 문구별 `effect`를 명시 |
| `motion.json` | `version: 2`의 `scenes`에 채택한 시각화 14개만 저장. 50개 중간 상태와 구간별 최종 비교 자료 |
| `lib/contract.js` | 교육 원본의 필수 항목·선행 관계·입력 경로·구간 종류별 자료 검사 |
| `lib/scroll-state.js` | 제작자가 정한 상태 경계 `stops`와 스크롤 진행률로 코드 줄·값·출력·상태 설명 계산 |
| `lib/text-effects.js` | 지정 문구의 스크롤 연결 효과 또는 짧은 진입 효과와 재진입 규칙 처리 |
| `scripts/generate.mjs` | 자료를 검증하고 전체 문서 `index.html`, 개별 레슨 `learn/<slug>.html`, `404.html` 생성 |
| `scripts/validate-examples.mjs` | 코드가 있는 135개 예제를 각각 별도 임시 폴더에서 실행하고 출력 대조 |
| `app.js`, `styles.css` | 읽기 흐름·시각화·글자 효과·목차 탐색·움직임 줄이기 처리 |

자료 구조와 제작 절차는 [기여 안내](CONTRIBUTING.md)를 참고하세요. 생성된 HTML은 직접 편집하지 않습니다. `npm run check`는 생성물과 원본의 일치, 누락 파일과 내부 파일 링크를 검사합니다.

예제 출력은 줄바꿈을 LF로 맞춘 뒤 마지막 줄바꿈 하나를 제외한 문자열을 `output`에 저장합니다. 내부의 빈 줄이나 공백은 그대로 비교합니다. 예제마다 4초 제한을 두고 `stdin`과 `files`를 준비합니다. 자체 모듈 예제를 위해 해당 임시 폴더만 모듈 검색 경로의 앞에 추가합니다. Python 실행 파일은 `SCROLLLAND_PYTHON=/path/to/python3 npm run validate:examples`로 지정합니다.

입력 파일 경로에는 절대 경로, 상위 폴더 이동, 역슬래시와 콜론을 사용할 수 없습니다. 예제 검사는 신뢰한 저장소 코드를 실행하는 개발 도구이며, 임의의 외부 코드를 격리하는 보안 실행기는 아닙니다.

## 정적 호스팅과 대체 표시

`npm run build`와 `npm run validate`를 통과한 프로젝트 루트 전체를 정적 호스팅에 게시합니다. 정상 페이지는 상대 경로를 사용합니다. 없는 주소에서 표시할 `404.html`의 목차 링크는 `SCROLLLAND_BASE_PATH`로 정합니다. 기본값은 `/`이며, `/scrollland/` 같은 하위 경로에 게시할 때는 `SCROLLLAND_BASE_PATH=/scrollland/ npm run build`와 같은 값의 `SCROLLLAND_BASE_PATH=/scrollland/ npm run validate`를 실행합니다. `learn/`과 `lessons/`를 포함한 동일 버전의 산출물을 함께 게시해야 합니다. GitHub 코드 공개와 웹사이트 배포는 별도 작업입니다.

본문과 필요한 상태 자료는 HTML에 함께 들어갑니다. 별도 레슨 JSON 요청이나 재시도 버튼은 없습니다. JavaScript를 사용할 수 없거나 움직임 줄이기를 선택한 경우에도 본문·예제·출력·순서대로 나열한 시각화 상태·해설을 읽을 수 있습니다. 시각화 하나가 실패하면 해당 구간을 정적으로 표시하고, 글자 효과가 실패하면 원래 문구와 서식을 남깁니다. 없는 주소에서는 `404.html`이 전체 문서로 안내합니다. 호스팅 제공자가 사용자 정의 404 페이지를 지원해야 이 안내가 표시됩니다.

## 자료와 권리

각 레슨의 `sourceUrls`와 페이지 하단은 개념 확인에 사용한 Python 공식 자료를 연결합니다. [디자인 참고 조사](docs/design-references.md)는 참고한 공개 원문과 채택한 구성을 구분합니다. 외부 문서·이미지·로고의 복사본을 배포하지 않습니다.

`lib/gsap.min.js`와 `lib/ScrollTrigger.min.js`는 GSAP 3.15.0 공식 npm 배포의 파일입니다. 해당 파일의 원래 저작권 고지를 보존하고 [GSAP 라이선스 고지·공식 조건 링크](lib/GSAP-LICENSE.txt)를 기록했습니다. [외부 의존성 기록](THIRD_PARTY.md)을 확인하세요. 제품 자체 코드와 교육 자료의 재사용 라이선스는 별도로 지정하지 않았습니다.
