# ScrollLand

스크롤하며 글을 읽고, 필요한 순간에 코드의 변화를 살펴보는 한국어 Python 학습 자료입니다. 8개 코스·44개 레슨을 코스별로 찾아 읽으며, 한 레슨 안에서 설명과 예제가 스크롤로 이어집니다. W3Schools Python Tutorial은 다룰 주제의 범위만 참고했고 문장·예제·코스 경계는 새로 작성했습니다.

시작 페이지는 서비스 소개와 8개 코스·44개 레슨의 목차를 제공합니다. 코스 페이지는 큰 주제 제목·상징 그림과 해당 레슨 목차를, 레슨 페이지는 한 레슨의 도입·본문·확인 문항을 담습니다. 코스 도입을 레슨마다 반복하지 않습니다. 주소와 이동 규칙은 [페이지 경계](docs/page-structure.md)에 있습니다.

본문과 정적 예제는 읽던 자리에 남습니다. 관계나 실행 과정의 변화가 중요한 구간에서는 스크롤 위치에 맞춰 코드 줄·이름과 값·도식·출력·상태 설명을 함께 갱신합니다. 위로 돌아가면 해당 위치의 상태를 복원합니다. 제작자가 지정한 일부 문구에는 작은 움직임·빛·입자 효과를 더합니다. 일반적인 굵게 표시는 움직이지 않습니다.

한 레슨의 학습 내용은 스크롤만으로 끝까지 읽습니다. 코스·레슨을 바꾸려면 목차·선행 레슨·이전·다음 링크를 사용합니다. 레슨 끝에서 다음 페이지로 자동 이동하지 않습니다. 확인 문항의 질문·선택지 3개·정답과 각 선택지의 이유도 본문처럼 이어 읽습니다. 재생·단계 이동·답 제출 버튼, 학습을 자동으로 진행하는 스크롤, 강제 스냅은 없습니다. 브라우저에서 로그인이나 설치 없이 읽으며 음성·Python 실행기·진도나 답안 수집은 제공하지 않습니다.

새로고침하거나 방문 기록으로 돌아오면 같은 주소의 읽던 위치를 복원합니다. 처음 여는 본문 링크와 읽던 위치는 글꼴·배치 준비 후 맞추며, 그전에 사용자가 스크롤하거나 탐색하면 늦은 위치 보정을 취소합니다. 위치 복원에 필요한 현재 주소와 가로·세로 좌표만 해당 브라우저 방문 기록에 남깁니다. 서버·계정·`localStorage`에 진도나 답안을 저장하지 않습니다.

## 현재 교육 구성

| 구성 | 수량 | 표시 방식 |
| --- | ---: | --- |
| 코스 / 레슨 | 8 / 44 | 문제와 선행 개념을 따라 연결 |
| 코스 도입 / 레슨 도입 | 8 / 44 | 주제별 상징 그림과 질문·결과 미리보기. 읽기·시각화 구간 수와 별도 |
| 읽기 구간 | 98 | 글과 필요한 정적 예제·비교 자료. 이 중 6개는 글만 있는 구간 |
| 시각화 구간 | 44 | 관찰 질문과 본문 → 상태 변화 → 해석 본문 |
| 전체 본문 구간 | 142 | 읽기 98개와 시각화 44개. 도입과 확인 문항은 별도 |
| 실행 가능한 예제 | 135 | 읽기·시각화 구간 전체에 걸쳐 보존 |
| 명시적인 본문 문구 효과 | 6 | 지정 문구에만 적용 |

코스 도입은 변화하는 그림을 볼 수 있도록 짧은 관찰 구간 동안 화면에 머뭅니다. 도입 전체가 화면에 들어가면 전체를, 설명이 길면 그림·캡션·전후 미리보기만 고정합니다. 그림 영역도 담을 수 없으면 완성된 정적 그림을 표시합니다. 작은 레슨 도입은 고정하지 않고 제목이 화면을 벗어나기 전에 연출을 마칩니다. 제목·설명·미리보기는 처음부터 읽을 수 있습니다. 도입 원고와 장면 선택은 [도입 콘텐츠 기록](docs/intro-content.md)에 있습니다.

44개 레슨에서 각각 핵심 오해를 풀기 위한 관찰 과정을 선정했습니다. 도입 효과와 최종 코드·결과만으로 설명이 충분하다고 보았던 기존 판단을 바로잡고, 입력에서 결과가 나오는 이유와 중간 과정을 보강했습니다. 현재 레슨마다 시각화가 하나인 것은 원고를 검토한 결과이며 새 레슨에 적용할 수량 할당 기준이 아닙니다. [레슨 관찰·설명 기준](docs/lesson-observation.md)과 [본문과 연출의 콘텐츠 선택 기록](docs/content-presentation.md)에 구체적인 판단을 남겼습니다.

선택한 시각화 44개는 모두 관찰 중 무대를 고정하도록 지정했습니다. 관찰용 스크롤 거리의 마지막 10%에서는 완성 상태를 유지해 결과를 확인할 수 있습니다. 무대 전체가 화면에 들어올 때만 움직이며, 낮거나 좁은 화면에 담기지 않으면 동적 무대 대신 모든 상태를 순서대로 나열한 정적 자료를 표시합니다. 일반 본문과 정적 예제 98개 구간은 고정하지 않습니다. 기존 135개 예제의 코드·입력·보조 파일·예상 출력은 유지하며 설명 본문을 보강했습니다.

## 로컬에서 읽기

저장소를 내려받아 이 폴더에서 정적 파일 서버를 실행합니다.

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8765/`를 엽니다. 학습할 때는 Node.js나 Python 설치가 필요하지 않습니다. 위 Python 명령은 개발자가 로컬 파일을 제공하는 방법입니다. 정적 호스팅에 게시하면 웹 주소만으로 읽을 수 있습니다.

## 원본 수정과 검증

개발에는 Node.js 20 이상, 예제 검사에는 Python 3.10 이상이 필요합니다. npm 패키지 설치 과정은 없습니다.

```sh
npm run build
npm run validate
```

| 원본 / 구현 | 역할 |
| --- | --- |
| `curriculum.json` | 코스 순서·레슨 식별자와 코스별 `intro` 원고 |
| `lessons/<slug>.json` | 레슨별 `intro`, 목표·본문·예제·출력·확인 문항. 각 구간의 `kind`와 문구별 `effect`를 명시 |
| `motion.json` | `version: 2`의 `scenes`에 채택한 시각화 44개만 저장. 시작·중간·마지막 관찰을 포함한 설명 단계 190개와 구간별 최종 비교 자료 44개 |
| `lib/contract.js` | 교육 원본의 필수 항목·선행 관계·입력 경로·구간 종류별 자료 검사 |
| `lib/scroll-state.js` | 제작자가 정한 상태 경계 `stops`와 스크롤 진행률로 코드 줄·값·출력·상태 설명 계산 |
| `scripts/render-intro.mjs` | 코스별 상징 그림 8종과 코스·레슨 도입의 공통 HTML 생성 |
| `lib/intro-motion.js` | 도입 제목·그림의 스크롤 위치별 배치 계산과 정적 복원 |
| `lib/page-navigation.js` | 이전 시작 페이지 해시를 명시한 코스·레슨 주소로만 변환 |
| `lib/text-effects.js` | 지정 문구의 스크롤 연결 효과 또는 짧은 진입 효과와 재진입 규칙 처리 |
| `scripts/generate.mjs` | 자료를 검증하고 시작 페이지 `index.html`, 코스 페이지 `courses/<courseId>.html`, 레슨 페이지 `learn/<slug>.html`, 오류 안내 `404.html` 생성 |
| `scripts/validate-examples.mjs` | 코드가 있는 135개 예제를 각각 별도 임시 폴더에서 실행하고 출력 대조 |
| `app.js`, `styles.css` | 읽기 흐름·도입·시각화·글자 효과·목차 탐색·움직임 줄이기 처리 |

자료 구조와 제작 절차는 [기여 안내](CONTRIBUTING.md)를 참고하세요. 생성된 HTML은 직접 편집하지 않습니다. `npm run check`는 생성물과 원본의 일치, 누락 파일과 내부 파일 링크를 검사합니다.

예제 출력은 줄바꿈을 LF로 맞춘 뒤 마지막 줄바꿈 하나를 제외한 문자열을 `output`에 저장합니다. 내부의 빈 줄이나 공백은 그대로 비교합니다. 예제마다 4초 제한을 두고 `stdin`과 `files`를 준비합니다. 자체 모듈 예제를 위해 해당 임시 폴더만 모듈 검색 경로의 앞에 추가합니다. Python 실행 파일은 `SCROLLLAND_PYTHON=/path/to/python3 npm run validate:examples`로 지정합니다.

입력 파일 경로에는 절대 경로, 상위 폴더 이동, 역슬래시와 콜론을 사용할 수 없습니다. 예제 검사는 신뢰한 저장소 코드를 실행하는 개발 도구이며, 임의의 외부 코드를 격리하는 보안 실행기는 아닙니다.

## 정적 호스팅과 대체 표시

`npm run build`와 `npm run validate`를 통과한 프로젝트 루트 전체를 정적 호스팅에 게시합니다. 정상 페이지는 상대 경로를 사용합니다. 없는 주소에서 표시할 `404.html`의 목차 링크는 `SCROLLLAND_BASE_PATH`로 정합니다. 기본값은 `/`이며, `/scrollland/` 같은 하위 경로에 게시할 때는 `SCROLLLAND_BASE_PATH=/scrollland/ npm run build`와 같은 값의 `SCROLLLAND_BASE_PATH=/scrollland/ npm run validate`를 실행합니다. `courses/`·`learn/`·`lessons/`를 포함한 동일 버전의 산출물을 함께 게시해야 합니다. GitHub 코드 공개와 웹사이트 배포는 별도 작업입니다.

본문과 필요한 상태 자료는 HTML에 함께 들어갑니다. 별도 레슨 JSON 요청이나 재시도 버튼은 없습니다. JavaScript를 사용할 수 없거나 움직임 줄이기를 선택한 경우에도 도입 제목·완성된 상징 그림·설명과 본문·예제·출력·순서대로 나열한 시각화 상태·해설을 읽을 수 있습니다. 도입 연출이 실패하면 완성된 상징 그림과 글을 남깁니다. 시각화 하나가 실패하면 해당 구간을 정적으로 표시하고, 글자 효과가 실패하면 원래 문구와 서식을 남깁니다. 없는 주소에서는 `404.html`이 시작 페이지의 전체 목차로 안내합니다. 호스팅 제공자가 사용자 정의 404 페이지를 지원해야 이 안내가 표시됩니다.

이전 `index.html#course-…`·`index.html#lesson-…` 주소는 JavaScript를 사용할 수 있으면 해당 코스·레슨 페이지로 연결합니다. JavaScript가 없어도 같은 앵커의 목차 항목과 링크를 사용할 수 있습니다.

## 자료와 권리

각 레슨의 `sourceUrls`와 페이지 하단은 개념 확인에 사용한 Python 공식 자료를 연결합니다. [디자인 참고 조사](docs/design-references.md)는 참고한 공개 원문과 채택한 구성을 구분합니다. 외부 문서·이미지·로고의 복사본을 배포하지 않습니다.

`lib/gsap.min.js`와 `lib/ScrollTrigger.min.js`는 GSAP 3.15.0 공식 npm 배포의 파일입니다. 해당 파일의 원래 저작권 고지를 보존하고 [GSAP 라이선스 고지·공식 조건 링크](lib/GSAP-LICENSE.txt)를 기록했습니다. [외부 의존성 기록](THIRD_PARTY.md)을 확인하세요. 제품 자체 코드와 교육 자료의 재사용 라이선스는 별도로 지정하지 않았습니다.

## 확인 범위

이 자료는 학습 자료 초판입니다. 자동 검사는 구조·연결·출력과 일부 동작을 확인하며 설명의 교육적 타당성이나 학습 효과를 입증하지 않습니다. 예제와 내용 검토 이력은 [콘텐츠 검증 기록](docs/content-verification.md), 실제 화면 검사와 미검증 범위는 [구현 검증 기록](docs/verification.md)에 기록합니다. 교수 검토·학생 학습 효과 검증·실제 기기 검증·웹 배포는 수행한 증거가 있을 때만 완료로 기록합니다.
